## §2 任务定义

- **T1/T4 验证**: `1` = 该文确实报道了**目标银行** (target_bank 列所示银行) 与**金融科技**相关的事实/活动/观点; `0` = 不是 (包括: 银行匹配错误、金科词属误匹配、纯广告/软文、与目标银行无实质关联的行业泛谈)。判断依据 = 标题 + 内容全文。
- **T2 全文情感**: 基于标题+内容, **仅对 target_bank 目标银行**金融科技活动的情感倾向/评价方向（同行提及不传染——其他银行的利好/负面与目标银行无直接关联时视为噪音, 不影响评分; M3 构念对齐 2026-07-14, 见 §8）。`正面` = 积极/利好/赞誉; `负面` = 消极/风险/批评/处罚; `中性` = 客观描述、无明显方向。
- **T3 窗口情感**: 同 T2 定义, 但**判断文本 = 「机器输入文本」列** (full=标题+正文 / ctx=标题+实体上下文窗口 / ss=标题+银行金科同句片段); **禁止**引入窗口外信息 — 窗口内读不出方向就标 `中性`, 即使全文能读出。

## §3 边界规则 (先例优先, 遇新边界记入 §8 后统一裁定)

1. **混合情感**: 正负并存时按**主导语调** (篇幅与标题倾向加权的整体印象); 真正势均力敌 → `中性`。
2. **引用他行负面**: 报道主体是目标银行、顺带引述其他银行负面 → 只按目标银行侧语调判; 他行负面不传染。
3. **监管处罚 vs 风险提示**: 目标银行因金科业务**被处罚/通报** → `负面`; 银行自身发布**风险提示/合规声明** (主动治理姿态) → 默认 `中性`, 除非文中明确批评银行。
4. **转述 vs 评论**: 纯转述银行公告/发布会 → 按公告内容方向判 (发布新产品/合作通常 `正面`); 记者/专家评论 → 按评论方向判。
5. **标题党**: 标题与正文方向冲突 → 以正文为主、标题为辅 (标题计入但不单独决定)。
6. **T1 边界**: 银行只是被列举的多家之一且无金科关联细节 → `0`; 银行金科产品被用户投诉 → `1` (是金科新闻, 情感另判负面)。
7. **无法判断** (乱码/截断/明显非新闻): T1/T4 标 `0`; T2/T3 标 `中性` 并在理由列注明 "文本异常"。

## §4 编码员与独立性条款

- **人数**: 每任务 2 名编码员 (A/B) + 1 名资深仲裁人 (C, 不参与初标)。
- **资格**: 编码员须具金融/经济学科背景 (研究生及以上或同等从业经验), 能读懂中文财经报道; 仲裁人须为课题组资深成员。
- **独立性 (硬条款)**: ① 每人只收到**自己的盲表副本** (文件级隔离, 非同文件分列); ② 标注期间**禁止**编码员之间就任何具体篇目交流; ③ 盲表不含任何机器判定 (词典/BERT/LLM/投票/抽样层标记) — 收到的文件若发现此类列, 立即停止并报告 (文件发放错误); ④ 编码顺序 = 表内行序 (已随机打乱), 不得自选顺序。
- **报酬与披露**: 按篇计酬, 报酬不与"同意率"或任何结果指标挂钩; 论文 data appendix 披露编码员人数、背景类别、报酬方式与本协议版本号。
- **AI 使用**: 编码员**禁止**使用任何 LLM/翻译/摘要工具辅助判定 (效标效度要求纯人工基准)。

## §5 试标资格门 (pilot gate)

1. 正式标注前, 每任务先试标 **50 篇** (从盲表头部顺序取, 该 50 篇的判定在正式阶段**保留不重标**)。
2. 试标后计算双编码 Cohen κ (`llms_evaluation.compute_cohens_kappa` 口径):
   - κ ≥ 0.667 (tentative 门, Krippendorff 2018) → 进入正式标注;
   - κ < 0.667 → 双人共同复盘分歧 (只讨论**规则理解**, 不看机器标签) → 修订 §3 边界规则 (记 §8) → **换一批** 50 篇重试标; 循环直至过门, 循环次数披露。
3. **报告阈值**: 全量完成后报 Cohen κ + Krippendorff α; α ≥ 0.80 为"可靠" (Krippendorff 2018), 0.667–0.80 为"暂可接受, 须披露"; 阈值预注册于此, 不得事后调整。

## §6 样本量与精度论证

- **T1/T2 (n=1000, 简单随机, seed=42)**: 总体 accuracy 的 Wilson 95% CI 半宽 ≤ ±3.1pp (最坏情形 p=0.5); 双任务共用同一批 → 边际成本减半。
- **T3 (每轨 n=300, 分层过采样: 一致/分歧/预测负面, 层权落盘)**: 分层 accuracy 半宽 ≤ ±9.8pp/层 (n=100 层), 总体加权 accuracy 经 Manski-Lerman 还原; 负面层过采样专门收紧 per-class recall CI (负类基率低, 简单随机下不可估)。
- **T4 (n=300, 年×媒体类型分层)**: 漏检率 (假阴性率) 上界的 Wilson 95% CI; 漏检率预期 ≪ 0.5, CI 实际更窄。
- 精度目标若不满足研究需要, 扩样须新 commit 登记, 不得只扩"结果难看"的层。

## §7 流程时序 (与母计划 §5 一致)

```
盲表生成 (WP-A/B 代码落地后, 生产 T=19 语料) → 试标 50 (§5 门) → 正式标注
→ merge_annotations (A=B→共识; A≠B→待仲裁) → 仲裁人填 编码者C_仲裁 (仍不见机器标签)
→ merge --with-adjudication (主口径) → 共识冻结 → 解锁 reconciliation 对账
→ stage 63/64 回读: κ/α + 分类指标 (剔除口径 与 仲裁口径 并排; T3 另报加权总体口径)
→ validity_claim_gate 解锁评估 (仅 tone 维)
```
