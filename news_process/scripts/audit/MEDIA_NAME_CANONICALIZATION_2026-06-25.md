# 媒体名归一 (MEDIA_NAME_OVERRIDES) 补全 — 2026-06-25

## 背景

stage 62 (`validation/dedup_threshold.py`) 在 **4,046,188 行去重前语料** (`data/processed/_cache/*.parquet`)
上计算媒体权重覆盖率, `df['媒体(中文)'].map(media_weights)` 精确匹配 `config/media_weights.json`:

```
媒体权重覆盖率: 2,795,875/4,046,188 行 (69.10%) 命中 media_weights.json; 未匹配行回退默认权重 10
未匹配媒体 518 个 (1,250,313 行回退默认权重), 高频未匹配: {'21世界经济报道': 154097, ...}
```

518 个未匹配媒体中, 既有【同一家报刊的不同写法】(typo / 改名 / 省名前缀 / 地方版 / 后缀报),
也有大量【先前未收录的独立地方报刊】。本次按用户指令分两类处理:

1. **同一报不同写法 → 预处理阶段归一** (本文档): 在 `MEDIA_NAME_OVERRIDES` 把变体名归一到
   母报/正名, 使 `媒体(中文)` 列本身携带 canonical 名 (影响 dedup 同日裁决、media_breadth、
   outlet 计数、attention 等全部下游), 而非在 `media_weights.json` 列别名权重。
2. **独立报刊 → 赋媒体权威权重** (见 `media-weights-100pct-coverage` / `media_weights.json`
   `//_SUPPLEMENT_2026_06_25` 段): 491 个独立报刊按 CNKI 行政层级评级体系赋权。

## 处理位置 (为什么是 MEDIA_NAME_OVERRIDES)

`MEDIA_NAME_OVERRIDES` (`pipeline/preprocess/_constants.py`) 在 **filter.py 第8步媒体名清理**
(`_clean_and_filter_dataframe`, `s_final.where(s_base != k, v)`) 中 **逐文件应用、且在 `_cache/*.parquet`
写盘之前** → 缓存与全部下游 (含 stage 62) 都看到 canonical 名。另有 runner.py 读回兜底。

⚠ **`compute_preprocess_cache_key` 不哈希 `MEDIA_NAME_OVERRIDES`**, 故本次同时把
`PREPROCESS_CODE_VERSION` `v2-2026-06-11-omni` → **`v3-2026-06-25-media-canon`**, 使旧缓存
(含未归一变体名) 在下次 production run 自动失效重算。

## 方法 (穷举候选 → 多智能体对抗裁决)

- **候选完整性 (确定性)**: 对 518 未匹配名穷举结构规则 (去分隔符等价 / 省名前缀 / 后缀报 /
  地方版后缀 / 法制→法治改名 / 紧 typo[同长1字差且共享前缀≥2后缀≥2]) → 41 个候选变体。
  (编辑距离≤2 规则因短中文名几乎两两≤2 噪声爆炸, 已弃用; 改由 agent 域知识补 typo/改名。)
- **裁决正确性 (多智能体)**: 126-agent 工作流 — 逐候选判定 merge/keep → 每个拟合并项
  **3 个独立 skeptic 从「地域/城市」「主办单位/行政层级」「受众/领域/创刊史」三视角竭力反驳**
  (<2 票反驳才合并) → 一致性终审 (政策对齐 + 链式排查 + 类目订正)。

## 已严格排除的 false-merge traps (保留为独立报刊)

多 skeptic 对抗后判为【不同报刊, 不合并】(各自在 media_weights.json 保留独立权重):

- **不同城市同结构名**: 张家港日报(江苏)≠张家口日报(河北)≠张家界日报(湖南)。
- **省级行业报 ≠ 中央同名报**: 浙江工人日报 / 四川工人日报 (省总工会) ≠ 工人日报 (全总, 中央)。
- **省级青年报互异且 ≠ 上海"青年报"**: 安徽 / 重庆 / 山东青年报 (各省团委报)。
- **不同受众/领域**: 上海老年报 ≠ 上海青年报 (老/青); 北京少年报 ≠ 北京青年报 (少/青);
  中国远洋报 ≠ 中国海洋报 (远洋运输/海洋管理)。
- **不同主办地域**: 上海大众卫生报 ≠ 大众卫生报(湖南); 上海侨报/侨报(美国《侨报》); 亳州新报 ≠ 亳州晚报。
- **独立刊号子版**: 新民晚报社区版 (CN 31-0062, 独立刊号) 保留独立, 仅其下"家庭周刊"归并到它。
