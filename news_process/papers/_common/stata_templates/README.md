## Overview / 概述

This directory hosts `.do.tmpl` Stata script templates with placeholder substitutions for plan v14 main-spec choices. Templates are instantiated into a user-side `replication_v3.2.0/` folder by `build_replication_package(main_spec_choices)`.

本目录存放 `.do.tmpl` Stata 脚本模板，含占位符（main spec 选择）。用户运行 `build_replication_package` 时按 spec 实例化到 `replication_v3.2.0_<locus>_<subst>_<sent>/` 子目录。

## Stata version & packages required / Stata 版本与包依赖

- **Stata ≥ 19** (项目策略 2026-05-16: Stata 19+ only, 无需向下兼容; reghdfe / coefplot / xtdidregress / frames 全功能可用)
- **必装包**:
  ```stata
  ssc install reghdfe
  ssc install ivreg2
  ssc install estout
  ssc install coefplot
  ssc install asdoc
  ```

## FAQ / 故障排查

**Q: `reghdfe` not found?**
A: `ssc install reghdfe` (Stata SSC archive)

**Q: 列 `tech_frac_lc` 不存在?**
A: 检查是否 `46_panel_yearly_full.dta` 由 stage 46 stata_export 生成 (v3.1.1 panel 不含 `_lc` 列). 走完整 pipeline 重生成.

**Q: Stata IC license 报"too many vars"?**
A: 2026-06-12 起 stage 46 只产单一全列 `46_panel_yearly_full.dta` (本机 StataNow/MP 19.5 maxvar≤120,000 直读; 已移除 core/aux IC 双切分). 若确需在 IC 跑, 自行 `keep` 变量子集或升级到 SE/MP.

**Q: main spec 怎么选?**
A: 论文 Methods §4 决定. 推荐 (plan v14 §3.6):
- Locus: `_lc` (Sautner 2023 JF entity-proximity 同构)
- Substantiveness: `_sf` (W&Z 1998 ASQ 全文判定优先, decoupling 信号需 article-level)
- Sentiment: `_ctx` (Hassan 2019 QJE)

但最终选择由论文论证决定; Robustness Appendix 报告其他 7 specs.
