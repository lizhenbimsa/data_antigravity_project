## CORE

该文提出对多个LLM推理结果做集成(多数投票/平均)的简单策略,证明中型LLM多次推理集成比单次大模型推理在文本分类(含情感分类)任务上更稳定、更准确,与本测度族多家LLM投票共识构念高度相关。 该文比较判别式模型(BERT/FinBERT)与生成式LLM(Llama3.1/Mistral/Gemma2)对财经新闻情感分析的表现,并将情感得分用于投资策略构建,呼应本测度族以多家LLM对新闻语调打分并聚合为面板变量的思路。

【构念与来源】
本家族刻画的核心构念是"媒体对目标银行金融科技活动的语调倾向", 也就是通常所说的媒体好感度或媒体情感立场。用大白话说, 就是在某一家银行的某一个年度里, 各家媒体谈论这家银行搞金融科技这件事的时候, 整体上是偏夸奖、偏中立、还是偏批评; 把这一年里一篇篇报道的立场汇总起来, 就得到这家银行这一年的"媒体语调水平"。这个构念在金融传媒与文本分析领域有深厚的学术根基。Tetlock (2007) 最早系统地论证了媒体语调携带超出硬性财务数据之外的增量信息, 并能预测随后的市场反应, 奠定了"媒体情感有独立信息含量"这一命题。Loughran 与 McDonald (2011) 则为金融领域的词典化情感测量打下方法学基石, 指出通用情感词典搬到金融文本上会严重失真, 必须使用领域专用词表。Loughran 与 McDonald (2016) 以及 Kearney 与 Liu (2014) 进一步综述了从关键词计数、词典打分到机器学习、大语言模型的整条语调测量谱系, 说明测量手段一路演进、但"给情感一个可量化载体"的目标一以贯之。本项目正是在中文银行金融科技新闻语料上, 把这一构念落地为 llm_vote_tone 家族。其原始数据来自流水线阶段 21 (tone_llms) 产出的文章级投票分 llm_vote_score, 随后在阶段 40 的 encode.py::aggregate_panel 中依循 Tetlock 等人所倡导的"先分后合"范式——先在每篇文章上判定语调, 再按银行与年度分组求聚合值——汇总成银行—年度面板列, 最终由 stata_audit.py::audit_variable_quality 的关键变量缺失闸对其质量进行监控。

【方法学与计算】
文章级语调的判定采用三家异构大语言模型的多数投票共识机制。这三家分别是 gpt54nano (OpenAI 系, 经 yunwu 路由)、gemini31 (Google 系, 经 yunwu 路由) 与 deepseekv4 (DeepSeek 系, 直连官方端点)。对每一篇报道, 三家模型各自独立给出正面、中性或负面的判定, 再按简单多数把结果折算为离散投票分 llm_vote_score, 取值落在负一、零、正一三个刻度上。之所以坚持用三家集成投票而非依赖单一模型, 理据有三层: 其一, Gilardi 等 (2023) 用实验证明大语言模型在文本标注任务上的准确度已经超过众包标注工人, 使自动化标注在效度上站得住脚; 其二, Kamen 与 Kamen (2025) 表明多数投票的集成策略在内容归类任务上稳定优于任何单一模型, 能有效抵消个别模型的系统性偏差; 其三, Carlson 与 Burbano (2026) 就管理学研究中使用大语言模型标注数据给出了基础守则与警示, 强调必须以多模型交叉与人工基准双重锚定测量效度, 不能盲信单模型输出。银行—年度层面的聚合默认采用等权算术平均, 即 llm_vote_tone{track}, 同时物化组内求和 (llm_vote_tone_sum) 与组内标准差 (llm_vote_tone_std, 即语调离散度或分歧度) 两个伴生统计量。除等权之外, 家族还额外物化三套加权聚合口径, 用来回答"哪一类报道更应当被计入语调": 其一是显著度或提及密度加权 vw, 让更密集提及银行金科的报道获得更大权重, 呼应 Hassan 等 (2019) 以提及频次刻画实体暴露强度的思路; 其二是媒体权威度加权 mw, 依据 media_weights.json 中的来源评级对高声望媒体加权 (原始权重除以均值归一, 使量级近似等权); 其三是羊群衰减加权 hw, 权重来自阶段 24 herd_decay_processor 的注意力衰减机制, 使短时间内扎堆涌现的同质报道被降权。此外, 家族还沿两条创新属性维度做条件均值切分: 依 Westphal 与 Zajac (1994) 的实质—象征二分, 产出实质性 (sub) 与象征性 (symb) 报道各自的语调; 依 Gomber 等 (2018) 的金科创新落点二分, 产出底层技术 (tech) 与应用场景 (app) 报道各自的语调。

【文献定位】
把大语言模型的投票分当作回归变量放进计量模型, 本质上是把一种"生成式测量"接入了因果推断框架, 因此本家族的方法学定位必须锚定在近年关于"大语言模型作为标注器与生成回归元"的规范讨论之上。Ludwig、Mullainathan 与 Rambachan (2025) 提出了大语言模型的应用计量框架, 明确指出由模型生成的变量携带测量误差, 在下游推断中必须显式处理、不能当作无误差的观测值。Egami 等 (2023) 的"设计式监督学习"给出了用不完美代理变量做下游推断的纠偏路径, 为把 LLM 输出接入回归提供了统计学保证。Frankel、Jennings 与 Lee (2022) 与 Huang、Wang 与 Yang (2023) 则分别比较了机器学习、大模型与传统词典法在金融文本情感测量上的相对优劣, 支撑了本项目"以 LLM 投票为主测度、以词典法与 BERT 为并行稳健测度"的三角化设计思想。相对于纯词典法 (例如 Du 等 2022 的中文金融情感词典、Loughran 与 McDonald 2011 的英文金融词典), LLM 投票的优势在于能够捕捉否定、转折、反讽与强烈语境依赖的语义, 这是简单关键词计分无法企及的; 但其代价是可复现性高度依赖缓存冻结, 一旦更换模型或改写提示词, 数值就会漂移, 因此必须以字节级冻结的缓存作为确定性锚。相对于宏观层面的新闻情感指数 (例如 Shapiro、Sudhof 与 Wilson 2022 的经济新闻情感测量), 本家族是实体归因的银行级测度, 只把与目标银行邻近共现的报道计入, 而非笼统汇总全市场新闻。此外, Xing (2025, ACM Transactions on Management Information Systems) 提出了基于分工协作的异质大语言模型代理框架用于金融文本情感分析, 呼应本家族以三家异构 LLM 多数投票汇聚语调判定的集成设计思路。Teles 与 Figueiredo (2025, arXiv) 比较了多个大语言模型在金融市场新闻情感分类任务上的表现, 为本家族多模型投票式情感测度提供了跨模型基准依据; Lefort、Benhamou、Ohana、Guez、Saltiel 与 Jacquot (2024, arXiv) 则以孔多塞陪审团定理检验了多 LLM 情感集成投票的独立性假设是否成立, 为本家族多数投票式语调测度提供了理论边界。

【识别策略定位】
在主线论文 bank_fintech_tone (代号 P1) 与方法学论文 llm_peer 中, canonical 列 llm_vote_tone_full 被明确登记为正文级主处理变量, 也就是 treatment.primary。P1 用它检验媒体语调对银行融资成本等结果变量的因果影响; llm_peer 则以它为核心构念, 演示同行工具变量与生成回归元的纠偏方法。在识别层面, 家族内部的加权、阈值、轨道与属性切分诸变体共同构成一条"规格稳健性梯子": 它们各自都是恰好识别 (just-identified) 的, 互为稳健性、不分主次, 用来证明主结论不会被任何一种聚合口径 (等权对比 vw、mw、hw 三种加权)、任何一个文本窗口 (full、ctx、ss 三轨) 或任何一个注意力衰减阈值 (thr25 至 thr45 四档) 的取舍所驱动。这里有一条必须严守的铁律: 这些并排的替代轨道绝对不能被混进同一个过度识别 (over-identified) 的 Hansen J 检验里去, 因为它们测量的是同一个构念的不同口径而非彼此独立的工具变量, 一旦混入就会伪造出虚假的过度识别自由度、让 J 统计量失去意义。真正意义上的跨模型族错误率控制走的是根级 rwolf 模板 (对应 Table A12), 其理论依据是 Romano 与 Wolf (2005) 关于逐步多重检验作为形式化数据窥探的经典结果——只有当多条系数估计确实构成一个"同一构念、不同测量"的族时, 才应对它们施加族错误率的联合控制, 而这恰恰不同于把它们当作过度识别工具塞进单一 J 统计量。至于工具变量族——同组留一均值、广义 Bartik 与媒体来源暴露三套引擎——则由独立的 iv_extensions 模块单独构造, 完全不属于本家族的范畴, 不可与本家族的稳健性轨混为一谈。还须特别指出, 当 canonical 列作为处理变量出现在方程右侧时, 它本质上是一个"生成回归元": 由三家大语言模型投票生成的离散分携带不可忽略的测量误差, 若直接当作无误差观测代入, 会招致经典的衰减偏误与推断失真。Ludwig、Mullainathan 与 Rambachan (2025) 的应用计量框架正是为此而设, 明确要求把模型生成变量的误差结构纳入识别假设; Egami 等 (2023) 的设计式监督学习则给出用不完美代理做下游推断时的偏误校正与置信区间构造路径。因此本家族在识别层面既要横向铺开规格稳健性梯子以排除口径依赖, 又要纵向正视生成测量误差以保证系数解释的无偏性, 两者缺一不可。

【与相邻测度的构念区分】
llm_vote_tone 必须与三类容易混淆的相邻测度严格区分开。第一类是词典法语调, 也就是六部情感词典 (jiang_2021、yao_2021、bian_2021、du_2022、you_2018、loughran) 各自产出的 tone 列: 词典法是可加、可逐词分解、完全可复现的关键词计分, 而 LLM 投票是对整篇文本语义的整体判定, 二者互为稳健性但绝不可并入同一个 Hansen J。第二类是 BERT 概率语调, 即三个 BERT 模型产出的概率与净语调列: BERT 给出的是连续概率并可派生分布形状五族, LLM 给出的是离散投票共识, 两法互为跨方法稳健性验证。第三类是同族但不同构念的连续分 llm_vote_cont 与概率分 llm_prob_score: 前者是按模型置信度加权的连续语调, 后者来自 logit 探针, 均不是本家族所刻画的离散投票聚合。还有一个极其重要的口径要点: canonical 无后缀的三轨测度是在留篇门控收敛为 full-only (2026-06-29 生效) 之后定义的——一篇报道是否被判定为"银行金科报道", 只看它在全文轨上的 llm_verified_full 是否为真, 因此 ctx 与 ss 两轨已经降格为 conditional-on-full 的子集稳健性测度, 三轨的行宇宙彼此并不对称, 各轨的分母必须逐轨独立计算、绝不可互相借用; 其中 ss 轨还带有专门的回退语义 (镜像 ctx): 当某银行—年度不存在银行与金融科技词的同句共现时, ss 文本退回全文正文并置回退标志、与 ctx 共享篇数分母, 优雅降级而非清空。第四类要区分的是宏观层面的新闻情感指数, 例如 Shapiro、Sudhof 与 Wilson (2022) 对整体经济新闻情感的测量: 那是不做实体归因、笼统汇总全市场新闻的时间序列指标, 而本家族是把报道精确归因到目标银行、只计入与该银行邻近共现的报道的实体级面板测度, 二者的聚合层级与信息用途根本不同。厘清这四类区分, 是防止在实证中把测量同一构念的替代轨、测量不同构念的并行方法、以及测量不同对象的宏观指数三者错误地当作彼此独立的证据来源加以叠加的前提。

【已知局限与稳健性梯子】
本家族的已知局限主要有三条, 使用时须格外注意。第一, 生成式测量的可复现性高度依赖缓存冻结: 全家族的数值都锚定在提示词 v8 字节级冻结加上三家 LLM 缓存零 miss 的离线复现约束之下, 一旦更换嵌入或情感模型、改写提示词, 就属于受控的全量重生, 必须先通过审批门, 并在手稿中如实披露厂商与维度变更 (例如 Google 转阿里 Qwen) 及 full-only 门控带来的数值副作用, 这些副作用是设计使然而非缺陷。第二, 在本银行金科语料上, 中性类与负面类的分布高度偏斜, 负面类近乎退化, 因此 stata 标签会显式标注"neg degenerate"以示警; 使用任何涉及负面向的极端占比变体时, 都须谨慎解读, 优先比较标准化系数而非原始占比水平。第三, 投票分本身携带测量误差 (Ludwig 等 2025; Egami 等 2023), 当它出现在方程左侧作结果变量、还是出现在右侧作处理变量时, 误差的传导方向截然不同, 需要按具体论文语境分别处理。基于这些局限, 稳健性梯子沿五个彼此正交的维度铺开: 聚合权重 (等权与 vw、mw、hw)、文本轨道 (full、ctx、ss)、注意力衰减阈值 (hw 的四档阈值)、创新属性切分 (实质象征与技术应用) 以及标准化与滞后变换 (z 值、一阶滞后、组内标准差)。每一个梯级都各自恰好识别、并排陈列、互为稳健性不分主次, 并且严禁跨维度交叉相乘以免列数呈几何爆炸——这一约束与项目内政治词权重梯度、词典规则消融梯度、co-primary 双轨嵌入所共同遵循的同一条 over-identified Hansen J 铁律完全一致, 是全项目测量稳健性设计的统一底座。除上述三条主要局限外, 还有两条工程与样本层面的注意事项须一并交代。其一是小样本退化: 在只有两年的开发样本 (T 等于二) 上, 凡涉及一阶滞后、组内标准差、羊群年内波动等需要多期或多篇支撑的变体会大量呈现缺失或零方差, 这是设计使然的预期退化而非缺陷, 到覆盖十九年的生产语料上才会正常取值, 解读时切勿据开发样本的缺失反推测度失效。其二是质量审计闸: 面板落地后, stata_audit.py 的关键变量缺失闸会把三轨语调列为受监控对象, 一旦在有报道的银行—年度上出现异常缺失即告警乃至判失败, 以此确保主测度不会因上游某环节静默丢列而带病进入回归。综合来看, 使用本家族时应遵循一条统一准则: 横向比较时把各口径视为平起平坐的旁证并排解读、绝不并入同一过度识别检验, 纵向解释系数时正视生成测量误差并按论文语境区分左右侧传导, 从而在稳健性广度与推断严谨性之间取得平衡。

【白话总览与阅读指南】
用最朴素的话把这一整族说清楚: 我们想量化的, 是"媒体在谈论某家银行搞金融科技这件事时, 到底是捧还是贬"。为此, 流水线先让三家不同来源的大语言模型逐篇给每条新闻打一个情感票——正面记正一、中性记零、负面记负一, 三家投票取多数; 然后把某家银行某一年里所有相关报道的票汇总成一个平均分, 这个平均分就是这家银行这一年的媒体语调。平均分接近正一, 说明这一年媒体基本在夸; 接近负一, 说明基本在批; 接近零, 说明褒贬各半或多为中性。整族之所以有六十多列, 不是因为要量六十多个不同的东西, 而是因为同一件事可以用不同的"计量姿势"去量, 每一种姿势都要单独存一列, 好在论文里证明结论不是靠某一种姿势凑出来的。

这些"计量姿势"主要分五组。第一组是文本范围: 是读整篇报道 (全文轨), 还是只读提到银行金科的那几段 (上下文轨), 还是只读把银行和金融科技写在同一句里的最窄片段 (同句共现轨); 三者由宽到窄, 全文轨是主尺子, 另两条是越来越保守的旁证。第二组是加权方式: 默认每篇报道一票同权, 但也可以让浓墨重彩讲这家银行的报道更有分量 (显著度加权)、让权威大报更有分量 (媒体权威度加权)、或把几天内一窝蜂发的跟风稿分量调低 (羊群衰减加权)。第三组是给羊群衰减加权再拧四档不同的力度旋钮 (第一档到第四档阈值), 画出一条完整的敏感性曲线。第四组是按报道内容切子集: 分成讲实质动作的和只喊口号的 (实质与象征), 以及讲底层技术的和讲应用落地的 (技术与应用), 两两相减就能看出媒体对"真干"和"作秀"、对"硬技术"和"软应用"的态度落差。第五组是统计变换: 把平均分换算成标准分方便跨变量比较 (标准化), 取上一年的值看惯性 (滞后), 或者算组内的分歧程度而非平均高低 (离散度)。

需要反复强调三条使用纪律。其一, 这五组姿势之间以及组内各档之间, 都是"平起平坐、互为旁证"的关系, 谁也不比谁更权威, 因此在做过度识别检验时绝不能把它们当成彼此独立的工具变量一股脑塞进同一个 Hansen J 统计量, 否则就是自欺欺人地虚增了识别自由度。其二, 由于在留篇门控收敛为只看全文之后, 上下文轨和同句共现轨都只是全文留篇集的子集, 三条轨道覆盖的样本并不一样多, 算比例、算缺失率时各轨必须用自己的分母, 不能互相借。其三, 这一族的所有数字都建立在"缓存冻结"这块基石上——只要三家模型的缓存全部命中, 就能在不花一分钱、不联网的情况下把结果一模一样地重算出来; 一旦要换模型或改提问方式, 数字就会变, 那属于伤筋动骨的重算, 必须走审批并在论文里老实交代。理解了这三条, 就能明白为什么同一个"媒体语调"要摊开成这么多列: 它们合起来构成的不是冗余, 而是一张让审稿人无从挑剔的稳健性网。

最后补充几点工程与质量上的细节, 以便使用者正确理解列里可能出现的缺失与退化。其一, 同句共现轨有一套明确的回退语义: 当某家银行在某一年根本没有一篇报道把它和金融科技写进同一句话时, 系统不会硬造数据, 而是让该轨的文本退回到全文正文并打上回退标志, 同时与上下文轨共享篇数分母, 从而优雅降级而非报错清空; 当金融科技词的匹配自动机整体为空时, 回退标志会全面置真, 相关列同样降级。其二, 在只有两年 (T 等于二) 的开发样本上, 涉及滞后、组内标准差、羊群年内波动一类需要多期或多篇支撑的变体会大量呈现缺失或零方差, 这是小样本下的预期退化而非缺陷, 到了覆盖十九年的生产语料上才会正常取值。其三, 面板落地后有一道专门的质量审核闸: 审核程序会把媒体语调的三条轨道列为关键变量, 检查它们在有新闻的银行—年度上是否异常缺失, 一旦在有报道的行里缺失率超过阈值就会告警甚至判失败, 以此确保主测度不会因上游某个环节的静默丢列而带病进入回归。把这些细节和前面的五组姿势、三条纪律合看, 使用者就能对这一族每一列的语义边界、缺失来源与可信区间形成完整而准确的判断, 并在撰写论文与解读系数时避免把不同姿势的替代测度错误地当作彼此独立的证据来源加以叠加。

## VAR: llm_vote_tone_full

【变体差分】
本列是整个家族的 canonical 主测度, 也是唯一 tier 为 core 的列。它在全文轨 (标题 prepend 加全文正文) 上, 对文章级投票分 llm_vote_score_full 按银行—年度取等权算术平均, 得到该银行当年金融科技媒体语调的核心水平。用大白话说, 这就是"这家银行今年被媒体谈金融科技时, 整体口碑有多好"的最主要一把尺子。它被同时登记为两篇论文的正文级主处理变量: 主线论文 bank_fintech_tone (P1) 以它为核心自变量, 检验媒体语调对银行融资成本等结果的影响; 方法学论文 llm_peer 以它为核心构念, 演示同行工具变量与生成回归元的纠偏方法。之所以选全文轨而非 ctx 或 ss 轨作主轨, 是因为 2026-06-29 起留篇门控收敛为 full-only: 一篇报道是否被判为"银行金科报道", 只看它的 llm_verified_full 是否为真; ctx 与 ss 两轨随之降格为 conditional-on-full 的子集稳健性测度。因此全文轨的行宇宙定义了全家族其余轨道的母集, 其分母 n_articles 是物理留篇数, 也是审计闸监控的关键变量之一。

文章级投票来自三家异构大语言模型 gpt54nano、gemini31 与 deepseekv4 的多数票共识, 折算为负一、零、正一的离散分。采用集成投票而非单模型, 依据是 Gilardi 等 (2023) 关于大模型标注超过众包工人的实验证据、Kamen 与 Kamen (2025) 关于多数投票集成稳定占优的结论, 以及 Carlson 与 Burbano (2026) 关于管理学研究中 LLM 标注须多模型交叉与人工锚定的守则。聚合遵循 Tetlock 等人的"先分后合"范式, 与 Fang 与 Peress (2009) 的媒体覆盖度测量、Hassan 等 (2019) 的实体归因文本测量传统一脉相承。在方法学上, 把生成式投票分接入计量框架必须正视其携带的测量误差: Ludwig、Mullainathan 与 Rambachan (2025) 给出应用计量框架, Egami 等 (2023) 给出设计式监督学习的纠偏路径; Frankel 等 (2022) 与 Huang 等 (2023) 则支持"以 LLM 为主、以词典 (Du 等 2022; Loughran 与 McDonald 2011) 与 BERT 并行"的三角化测量策略, 使主测度既有语义捕捉力又有可复现的旁证。

作为 canonical, 本列与家族内所有变体的关系是"母测度对稳健性梯子"的关系: 加权口径 (vw、mw、hw)、文本轨道 (ctx、ss)、注意力衰减阈值 (hw 四档)、创新属性 (实质象征、技术应用) 与统计变换 (z 值、一阶滞后、组内标准差) 诸列, 各自恰好识别、并排陈列、互为稳健性不分主次, 共同证明主结论不被任何单一聚合口径所驱动。铁律是这些并排轨道严禁混进同一个过度识别的 Hansen J 检验; 真正的跨模型族错误率控制走根级 rwolf 模板 (Table A12), 其理论依据是 Romano 与 Wolf (2005)。在数值层面, 全列锚定在提示词 v8 字节冻结加 LLM 缓存零 miss 的离线复现约束之下, 更换模型属于受控的全量重生, 且必须在手稿中披露厂商与维度变更的副作用。

就取值解读而言, 本主测度数值越接近正一, 表示这一年媒体对该银行金融科技活动整体口碑越好; 越接近负一口碑越差; 接近零表示中性或褒贬相抵。作为两篇论文共用的正文级主处理变量, 它在数值确定性上锚定于提示词版本八的字节级冻结缓存、温度零解码与固定随机种子, 在三轨缓存零 miss 时可离线零成本逐位复现; 任何更换情感模型或改写提示词的操作都属受控全量重生, 必须先通过审批门并在手稿中如实披露厂商与维度变更带来的数值副作用。在实证使用中, 它既是回归方程里被反复检验的核心自变量, 也是全家族数十条稳健性轨共同环绕的母测度; 它与词典法六部词典的语调列、三个 BERT 模型的净语调与概率分布列彼此互为跨方法稳健性验证, 但三法之间以及本家族内部的各口径之间都严禁被并入同一个过度识别的 Hansen J 检验, 这一纪律与三轨文本、co-primary 双轨嵌入、政治词权重三档所遵循的完全一致, 是全项目测量稳健性设计的统一底座, 其理论根据可追溯至 Romano 与 Wolf (2005) 关于逐步多重检验的经典处理。
