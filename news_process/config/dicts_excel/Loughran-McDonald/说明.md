# Loughran-McDonald 中文金融情感词典 — 构建·审计·去重·最小词元 全流程说明

> 适用对象：中国银行业本土化金融情感词典，用于对中国新闻媒体的商业银行报道做词频统计与大数据文本情感分析。
> 文档日期：2026-06-16。本文件是整套交付物的权威说明（流程 / 规则 / 文件清单 / 统计 / 复现）。

---

## 0. 一句话总览（大白话）

把 Loughran-McDonald 英文金融词表里**带情感标签的 3,900 个词**逐词翻译成中文（含主译词、近义词、情感分类、媒体例句），再用 325 个 AI 分三轮互相挑错、互相否决做了顶刊级审计，最后压成两种"查词频用"的清单：**去重表**（删掉重复中文词）和**最小词元表**（在去重之外再删掉"内部已含更短词"的长词、并踢掉单字）。所有文件都在本目录下。

## 3. 词典构建流程

### 3.1 翻译（两道工序）
3,900 词按字母序分 65 批（每批 60 词，**同词根屈折变体留在同批**以保证词族内一致）。每批两道独立工序：

1. **翻译**：资深财经翻译给出金融中文主译词、2–5 个近义词、媒体语境示例。
2. **对抗校验**：独立质检员逐词复核并修正，只对确认问题落地。

### 3.2 五条翻译规则（贯穿翻译与全部审计）

| # | 规则 | 要点 |
|---|---|---|
| R1 | **金融专业性** | 只保留金融义，舍弃普通义。例：Impairment=减值、Yield=收益率、Default=违约、Provision=拨备、Security=证券、Interest=利息。 |
| R2 | **新闻媒体属性** | 近义词须为中国官方财经媒体（新华社、四大证券报）规范书面词；严禁口语 / 网络词 / 生僻字 / 生造词。 |
| R3 | **词性一致** | 主译词与近义词词性须与英文原词金融常用词性一致；同词根屈折变体（-ED/-ING/-MENT/-S）词族内统一。 |
| R4 | **排他性去重** | 近义词之间有细微语义区分以扩大匹配面，但绝不偏离原始情感色彩。 |
| R5 | **情感锚定** | 主译词与每个近义词都须落在该词 LM 情感类别的方向内。 |

> 主译词字段字节级遵循上述规则；情感分类（label）始终取自源词典，不改动。

## 4. 顶刊级多智能体审计（4 阶段 / 3 轮独立 / 325 个 agent / ~22M tokens）

### 4.1 Phase 0 — 确定性结构基线（Python 精确校验）
不依赖 AI 判断，逐项硬校验：3,900 覆盖 1:1、词形 / 标签逐字匹配、近义词 2–5 互异且不含主译词、无空字段 / 乱码 / 控制符、八类别计数与源词典精确一致、主表与 A/B 可复算与平价。**结果：0 FAIL**。

### 4.2 Phase 1–2 — 语义审计（审稿人 → 独立终审长）
每批两道独立工序：**对抗审稿人**（假定有错，逐词攻 R1–R5）→ **独立终审长**（剔除误报 + 补查遗漏，只对确认的 P0/P1 落地）。
- 原始发现 388（P0=3 · P1=202 · P2=183）；独立确认 260（含 3 项 P0 硬错误）。

### 4.3 Phase 3 — 第三轮独立裁定（怀疑论裁判）
65 个裁判对全部 365 处修正逐项判 KEEP / REVERT（对修改保持怀疑，不默认改后更优）。
- **308 KEEP / 57 REVERT**：拦下审计自身引入的退化（如 ACCRUES 孳息→孳生 误改、BAD 丢"坏账"、CONTRACTIBLE 漂成物理义、CONCEDE 让步义→刑侦"招认"、HEREAFTER/INDEFEASIBLE 法律义漂移）。

### 4.4 主控终裁
裁判 KEEP 但主控复核后 override 5 字段 + 修 2 处结构冲突：CONTEMPT 回"藐视法庭"法律义、JUSTIFIABLE 去注入的"自称"、UNTO 清理英文残留、BENEFICIALLY/UNFAVORABLE 结构修复。

### 4.5 最终
净保留改进 **207 词条**；重跑结构基线 **0 FAIL**；八类别标签与源词典逐类精确一致。

## 5. 去重规则（表 A / 表 B）

> 目的：把逐词词典"拍扁"成可直接做词频匹配的去重清单。

- **表 A（主译词去重）**：把 3,900 个**主译词**按中文字符串去重 → 2,150 个唯一词。
- **表 B（主译词+近义词去重）**：把 3,900 主译词与全部近义词摊平成独立匹配项后去重 → 8,361 个唯一词（撒网更大，能匹配更多新闻说法）。
- **英文原词列**：聚合所有映射到该中文词的英文源词（分号分隔）。
- **情感分类列**：取这些源词类别的**并集**（如「消极、诉讼」；诉讼是主题类、非极性，与消极不冲突）。
- **排序与 ID**：按最小源 ID（≈字母序）排，重新顺序编号 1…N。

### 5.1 极性冲突（保留，按用户选择）
去重后有少量中文词同时落在「消极」和「积极」（表 A 1 个、表 B 16 个），因它们当了正反两类词的共同近义词（如 大幅 / 显著 / 化解 / 颠覆）。**按用户决策，以并集标签保留**，由下游计分自裁。完整溯源见 `_work/`。

## 6. 最小词元规则（在去重之上再约简）

> 目的：进一步去掉"冗余长词"，只保留不可再缩的最小匹配单元，避免长短词重复计数。

### 6.1 口径（用户选定）
- **全局最小词元**：一个词 t 若其内部含有列表中**另一个 ≥2 字**的词 s（连续子串），则删 t 留 s。
  - 例：删「不利的 / 不利地 / 不利于」，留最小词「**不利**」；删「上诉中 / 上诉人」，留「**上诉**」。
  - "全局" = 不分情感类别做约简（用户已确认接受跨类别约简）。
- **排除全部单字词元**：长度=1 的词（其 / 兹 / 将 / 应 / 约 / 近 / 需 / 须）**既不进入最小词元表、也不去吸收长词**。
  - 原因：单字几乎都是功能词 / 超高频字，作为匹配词会大量误命中并跨义坍缩（「约」在 大约 / 约会 / 节约 中泛滥；且会错误吃掉 缔约 / 违约 / 约束）。
  - 因单字不吸收，**缔约 / 违约 / 约束** 等正经词完整保留。

### 6.2 形式定义
保留集 = { t ∈ 去重表 : len(t) ≥ 2，且 t 的任何长度 ≥2 的真子串都不是表中的词 }。

### 6.3 校验
保留词 len<2 = 0；非最小（仍含 ≥2 字子词）= 0；重复 = 0；越界（非原表词）= 0。

## 9. 已知限制与注意事项

1. **极性冲突词（16+1）**：表 B/A 中以并集标签「消极、积极」保留，词频情感计分时会正负双计，建议下游对这 17 个词单独处理（清单见审计报告 / `_work/`）。
2. **最小词元的跨情感坍缩**：按"全局"口径，若长词因含一个**不同情感**的更短词被删，其表面形将由该更短词匹配计分。如需按情感隔离，可改出"同类内最小"版本（同类内约简：表 A→1,363 / 表 B→4,025）。
3. **银行财务数据**：本词典仅为文本侧资产；财务面板数据为后续接入项，不影响词典使用。
4. **匹配实现建议**：词频匹配建议用 Aho-Corasick 多模式匹配；最小词元表已规避单字误命中，但仍建议对高频通用词做语境校验。

## 11. 大白话总结

- **第一步 翻译**：3,900 个带情感的英文金融词，逐个翻成中文，每个给一个最准的译词 + 几个财经媒体常用近义词 + 一句新闻例句 + 情感标签。
- **第二步 审计**：325 个 AI 分三轮互相挑错、互相否决，专门有一轮"怀疑派"去查"前面改得对不对"，拦下了 57 处越改越糟的，机器又精确体检全绿，3,900 词一个不差。
- **第三步 去重**：把重复的中文词合并，得到表 A（只主译词，2,150）和表 B（主译词+近义词，8,361）。
- **第四步 最小词元**：再删掉"里头已含更短词"的长词、踢掉单个字，得到表 A（1,290）和表 B（3,601），可直接拿去数新闻词频。
- 所有结果都在本目录，过程脚本和备份都在 `_work/`，随时能复验。
