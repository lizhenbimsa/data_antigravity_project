## 2. 各层发现与处置

### 2.1 L1 确定性硬核查（独立验证器 `audit_full.py`，0 缺陷）
用全新实现复核（**不复用** `build.py` 任何函数，以揪 build 自身潜在 bug）：覆盖率、最小词元正确性、纯 CJK、去重、跨文件(JSON/MD/xlsx)逐词相等、类别归属正反一致、overlay 落地、回归。**全部 0 缺陷**。
- **新发现并处置（顶刊级关键点）**：扩展后做全局最小词元约简时，**567 个原始种子被新增更短同义词吸收**而退出最小表，其中 **124 例为"跨类别不兼容吸收"**（吸收词带不同情感类别 → 该原词表面形会被算成另一情感）。这是全局最小词元在扩展后放大的"跨情感坍缩"（原《说明.md》§9.2 已记载、原方法学留有"同类内最小"备选）。
- **处置**：新增并列产出**情感安全"同类内最小词元"变体**（仅被共享≥1情感类别的更短词吸收，**杜绝跨情感坍缩**，7,248 词），供情感计分重视极性纯净度时采用；全局版（6,596）保留以与原交付物口径一致。两版均交付，用户按需取用。

### 2.2 L2 对抗复评（226 确认删除）
独立第二 referee 重审全部当前保留近义词，标记 412 处；双票确认后 **226 处确认删除**（95 驳回、92 分歧保守保留、0 漏票）。确认删除分布：V2 非金融义 107、V1 极性 97、V5 冗余套壳 15、V3 媒体不规范 7。删除样例（均为已从交付物移除的边）：`倏然`(文学体, V3)、`突发态势`(套壳, V5)、`默许`(偏离极性, V1)。
> ⚠ 说明：L2 删除是**针对具体"种子→近义词"边**的精确移除；某些被删词若同时是其它种子的合理近义词或本身是种子，仍会经那条边保留在去重表中（如 `核实/查证` 锚定真实 LM 种子 ATTEST/INVESTIGATE，故整体保留）——这与"0 漏票"不矛盾（漏票指未投票，非未删词）。

### 2.3 L3 专项深审（21 确认 / 308 驳回 — 防过删的胜利）
跨来源类别合理性 + 多类别一致性 + 高频词深查共提 329 删除提议。经**方法学精确化双票确认**（明确告知"多类别=并集语义，不要求同时满足所有类别；仅极性相反/非金融/不规范/词性错/纯冗余才删"），**仅 21 确认删除，308 驳回**。这印证：L3 多类别审计的"须满足全部类别"前提过严，若盲目采纳将**误删 308 个合规词**（违反 R4）。双票确认机制成功拦截了这次过度删除。
- 极性冲突 68 个**全判"正反两用"**（与前轮一致），按既定并集方法学保留。

### 2.4 L4 完整性批判（顶刊级，见 §4 全文）
- **真遗漏**：26 个银行危机/监管处置场景词（挤兑/暴雷/逃废债/立案调查/警示函/责令改正…），属**种子级**缺口（LM 英文原典无这些中国本土新词）。

## 4. 完整性批判全文（顶刊审稿人意见 — 论文披露清单）

> 以下为 L4 完整性批判审稿人的原始意见，**作为 manuscript 必披露的方法学限制**保留。多数为 **LM 框架 + 原词典固有特性**（非本轮扩展引入），不应靠擅改原种子类别"假装修复"。

**4.1 类别覆盖与构念效度**
- **强情态被极性形容词污染**：`一流/最优/最佳/顶尖/领先` 等是 positive 优越性形容词（**源自原词典强情态种子**），非 LM 意义的确定性情态助动词（shall/will/must）。会使强情态计数与 positive 共线，削弱 modal-tone 测度独立性。建议论文将强情态构念对齐 LM，或剥离极性形容词后做稳健性。
- **约束性混入纯条件副词**：`依赖/依据/取决于/视情况而定` 同时出现在弱情态/不确定/约束性，稀释 constraining（LM 原义=限制公司行动自由度 covenant/require/mandate）。
- **复杂性退化为业务名词库**：complexity 类除"交易/组织结构名词"（合资企业/可转债/衍生工具/证券化）外，还**并入 COLLABORATE/ALLIANCE 系正向协作词**（协作/合作/携手/结盟，标积极+复杂性）与 **BANKRUPTCY/LAWSUIT 系负向/诉讼词**（破产/倒闭/侵占/诉讼/控告），均**源自原始种子**（非本轮引入）。故 complexity 计数与极性类、诉讼类共线更严重，偏离 LM 原义（会计法律结构晦涩度）；建议论文披露 complexity 与各极性/诉讼类的两两 Jaccard。
- **litigious 类含情态义务词**（第5轮发现）：法律语域义务词 `应当/必须/理应/务必`（LM litigious 含 shall/must/require 法律义务语言）在 litigious 内**正当成员**；但纯频率/一贯性副词（`一贯/历来/始终/素来`，作诉讼种子 `向来` 的近义）若挂诉讼则属污染——第5轮已删（连同 false-friend `纾困→扶困` 共 5 条边，见 §9）。

**4.2 极性方向性疑点（测度效度，须敏感性分析）**
- **会计中性程序词计入消极**：`减值/拨备/计提/核销/敞口`（**原词典 LM 映射所致**）在银行常规披露中属中性程序词，高频出现会**系统性高估银行负面语调**，对 H1（媒体负面）形成虚假支持。**强烈建议**：剔除会计程序词子集后做主结果稳健性检验。
- **`审慎/谨慎`同列消极**（`稳健` 实为积极/不确定，不在消极）：监管语境"审慎经营"是正面合规信号，`审慎/谨慎` 归消极会把正面合规新闻误判为负面。
- **`处置`并集消极+积极**：银行"风险处置/不良处置"多为中性程序词。
- **会计程序词的 false-friend**（第5轮发现）：`施行`(实施/生效, 中性) 系**原始种子**锚定 LM PERPETRATE(负)/PROMULGATE(诉讼)；`独占` 系**原始积极种子**（垄断义负极性由近义合并带入）。均为原词典/LM 框架固有，**如实披露、不擅改原种子类别**。

**4.3 银行场景覆盖缺口（最严重，§5 给出修复建议）**
- 危机词整簇缺失：暴雷/挤兑/踩雷/资金链断裂/刚兑/逃废债/断供/抽贷/压贷/资产质量恶化/息差收窄/风险出清/高风险机构。
- 监管处置/反腐分级词稀疏：警示函/监管函/责令改正/限期整改/停业整顿/市场禁入/被查/落马/立案调查。
- 资本补充/纾困中性偏正向词缺失：补血/输血/增资扩股/化险/盘活/清收。

**4.4 方法学风险（须披露）**
1. **种子可达闭包封顶**：词典覆盖被初始种子集封顶；须报告对随机抽取负面银行新闻的人工召回率/漏检率。
2. **一词多类计数共线**：大量词同属消极/约束性/不确定/诉讼；下游各类独立计数同进回归会机械共线，须披露多类成员清单 + 两两 Jaccard 重叠 + 是否去权。
3. **会计程序词极性污染**（见 4.2）：须做剔除稳健性。
4. **三个非极性类目构念效度**：须报告类别间相关矩阵 + 与英文 LM 类目的 translation/construct validity。
5. **复合词分词命中**：含 ≥4 字复合词，jieba 裸切会切碎漏匹配（本项目已知问题）；须披露采用 AC 自动机整词匹配并报告复合词命中率。
6. **派生—循环依赖**：词典自项目自身派生 + LLM 扩展；须披露 prompt/温度/去重规则，并与外部独立中文金融词典（Jiang 等 / CFSD）报告重叠率与 kappa 作外部效度。
7. **极性强度未分级**：二元收录使"暴雷"与"下滑"同计一个负面命中；若宣称测度语调强度须说明加权。
8. **激活前受控重生 golden**：候选并入生产会改全部 `*_w`/词典轨情感列与 golden，须在确定性环境（`PYTHONHASHSEED=0`+线程钉死）受控重生并做激活前后主结果对照披露。
