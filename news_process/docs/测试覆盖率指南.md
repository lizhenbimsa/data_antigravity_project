## 本地运行

### 生成覆盖率报告

```bash
# 运行测试并生成覆盖率报告
pytest

# 或者显式指定覆盖率选项
pytest --cov=news_process --cov-report=html --cov-report=term-missing
```

### 查看报告

```bash
# HTML 报告会生成在 htmlcov/ 目录
# 在浏览器中打开
open htmlcov/index.html  # macOS
start htmlcov/index.html  # Windows
xdg-open htmlcov/index.html  # Linux
```

## CI 集成

CI 流水线会自动：
1. 运行测试并生成覆盖率报告
2. 上传覆盖率数据到 Codecov（仅 Python 3.10）
3. 在 PR 中显示覆盖率变化

## 配置说明

### pyproject.toml

```toml
[tool.pytest.ini_options]
addopts = "-q --cov=news_process --cov-report=term-missing --cov-report=html"

[tool.coverage.run]
source = ["news_process"]
omit = [
    "*/tests/*",
    "*/test_*.py",
    "*/__pycache__/*",
    "*/site-packages/*",
]

[tool.coverage.report]
exclude_lines = [
    "pragma: no cover",
    "def __repr__",
    "raise AssertionError",
    "raise NotImplementedError",
    "if __name__ == .__main__.:",
    "if TYPE_CHECKING:",
    "@abstractmethod",
]
```

### 排除特定代码

在代码中添加 `# pragma: no cover` 注释来排除特定行：

```python
def debug_only_function():  # pragma: no cover
    """仅用于调试的函数"""
    pass
```

## 覆盖率目标

当前项目覆盖率目标：
- **最低要求**: 70%
- **推荐目标**: 80%
- **理想目标**: 90%

## 提升覆盖率的建议

1. **识别未覆盖代码**：查看 HTML 报告中的红色高亮部分
2. **添加单元测试**：为未覆盖的函数和类添加测试
3. **添加边界测试**：测试异常情况和边界条件
4. **重构复杂函数**：将复杂函数拆分为更小的可测试单元

## 注意事项

- 覆盖率不是唯一的质量指标，高覆盖率不等于高质量测试
- 关注测试的有效性，而不仅仅是覆盖率数字
- 某些代码（如调试工具、抽象方法）可以合理地排除在覆盖率之外
