1.2 核心设计语言¶

(a) 双轨 _full / _ctx（v3.2.0 BREAKING）¶

  • _full = 整篇新闻文本作为 LLM/词典/BERT 的输入；
  • _ctx = 仅取目标银行实体的前后窗口（Hassan et al. 2019 QJE entity-proximity 框架）；
  • 两轨独立判定，不是 _ctx 由 _full 后处理而来。Prompt v8 在 stage 21 各跑一次。

(b) 三轨 _full / _ctx / _title¶

某些指标（特别是 LLM 投票、词典、BERT 系列）还有 _title 第三轨（只看标题）。

(c) 创新属性三维框架¶

维度 0 = baseline 1 = 对照 锚定文献
innovation_locus 底层技术 应用场景 Gomber, Kauffman, Parker, Weber (2018, JMIS)
innovation_substantiveness 实质性 象征性 Westphal & Zajac (1998, ASQ); Bingler et al. (2022, FRL)
innovation_collab_mode 自主研发 外部协同 Chesbrough (2003) Open Innovation; Laursen & Salter (2006, SMJ)

编码方向约定：所有三维分类变量统一 0 = baseline / 1 = 对照，这是项目的"洗稿率"框架——positive_class 始终对应对照类（象征性 / 应用场景 / 外部协同），与 prob_score 列的 P(positive) 编码方向严格对齐。详见 stata_export.py:42-93。

(e) 三套加权方式¶

加权 后缀 权重源 学术依据
Value-weighted _vw / _w mention_density 单篇提及密度 Hassan et al. (2019, QJE) entity-proximity

每个 tone 主指标都派生 3 套加权版（mean、sum、vw、mw、hw），构成"3 方法 × 3 加权 × 3 轨"的庞大笛卡尔。

1.4 缺失值语义¶

  • NaN → Stata .（pandas backend）或 . / .a / .b（pyreadstat backend，extended missing）；
  • d4_data_quality_flag = 'insufficient' → ctx coverage 不足，Stata 端 keep if d4_data_quality_flag == "ok"；
  • v6/F3 关键修复：所有"无新闻 bank-year"列保留 NaN而非填 0，避免 TWFE 制造伪零质心污染系数（见 runner.py:1041-1043 Allison 2001 + Heckman 1979 论证）；
  • 计数类列（n_articles* / *_sum / *_count / sum_media_authority_weight）在 balance_panel() 中 fillna 为 0；比率类（*_frac / *_ratio / *_tone / concern_score / etc.）保留 NaN。

5. D 媒体加权三套体系¶

整体说明：本项目同时维护三套媒体权重，分别用于不同的稳健性维度。这是 v3.6.1 PR #6 后的状态——原 media_authority_weight（连续）保留为 main，新增 media_authority_weight_tier（3 级 tier）作 sensitivity，不替换原列。

5.1 原始连续权重（Holzman et al. 2023, TAR）¶

变量 公式 含义
media_authority_weight raw_weight / mean(raw_weight)（10–100 评分归一化） 单篇连续媒体权威度，main spec 用
sum_media_authority_weight bank-year 加权和 MW 加权聚合分母

5.2 v3.6.1 媒体 3 级 tier（Solomon 2012 RFS + Engelberg-Parsons 2011 JF）¶

基于 config/media_classification.json（central 171 / financial 15 / comprehensive 27）。互斥优先级：financial > comprehensive > central > other。权重 dict：{'central': 2.5, 'financial': 2.0, 'comprehensive': 1.5, 'other': 1.0}。

变量 取值 含义
media_authority_weight_tier float ∈ 3 级 tier 离散权重（Table A8 sensitivity）
media_tier_label str ∈ {central, financial, comprehensive, other} tier 字符串标签

5.3 媒体权威性档位（Bartik IV 4 用）¶

基于 media_weights.json 评分高低划档：high ≥ 80 / mid ≥ 60 / low。仅在 runner.py::compute_bartik_iv_fintech(..., 'mauth') 中作为 share，不直接进 panel 列，但派生 bartik_mauth_iv_* 系列 IV。

6. E 注意力指数 (Stage 24/42)¶

整体说明：基于 Da, Engelberg & Gao (2011, JF) Direct Attention + Fang & Peress (2009, JF) 媒体覆盖框架，指数化的"该年市场对该银行金融科技的关注度"，含指数距离衰减（地理/时间）。

变量 公式 范围 来源

注：这三个 parquet 是 panel runner 的副产品，可用于 province-year / city-year 维度的注意力面板分析（论文 P2 attention 主线）。

7. F LLM 投票情感（双轨主指标）¶

整体说明：3 个 LLM（GPT-5.4-nano / Gemini-3.1-1.1.1 / DeepSeek-V4）独立标注，多数投票产出 sentiment。_full / _ctx / _title 各跑一次 prompt，独立判定（v3.2.0 BREAKING）。所有 LLM 原始响应通过 DC3 LLM archive 模块 持久化为 append-only JSONL + SHA-256 manifest，满足顶刊 reproducibility 硬约束。

锚定：Cao et al. (2025 WP); Shapiro, Sudhof & Wilson (2022, JoE)；Törnberg (2024, arXiv:2307.13106)。

7.4 内在含义解读（深度增强）¶

度量什么：每条 LLM tone 列度量的是"该 bank-year 内媒体语调的方向性强度"，是情感信息含量（informational tone）而非简单的好坏评价。

为什么三模型投票而非单模型： - 单模型存在系统性偏差（GPT 系列偏中性、Gemini 偏正面、DeepSeek 偏波动）。三模型多数投票把"系统性偏差 + 真实信号"中的前者抵消（Cao et al. 2025 WP）； - llm_vote_tone 用 is_positive - is_negative / total 归一化后 ∈ [-1, 1]，可与 Tetlock 2007 (JF) 的 pessimism index 框架直接对话； - v6/F2 修复后，verified=False / undefined / call_failure 的 NaN 严格区分于"真实中性"——这避免了 Loughran-McDonald (2011 JF §IV) 警告的"中性坍塌偏差"。

核心三列的关系： | 列 | 信号类型 | 经济学解读 | |---|---|---| | llm_vote_tone_{track} | 离散投票均值 ∈ [-1, 1] | 篇章级方向多数；适合做事件研究 OLS 主表 | | llm_vote_cont_{track} | 离散 × 置信度（连续） | Shapiro-Sudhof-Wilson (2022, JoE) 信号质量加权；attenuation bias 校正 | | llm_prob_score_{track} | Logit-to-Score Bernoulli ∈ [0, 1] | Törnberg (2024) 最大熵映射；适合做 Logit / Probit 因变量 |

双轨 _full vs _ctx 的选择逻辑： - 主回归默认 _ctx（v3.6.0 G3 起 P1 paper main spec 即 llm_vote_tone_ctx）：实体邻近上下文规避了"该新闻提了银行但实际讲行业"的污染； - 稳健性用 _full：完整文本捕获更多语义，但可能稀释信号； - 两轨一致 → 强证据；分歧 → §43 disag 度量出现 → 论文需在 robustness 中讨论。

典型 Stata 用法（P1 main spec）：

xtset target_bank year
* Main spec (v3.6.0 G3 后)
reghdfe Y llm_vote_tone_ctx controls, absorb(target_bank year) cluster(bank_province)
* 稳健性：换 _full
reghdfe Y llm_vote_tone_full controls, absorb(target_bank year) cluster(bank_province)
* 测量误差校正（用 prob_score 作 IV）
ivreghdfe Y (llm_vote_tone_ctx = llm_prob_score_ctx) controls, absorb(target_bank year)

典型使用陷阱： - ⚠ 稀疏 bank-year：n_articles < 5 时 tone 估计噪音大，建议在主回归中过滤 if n_articles >= 5； - ⚠ 零中性混淆：v6/F2 前 is_neutral 会把 verification 失败也算成中性 → 旧 panel 的统计量需重跑； - ⚠ VW/HW/MW vs 等权：加权版本（§13-15）系数会更小（高权重篇章往往主流且温和），论文需在 robustness 表展示三种加权对比。

16.4 内在含义解读（深度增强 — 项目灵魂）¶

为什么是三维而非一维：传统金融文本研究只测 sentiment（好/坏），但中国银行金融科技战略选择有 3 个正交决策维度： 1. Locus = "做哪一层" → 底层技术（区块链 / AI 算法 / 云架构）vs 应用场景（信贷审批 / 客户服务 / 营销） 2. Substantiveness = "真做 vs 装做" → 实质性投入（自研 + 落地）vs 象征性宣示（PR 公告） 3. Collab mode = "自己做还是合作" → 自主研发 vs 外部协同（与 BigTech / 金融科技公司合作）

三维笛卡尔积 = 8 个战略 cell（§18 D2 分解）。洗稿率 = Pr(Substantiveness = 象征性 | 报道正面) 是项目核心 treatment。

为什么双轨独立： - _full 轨从全文判定 → 受"行业新闻借提银行名"污染（如"区块链火热，工行也在跟进"实际讲行业）； - _ctx 轨从实体前后窗口判定 → Hassan et al. (2019 QJE) entity-proximity，真正针对该银行； - 双轨独立 prompt（不是后处理）→ 让 ctx 轨可作 main spec（v3.6.0 G3 解锁）。

编码方向 0=baseline / 1=对照的统计意义： - 主回归 reghdfe Y D 中 D 是 binary，coefficient 解读为"对照类相对 baseline 类的边际效应"； - 1 = 对照 = "象征性 / 应用场景 / 外部协同" → 三者都是"较不实质"的方向； - tone_gap_sub_symb = 实质性 tone − 象征性 tone > 0 意味着实质性文章语调更正面——这是 W&Z (1998 ASQ) decoupling 框架的反向证据（论文常假设 < 0，即"洗稿文章 PR 修饰更夸张"）。

置信度列（§17 P）的用法： - category_confidence_{full,ctx} 是 LLM × keyword crossvalidation 杂交（+0.2 boost / ×0.5 penalty），是最严格的判定信心； - 论文常做 if category_confidence_ctx >= 0.7 的子样本 robustness； - avg_il/iss/icm_confidence_* 是纯 LLM verbalized confidence，更宽松。

典型论文 spec（P3 substantiveness main）：

* Main: 象征性比例对 outcome 的影响
reghdfe Y symb_frac_sc loss_controls, absorb(target_bank year) cluster(bank_province)

21.1 内在含义解读（深度增强 — 主回归 treatment 候选）¶

经济学直觉：tone gap 度量"同一银行同年内不同类别新闻之间的语调差异"。这是议题异质性（issue heterogeneity）信号，远比单一 tone 均值更精准。

3 个核心 gap 的论文用法：

Gap 名 度量什么 论文用作
tone_gap_tech_app 底层技术 vs 应用场景的语调差 Adner & Kapoor (2010 SMJ) 生态系统位点效应；P4 paper main
tone_gap_sub_symb_sc_ctx 实质性 vs 象征性的语调差（ctx 轨） 洗稿率核心指标；P3 paper main 与 P1 secondary
tone_gap_indep_collab_cm_ctx 自主 vs 协同的语调差 Chesbrough (2003) open innovation；P5 paper main

经济学符号预期： - tone_gap_sub_symb 常常 > 0（实质性文章语调更正）——这是 Westphal & Zajac (1998 ASQ) "decoupling 正向标签"的反向：实做的人也实说，洗稿的人话术更虚； - 若实证发现 tone_gap_sub_symb < 0 → 强 PR 主导市场 → 论文需要在 Discussion 节解释（典型 Bingler et al. 2022 FRL 的 cheap talk 情景）； - tone_gap_title_full > 0 → 标题党（标题更正面），是 SEC Form 10-K 文献的经典指标；

n_articles 门控的统计意义： - min(n_a, n_b) >= 5 是 compositional confound 防御。原理：当某子集仅有 1-2 篇时，子集均值受单篇极值主导（high variance）→ gap 估计 unbiased 但方差爆炸 → 错误结论； - 这个 gate 让稀疏 bank-year 自动 NaN drop，确保回归 SE 准确。

典型 Stata 用法（P3 main spec）：

* Main: 实质-象征 tone gap 对 outcome 的影响（ctx main）
reghdfe Y tone_gap_sub_symb_sc_ctx controls, absorb(target_bank year) cluster(bank_province)

* 稳健性: full 轨
reghdfe Y tone_gap_sub_symb controls, absorb(target_bank year)

* 稳健性: 提高门控
reghdfe Y tone_gap_sub_symb_sc_ctx controls if n_articles_sub_sc_ctx >= 10 & n_articles_symb_sc_ctx >= 10, ///
    absorb(target_bank year)

* 异质性: 国有 vs 非国有
reghdfe Y c.tone_gap_sub_symb_sc_ctx##i.is_soe controls, absorb(target_bank year)

常见使用陷阱： - ⚠ 样本量缺失：因 min ≥ 5 自动 NaN，论文报告时必须披露回归样本量远小于 panel 总行数（典型 4608 → ~1800-2400）； - ⚠ 方向解释错误：tone_gap_sub_symb > 0 不是"实质性更好"，而是"实质性文章语调相对更正"——这是信号 而非结果； - ⚠ 不要平均双轨：(tone_gap_sub_symb + tone_gap_sub_symb_sc_ctx) / 2 在统计上没有意义（两个独立估计的简单平均不是 MLE），论文应分别报告两套结果。

22.4 内在含义解读（项目核心概念：洗稿率）¶

洗稿率（Washing Ratio）定义：WR = #{正面 ∩ 象征性} / #{正面} = "正面新闻中有多大比例是象征性 PR"。

经济学直觉： - WR = 0 → 所有正面新闻都讲实质（理想）； - WR = 1 → 正面新闻全是 PR 洗稿（极端洗稿）； - 实际 panel 中 WR 通常 ∈ [0.15, 0.60]，分布右偏。

为什么用 4 way 计数： - pos_symb_count（洗稿信号正头）vs neg_sub_count（真问题暴露反头）——前者 → 洗稿率分子；后者 → "反向验证"（reverse-validation, Deephouse 2000 J Mgmt）防御 LLM 偏见； - washing_asymmetry = neg_sub_ratio − (1 − washing_ratio) 度量"正负两侧不对称"，> 0 → 实质性的语调更尖锐（与象征性的温和形成对比）。

10 种 washing ratio 变体的统计意义： - 方法 A（LLM 投票）→ main； - 方法 A2（3 个单模型）→ inter-rater reliability 稳健性； - 方法 D2（5 个单词典）→ method-source robustness； - 方法 E2（5 个 BERT）→ deep-model robustness； - 方法 F（高置信子样本）→ measurement-quality robustness； - 方法 G（情感偏移 tone_shift）→ continuous version (vs binary ratio)。

10 方法 × 2 轨 = 20+ 列让论文可以做 Romano-Wolf 多重检验校正后的"方法稳健性表"。

典型 Stata spec：

* P1/P3 paper Main: washing ratio (LLM 投票, ctx)
reghdfe Y washing_ratio_ctx controls, absorb(target_bank year) cluster(bank_province)

* Romano-Wolf 多重稳健性: 10 方法
rwolf reghdfe Y i.D controls, ///
    indepvars(washing_ratio washing_ratio_ctx washing_ratio_dict washing_ratio_bert ///
              washing_ratio_jiang_2021 washing_ratio_yao_2021 washing_ratio_hc) ///
    absorb(target_bank year) reps(1000) seed(42)

陷阱： - ⚠ 分母 0：当 bank-year 全无正面新闻时 pos_count = 0 → 分母为 0 → NaN（_safe_ratio 已处理），但论文样本量会缩小；可用 dummy_no_positive_news 控制； - ⚠ substantiveness 来自 full 轨：washing ratio 默认基于 innovation_substantiveness_full；ctx 版用 _sc 后缀的 4-way 计数（runner.py:496-528 派生 pos_symb_*_sc 系列）。

35.1 内在含义解读（第 7 篇 paper 主指标）¶

度量什么：Jha, Liu & Manela (2026 RFS) 的"finance benefit society 双极投影"。它不是一般情感（positive/negative），而是专门针对银行 fintech 是否改善经营效率这一特定语义维度的连续 score。

与一般 sentiment 的区别： - llm_vote_tone_ctx 度量"该文章对银行的整体态度好坏"（通用情感）； - benefit_mean_ctx 度量"该文章把 fintech 描述为对银行经营有利还是有害"（特定方向）； - 一篇可以 sentiment 正面（语气温和）但 benefit_mean 负面（讲 fintech 削弱了银行）—— 两者正交但互补。

双极锚点方法的几何直觉： 1. 准备 10 对正/负极锚点句子（如"金融科技提升经营效率" vs "金融科技降低经营效率"）； 2. 把锚点向量化 → 求差得到"利好经营"方向轴 p = mean(pos) − mean(neg)； 3. 每篇新闻向量化后投影到该轴上（cos(s_j, p) ∈ [-1, 1]）； 4. 这就实现了 Kozlowski-Taddy-Evans (2019 ASR) 的 "geometry of culture" —— 把语义维度变成可度量的几何方向。

4 列的关系： | 列 | 信号 | 论文用法 | |---|---|---| | benefit_mean_ctx | 投影均值，main treatment | 主回归因变量或 X | | benefit_std_ctx | 投影离散度 | 信号方差，用于 Garcia-Schmidt-Levine (2025) volatility 分析 | | benefit_pos_frac_ctx | 利好文章占比（discretized） | 二值化稳健性 | | benefit_neg_frac_ctx | 不利文章占比 | 反向验证 |

v6/F3 NaN 保留约定：早期版本对无 fintech 新闻 bank-year fillna(0) → TWFE 出现伪零质心；现统一保留 NaN，Stata 端 listwise drop（详见 §57 BD）。

37.9 内在含义解读（因果识别工具）¶

为什么需要 Bartik IV：媒体 tone 与银行 outcome 之间存在反向因果——业绩好的银行获得更多正面报道（reverse causality）。Bartik shift-share IV 用"行业层面冲击 × 银行基期特征"构造外生 instrument，识别 tone → outcome 的单向因果。

Goldsmith-Pinkham-Sorkin-Swift (2020 AER) 的外生性公理： - share 必须在 pre-treatment 期固定且独立于 outcome； - 这就是项目把 share 限定为 bank_type / bank_scale（pre-treatment 银行属性）+ media / mauth / geoprox（pre-treatment 媒体属性）的原因； - v6/F4 删除的 28 类 IV 是因为它们的 share 是post-treatment 编辑决策（文档长度 / 标题选择 / 媒体分类）→ 违反公理 → identification fail；

为什么基期 T0 = max(panel.year.min(), 2010)： - 2010 = 中国 fintech 萌芽前； - DCEP 数字人民币里程碑 = 2019 → 强制 T0 < 2019 防止 share 已在 post-treatment 区间。

Romano-Wolf 校正的统计含义： - 当 IV ≥ 6 套时，naive 单一 IV 的 p 值会因多重检验通胀； - Romano-Wolf step-down 校正后的 p 值才是"真正显著"——论文 main table 必须报告校正后； - Stata 实现：rwolf 包（ssc install rwolf）。

Rotemberg 权重诊断的解读： - α_k > 0 大且集中 → 几个 share 维度主导 IV → 论文需在 robustness 表展示"剔除大权重维度后 IV 仍 work"； - α_k < 0 → misspecification 警告（Goldsmith-Pinkham 2020 §5.2）→ 该 share 维度违反正交性 → 论文必须删除该维度或解释； - HHI(|α|) < 0.25 → 分散 → IV 健康； - HHI(|α|) ≥ 0.25 → 集中 → Borusyak-Hull-Jaravel (2022 RES) shift-share 解释下需慎用。

典型 Stata spec（P2 attention IV）：

* First stage

* Second stage with Romano-Wolf
ivreghdfe Y (ft_attn_yr = bartik_type_iv_full bartik_scale_iv_full bartik_fintech_lf_iv_full ///
    bartik_media_iv_full bartik_mauth_iv_full bartik_geoprox_iv_full) controls, ///
    absorb(target_bank year) cluster(bank_province)
* 报 Kleibergen-Paap rk LM + Sanderson-Windmeijer F + Hansen J

* Romano-Wolf 校正 (6 IV)
rwolf ivreghdfe Y (ft_attn_yr = $iv_set) controls, ///
    indepvars(ft_attn_yr) reps(1000) seed(42)

* Rotemberg 分解
ssc install bartik_weight

38.5 内在含义解读（因果识别 staggered DID）¶

为什么需要 staggered DID 而非传统 DID： - DCEP 数字人民币试点 2020-2024 分 4 批（深圳/苏州/北京等），不同银行省份在不同时间获得 treatment； - 传统 DID（pre-post × treated-control）会用"晚期 treated"作为"早期 treated"的 control → bias（Goodman-Bacon 2021 JOE）； - staggered DID + Callaway-Sant'Anna (2021 JOE) ATT(g, t) → 正确估计。

为什么用 lead/lag dummy 而非线性 rel_year： - 线性 rel_year 假设效应随时间线性变化，约束过强； - 6 个 lead/lag dummy 让效应"自由变化"，event study plot 可视化平行趋势 + 动态效应； - lead4plus / lag4plus endpoint binning 防止极端 event-time 样本太少导致系数波动。

关键平行趋势检验： - lead2 / lead3 / lead4plus 系数应不显著 → 平行趋势成立； - lag0 系数 = 政策当年效应；lag1 = 一年后效应； - 若 lead3 显著 → pre-trend 存在 → DID 估计有偏。

{prefix}_treated × controls 异质性扩展： - dcep_treated × is_soe → 国有银行在 DCEP 下是否被赋予不同角色（国有大行通常是试点主力）； - dcep_post × digital_frontier = §39.AL §39.2 的 DDD dcep_ddd_digfront。

* 手动 event-study + endpoint binning

    dcep_lead4plus dcep_lag4plus controls, ///
    absorb(target_bank year) cluster(bank_province)

* DDD: DCEP × 数字前沿（runner.py:913-926 预算）

    dcep_treated#dcep_post dcep_treated#digital_frontier dcep_post#digital_frontier ///
    controls, absorb(target_bank year)

* 平行趋势 placebo (§55 BB)
reghdfe Y dcep_placebo2_did controls, absorb(target_bank year) cluster(bank_province)
* dcep_placebo2_did 应不显著

54.4 内在含义解读（第 10/11 篇 paper outcome）¶

为什么是这 4 个 outcome 而非 ROA： - 论文核心问题是"fintech 报道如何影响银行风险承担"——ROA 是 outcome 但不是 risk 直接度量； - z_score（Roy 1952 + Berger-Klapper-Turk-Ariss 2009 JFS）：破产距离，越高越安全 → 风险承担↓； - npl_formation_rate（Δ NPL / loans）：流量指标，捕捉新增风险（vs npl_ratio 存量）； - rwa_to_ta_ratio：风险加权资产 / 总资产 = 资产组合"密度"——监管视角的风险度量； - loan_loss_provision_discretion（Beatty & Liao 2014 JAE）：LLP 中的会计 discretion 部分，捕捉"管理层主动调节准备金"行为。

4 个 outcome 的因果链解读：

fintech tone (Treatment) 
  → 银行战略选择（自主 vs 协同）
    → 风险承担行为
      → z_score ↑↓ (整体风险)
      → npl_formation_rate ↑↓ (信贷扩张质量)
      → rwa_to_ta_ratio ↑↓ (资产风险密度)
      → llp_discretion ↑↓ (盈余管理)

implicit_guarantee_tier 异质性维度： - Acharya-Anginer-Warburton (2016 RFS) 框架：政府隐性担保高的银行（big6 / dsib）→ moral hazard → 风险承担更激进； - 论文常做 c.benefit_mean_ctx##i.implicit_guarantee_tier 异质性分析。

典型 Stata spec（第 10 paper main）：

* Main: cross-media disagreement 对风险承担
foreach y in z_score npl_formation_rate rwa_to_ta_ratio loan_loss_provision_discretion {
    reghdfe `y' cross_outlet_tone_variance_full controls, ///
        absorb(target_bank year) cluster(bank_province)
}

* 异质性: 隐性担保层级
reghdfe z_score c.cross_outlet_tone_variance_full##i.implicit_guarantee_tier controls, ///
    absorb(target_bank year)

* LLP discretion: BW 2012 残差化 + tone 影响
* Step 1: 残差化（Stata 端做）
reghdfe loan_loss_provision_discretion L.npl_ratio L.loan_growth, absorb(target_bank year) resid
predict llp_resid, residual
* Step 2: tone → llp_resid
reghdfe llp_resid benefit_mean_ctx controls, absorb(target_bank year)

陷阱： - ⚠ 数据来源 fallback 三级：α (Wind) → β (银保监 PDF) → γ (估算)；writeoffs_imputed = 1 标识 imputation 行 → 论文应在 Robustness 中报告排除这些行的结果； - ⚠ 季度 → 年度聚合规则：stock 类用最后可得季度（v3.7.0 M8 修复 Q4 缺失即全年丢失的 bug），intensive 类用年均，flow 类用年累——这意味着 z_score 是年均 ROA算出的，与季度高频版不同； - ⚠ z_score 不是 zscore：命名差异！老脚本可能引用错误名导致 KeyError。
