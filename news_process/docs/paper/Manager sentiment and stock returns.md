# 基于《Manager sentiment and stock returns》的项目诊断与重构执行计划

=========================================
第一部分：基于参考论文的项目分析与诊断报告

1. 范式映射与盲区诊断：
参考论文（Jiang et al., 2018）的核心机制在于揭示了“管理者情感（Manager Sentiment）”作为一种反向预测指标（Contrarian Predictor）的作用：管理层在特定财务文本中表现出的主观过度乐观的语调，往往预示着随后的过度投资（Overinvestment）和显著为负的未来股票回报（Return Reversals）。
**盲区诊断**：当前项目（`news_process`）底层逻辑是在捕捉泛化的“媒体情感（Media Sentiment）”，却忽略了财经新闻文本在信息源泉上的底层异质性——很多金融科技新闻实质上是银行的公关通稿（PR）或是大量引述了银行最高管理层的乐观发言。项目当前粗粒度地将“管理者的主观包装（过度乐观预期）”与“第三方记者的客观/批判性报道”混为一谈。如果不把隐藏在泛化新闻里的“管理者情感”剥离出来，项目将极大地错失捕捉由管理层过度自信和认知偏差带来的金融科技“过度投资”与“预期差”爆雷风险。这是当前我们在研究视角和特征变量分离上的重大落差。

2. 实质性改进项（宁缺毋滥）：
- **改进 A：基于 LLM 的新闻情感异质性分解（管理者情感 vs. 独立媒体情感）** 
  - **标明论文依据**：Jiang et al. (2018) Table 3 & Introduction 强调管理者情感有别于外部投资者情感，且管理层的认知偏差（如盲目乐观）会传导至公开披露的文本语调中，具有独立于基本面和大众情绪的独特预测价值。
  - **阐述预期的边际贡献**：无需重新费力收集 10-K/Q 的语料，直接拓展当前流水线中 `21_tone_llms.py` 的大模型提示词工程（Prompt Engineering）。利用大模型的实体识别和观点源抽离能力，将原本单一的新闻情感分解为：`manager_sentiment`（引用的管理层或银行官方声明传递的情绪）与 `media_sentiment`（剥离官方表态后的记者独立情绪观点）。这一重构能彻底解决现有特征将公关稿与深度新闻混淆的内生性弊端，构建专门的新闻渠道“管理者过度预期的测度物”，用于检验其由于认知偏差导致的反向预测力（Contrarian Predictor效用）。
  
- **改进 B：引入盈余预期差与过度投资的传导机制检验（Expectation Error & Overinvestment）** 
  - **标明论文依据**：Jiang et al. (2018) Section 5.3 & 5.4 严格论证了现金流预期误差和过度投资渠道：管理者的高涨情绪有力地负向预测未来的总体盈余惊喜（Earnings Surprises），并伴随着前高后低的投资增长。
  - **阐述预期的边际贡献**：打破 `45_panel_export_main.py` 纯粹只看当年效应的验证模式，大幅引入前瞻预期差与结构错位的检验。围绕“事前新闻公关稿中管理者高昂情感 -> 事中银行进行非理性的金融科技过度投资（过高资本性IT支出） -> 事后惨不忍睹的收益水平与盈利惊喜（ROA/ROE负面突变）”重设理论逻辑。将单一面板重构为多周期的前瞻预测回归模型（Forecasting up to 1-3 years），让文章具备冲击顶级金融学主刊的动态微观实证纵深。

3. 冗余剥离：
- **强烈建议直接剔除 `22_tone_words.py`（词典法情感分析）及附属的 L&M/金融字典配置**。项目的最大护城河是有高精度的大模型思维链推理（CoT）验证。并且上述“改进 A”需要依赖对文本主语进行上下文溯源以及独立的情感脱水，这完全不是传统基于上下文无关、盲目计算（正向词频-负向词频）的 Loughran & McDonald 词袋模型所能支撑的任务。词典法由于混淆主语情绪已完全沦为毫无理论边际价值的“伪需求”，继续保留只会平白消耗算力、徒增流水线复杂度甚至干扰最后的核心判断。与之相关的辅助脚本字典扫描步骤也建议全面退役。

=========================================
第二部分：项目重构与优化执行计划书

1. 优先级排布：
- **速赢项（Quick Wins）**：清理并剔除过时且无法兼容多主语分解的词典法组件（抛弃传统 NLP 情感提取包袱），仅保留基于 API 聚合的稳健模型管线。
- **核心攻坚项**：重构 `21_tone_llms.py` 和 `config.yaml` 内的 JSON Prompt 结构设计，训练 LLM 正确且稳健地实现（官方/高管 vs 媒体/记者）多级情绪抽离；同时在 `45_panel_export_main.py` 的面板拼装层补强“盈利预期差（Earnings Surprises）”和“IT投资规模异动”两大核心因变量的跨期拼接计算。

2. 阶段化执行指令 (SOP)：

**阶段一（机制重塑与特征分解解析）：**
- **动作指令 1.1**：在 `config.yaml` 中更新 `prompt_template`，要求大模型在完成金融科技文本识别时，废弃原有的单极 `sentiment` 输出。强制输出为 JSON 双属性组：`manager_sentiment`（文本涵盖的被涉事银行官方或其管理层释放的情绪倾向，如无则标记 null）与 `media_sentiment`（文本作者抛开引语后对该主体的独立评价性情绪）。
- **动作指令 1.2**：修改 `21_tone_llms.py` 后置字典解析与对齐逻辑，将单一的情感特征拉平扩展成两个不同维度的语义倾向特征字段写入到 Parquet 文件中。
- **动作指令 1.3**：物理移除 `22_tone_words.py` 并在 `config.yaml` 层面将 `tone_words` 移出 `sentiment_analysis.enabled_methods`，彻底终止词典级的一切计算。

**阶段二（面板挂载模型重构与实证拼接）：**
- **动作指令 2.1**：在 `41_panel_encode_aggregate.py` 中，聚合升维计算，产出基于年份的面板字段变量 `Avg_Manager_Sentiment` 与 `Avg_Media_Sentiment`。
- **动作指令 2.2**：在 `45_panel_export_main.py` 面板整合环节接入新的数据字典构造计算——新增并计算出“分析师盈利预测偏误（Forecast Errors）”、“盈利意外冲击（Earnings Surprises）”以及“相对同业的异常科技投资占比增量”作为目标检验因子列。
- **动作指令 2.3**：设计赛马回归（Horse Race Regression）脚本指令：控制传统文本基准后，展开 T+1、T+2 的长窗口回归。主要验证 `Avg_Manager_Sentiment` 的估计系数是否为极端显著的负值（证明其为盲目乐观反向指标），而 `Avg_Media_Sentiment` 的估计系数是否能反映真实的正向传导。

**阶段三（文章故事拔高与结论重塑）：**
- **动作指令 3.1**：将科研成果输出物的故事包装基调从“媒体正向吹捧如何利好金融科技发酵”完全脱胎换骨，升格为更符合顶刊审美的高级博弈理论——“警惕数字浪潮下的海市蜃楼：银行金融科技新闻的深层解构证明了——媒体字里行间所透露出的管理层高涨的科技自负情绪，实则精准预示着未来资本错配、技术无效投入乱象及随后大幅爆雷的惨淡利润归宿”。 

3. 风险预案 (Plan B)：
- **致命卡点**：针对大量没有深度采访甚至短平快的豆腐块新闻，大模型极难区分是谁说的话。新闻语料中如果大量缺乏实质性的管理层直接引语（Manager Quotes），会导致新抽取的 `manager_sentiment` 列出现致命的大面积缺失值/稀疏分布（Sparse Data），引发最后年度面板跨期对齐后统计自由度不足，无法进行稳健的面板回归跑批。
- **替代方案 (Plan B)**：若尝试执行 LLM 实体观点抽离后证实数据稀疏度极高（失败率>50%）。则改为通过“原始新闻文体/发布版块类型”进行粗粒度的代理分配映射：利用之前提取的文章大类特征，强制打标——凡是来源板块标识为涵盖“企业通告”、“官方声明”、“公司动态”类体裁提取的情感近似视同为“全量管理者主导情感”，而版块标识定位于“深度调查”、“宏观经济评论”类体裁文章提取的情感被严格视同为“独立外部审视媒体情感”。利用分类树强制兜底降维规避信息提取丢失风险，确保回归的完整性。
