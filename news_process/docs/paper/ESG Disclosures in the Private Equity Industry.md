# 基于《ESG Disclosures in the Private Equity Industry》的项目分析与诊断报告

=========================================
第一部分：基于参考论文的项目分析与诊断报告

1. 范式映射与盲区诊断：
参考论文的核心机制是构建一个透明的词典匹配指标（ESG Ratio），即特定主题词频（ESG词汇）在文本总词汇数中的占比，以量化自愿披露的“相对强度”，并通过结合LLM（ChatGPT）的评估验证了这一指标的有效性（同时指出高频词段存在噪音并呈现边际效用递减）。
对照当前项目（新闻处理与金融科技/情感量化流水线），当前项目已具有先进的大语言模型（LLM）思维链（CoT）推理来进行复杂的二元定性与情感定级（`is_bank_fintech_news`）。
**盲区诊断**：当前项目在处理语义精准度上**优于**论文的纯词典法（已形成逻辑自洽与降噪），但当前项目过度聚焦于主题的“有/无”（二元识别），缺乏对信息密度的“相对披露强度”（Relative Information Density）的连续性量化。新闻总体长度作为一种内生的混淆因素，应当将其纳入测度，因为机构分配给特定话题的篇幅比重，是衡量其真实战略披露意愿的核心维度。

2. 实质性改进项（宁缺毋滥）：
- **改进 A：构建连续的相对披露比率指标（Relative Topic Disclosure Ratio）**
  -> **[标明论文依据]**：论文第3.2部分的核心变量 `ESG Ratio`（构建公式为：特定主题词汇数 / 总体网页有效词汇数），直接控制了文本长度膨胀。
  -> **[预期边际贡献/解决的内生性问题]**：当前项目的词典段（`config.yaml`中的 `tone_words` 等）侧重情感绝对计数。如果在流水线中构建“金融科技词汇占比”（`Fintech_Word_Ratio` = 金融科技专属词数 / 文章总词数），可将其作为强力控制变量，吸纳由于金融机构新闻通稿“长篇大论”带来的系统性篇幅干扰，有效验证 LLM 的二元判定结果。

- **改进 B：特征词典的精细化子维度拆解（Granular Sub-Topic Decomposition）**
  -> **[标明论文依据]**：图2及论文论证过程不仅分析总体的 ESG Ratio，还将其严格拆解为独立的 `Environmental Ratio`、`Social Ratio` 和 `Governance Ratio`。
  -> **[预期边际贡献]**：利用这一范式，将当前项目的概念词汇（如金融科技领域，可细分为“底层技术”与“应用场景”）或其它关键词映射分解至最基本维度，生成不同维度的细分频率占比，用于增强截面数据的异质性分析（Heterogeneity Analysis）。

3. 冗余剥离：
- **拒绝纯词典降级（明确输出“维持原状”）**：论文依赖词汇法作为决定性核心变量，是因为其研究对象（PE机构的历史网页快照）难以进行标准化机器语义理解。而当前项目针对的是中文规范新闻文本，且已经部署了多模型混合的三阶段判准体系（`tone_llms.py`）。在这方面，项目必须**维持原状**！严禁将基础的词频法代替 LLM 作为数据的主分类标准，而仅允许将由“改进 A&B”所派生的连续频率特征（Ratio）用作稳健性检验（Robustness Check）工具及协变量。


=========================================
第二部分：项目重构与优化执行计划书

1. 优先级排布：
- **速赢项（Quick Wins）**：修改现有的基于词典特征抽取的模块（例如 22_tone_words.py ），增设计算去除停用词后的“总合法词汇数”，输出标准化的标准化 Ratio 比率。
- **核心攻坚项**：建立类似论文中划分 E、S、G 维度的嵌套式子树词典，从单维度的概念库升级到多维度的词表统计输出，并体现在最终聚合的年度面板（Panel Yearly Data）特征中。

2. 阶段化执行指令 (SOP)：

**阶段一（机制重塑/数据清洗）**：
- 核心动作指令：进入文本预处理及词典统计流水线，加入统计全文本清理后有效长度（Total Cleaned Tokens）的代码，确保每一个词典统计结果必须伴随对应的分子/分母结构。
- 明确交付物标准：生成的 `22_words_tone.parquet` 中除绝对次数外，必须包含明确的标准化比率序列（如 `fintech_ratio`, `sub_topic_ratio` ）。

**阶段二（实证/模型重构与检验）**：
- 核心动作指令：在面板数据合并阶段（`45_panel_export_main.py`），对年度文章层级的 Ratio 做算术平均或加权均值映射至 Bank-Year 层级。
- 稳健性检验标准：复刻论文的多元回归规范：在回归模型中代入这个新生成的连续比率（Ratio）作为控制变量，证明被加入对总字数的控制比率后，原来由大语言模型（LLM）识别的倾向与情感效应依然稳健。

**阶段三（结论重构）**：
- 核心动作指令：借鉴文献论证思路，不仅撰写绝对事件次数的高频影响，必须开辟专题分析基于比率所展现的“相对关注度焦点转换”。

3. 风险预案 (Plan B)：
- **预判致命卡点**：中文新闻数据在去除清洗停用词后依然“水分”偏多（如大量宏观政策论述），导致分母激增、Ratio 数值畸小，在面板回归中产生右偏极端分布，方差微弱无法获得显著变异。
- **切实可行的替代方案**：复刻论文做法（Table 2, Log. ESG Ratio），使用对数化预处理，即构建 `Log_Topic_Ratio = ln(1 + Ratio)` 来缩放极端分布；或者使用分位数法排序，将该连续变量直接降维为分类虚变量（高于行业均值标为 1，否则为 0）。
