# 基于《象征性还是实质性：合法性压力下的企业ESG行动策略研究》的项目分析与执行计划

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
- **论文核心机制**：该研究聚焦于企业“言行不一”的新型“漂绿”行为。方法上，利用大语言模型从报告非结构化文本中精准划分“象征性（Symbolic，如口号、协议）”与“实质性（Substantive，如实质量化投入）”ESG 行动；理论上，引入 DNDD（差异与非差异）框架，论证合法性压力（政府规制与媒体监督）如何促进行动一致性。
- **当前项目真实落差**：现有项目（`news_process`）的 LLM Prompt（仅做 `is_bank_fintech_news` 和 `sentiment` 验证）完全无法区分银行是真正开展了金融科技落地（实质性），还是在释放数字化“烟雾弹”（象征性，即数字化漂绿行为）。此外，虽然项目中存在正负面情感词典与模型输出，但并未通过 Janis-Fadner (J-F) 系数等学术公认的指标将海量媒体情感转化映射为系统层面反映的“媒体认知合法性压力”。这导致现有面板不能深入探索当前极其前沿的“策略性表态”问题。

### 2. 实质性改进项（宁缺毋滥）
- **改进 A：在 LLM 信息抽取环节引入“象征性 vs 实质性”二维标签识别**
  - *论文依据*：参考论文第三部分“基于大语言模型的 ESG 行动度量方法”及其对象征性/实质性行动的分类标准。
  - *预期边际贡献*：将原先粗放的“是否为金融科技新闻”升级为“Fintech Talk（声明性）”与“Fintech Walk（实质性）”的二维面板指标。有助于揭示银行是否存在“数字化漂绿”行为，解决单一维度信息提取中固有的同质化及信息内生性混淆偏差。

- **改进 B：基于海量金融新闻构建银行维度的 Janis-Fadner (J-F) 媒体监督系数**
  - *论文依据*：论文核心解释变量与构建体系——通过 J-F 系数有效将正向、负向新闻合成为一致的且非线性的“媒体舆论监督”度量指数（即外部认知压力代理变量）。
  - *预期边际贡献*：提升对外部环境约束度量的精准度，使得本项目的宏观分析可直接对接合法性理论框架下的前沿资产定价或机构投资研究，解决利用简单词频差值所带来的异方差风险。

- **改进 C：全面接轨 DNDD（方向性与非方向性）差异检验框架**
  - *论文依据*：论文引用的Bednall & Zhang (Directional and Non-Directional Difference) 一致性偏离模型。
  - *预期边际贡献*：摒弃传统计量中的“直接求差法（Sym minus Sub）”。能够分离“数字化行动一致性”中系统性的策略偏移（方向性差异）及由信息摩擦导致的随机方差（非方向性差异），将极大地提升当前计量面板推断严谨性及后续的顶刊投稿适配度。

### 3. 冗余剥离
- **剥离对象**：`config.yaml` 中基于旧版文本挖掘设计的传统规则验证机制，如阶段37（纯金融科技词典覆盖率审计）、阶段35（非语义特征的窗口半径敏感性检验）。
- **理由**：既然核心测度已切换为具有强推理能力的LLM（用以区分象征/实质边界），再去追求低维语义词典的覆盖率边际效用极低，这种追求形式主义的“伪需求”验证毫无意义，应直接剔除并把算力集中分配至针对 LLM Prompt 测量的置信度阈值分析与鲁棒性验证（即阶段 39）上。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：在阶段21（`21_tone_llms`）中修改提示词（Prompt Template），让大模型在现有判定基础上，以格式化 JSON 追加输出 `action_nature` (“象征性”/“实质性”) 并给出提取证据。并在面板导出代码中建立对于这两种行为在年度层面的加总频次变量。
- **核心攻坚项**：引入DNDD模型的构建。因为DNDD需要特殊的条件期望运算（如：计算特定截距、构建双指标协方差扰动项的差值绝对值），这必须在计量分析或者Stata导出生成环境`45_panel_export_main.py`进行底层脚本对接支持和残差预计算。同时，需要聚合个体新闻的正负极性计算得出J-F系数序列。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑/数据清洗）：**
- **动作指令 1**：修改 `config.yaml` 的 `tone_llm_processing.prompt_template`。明确给出准则：(1)“象征性（Symbolic）”：战略合作意向、愿景规划、概念性发言或尚未量化的政策方针；(2)“实质性（Substantive）”：量化的投入经费、真实产品上线、系统重构落地、明确技术专利取得。要求 JSON 输出层级拓展包含 `action_nature` 和 `action_reason` 。
- **动作指令 2**：在 `config.yaml` 的验证节点强制关闭 `radius_sensitivity` 和 `dict_coverage_audit` 设置 (`false`)。
- **交付物**：经过本地 LLM API 单例验证无误、能够稳健输出 `action_nature` 字段的 `config.yaml` 文件。

**阶段二（实证/模型重构与检验）：**
- **动作指令 1**：重构 `45_panel_export_main.py`。读取含带有 `action_nature` 的输入表，按年份和银行进行 `groupby` 计算 `fintech_talk_count` (象征) 和 `fintech_walk_count` (实质)。
- **动作指令 2**：在年度面板构建过程中增加 `media_J_F_index` 指标的向量化计算（当正向新闻数 $e$ 与负向新闻数 $c$ 时，使用分段公式：$e > c$ 时为 $(e^2-ec)/t^2$；$e < c$ 时为 $(ec-c^2)/t^2$）。
- **交付物**：包含完整的、具有创新维度的“银行-年份（Bank-Year）”复合面板数据，为实质分析提供 Stata ready 版的 `.dta` / `.parquet` 支持。

**阶段三（结论重构）：**
- **动作指令 1**：依据输出面板，撰写或运行基准 OLS与 DNDD 模型，检验在面临高认知压力（即当年高强度的媒体J-F指数）或规制压力（基于政策事件）的情况下，企业“言行差距”是扩大了还是收敛了。
- **交付物**：一套具备稳健性支撑和调节机制结果的回归报告（包含方向性/非方向性差异结果表）。

### 3. 风险预案 (Plan B)
- **致命卡点 1（大模型在短文本的新闻语料中无法有效区分性质）**：有些新闻仅含只言片语导致LLM出现“幻觉”均判为实质性。**替代方案（Plan B）**：在阶段22使用正则表达式抽取出是否含具体金额指标（如“万元”、“亿”）、版本号（如“V2.0”）、或“专利”、“投产”，强行实施后处理覆写。若匹配词元出现，才强制判定为“实质性”，否则一律降级为“象征性”。
- **致命卡点 2（DNDD模型的参数化在小样本面板不收敛）**：DNDD 存在条件方差与非线性 Delta 约束对样本分布和无量纲化的严格要求。在Stata中若发生无法识别异方差现象。**替代方案（Plan B）**：果断退回至传统的基于标准计量的“直接差值法”，将被解释变量转为 $\ln(Symbolic\_Count+1) - \ln(Substantive\_Count+1)$，并在附录中承认新闻高频波动的特殊性限制。遵循论文表 5 的稳健性应对模式。
