# 基于《Economic policy uncertainty and bank liquidity》的项目优化执行计划

=========================================
第一部分：基于参考论文的项目分析与诊断报告
=========================================

**1. 范式映射与盲区诊断：**
参考论文的核心机制是：**经济政策不确定性（EPU）驱动银行预期到未来的流动性冲击和融资约束，从而引发其在资产、负债和表外全面囤积流动性（防御性行为）**，并且该行为受到显著的“同业溢出效应（Peer Spillover）”放大。
映射至当前 `news_process` 新闻分析项目，现有流水线重度依赖于“正面/负面情感（Sentiment）”及静态金融科技主题分类，存在两大核心盲区：
一是**缺乏异质性不确定性冲击视角的量化**。项目未区分系统性政策不确定性与个体经营风险，仅仅衡量舆情好坏，无法刻画银行应对宏观EPU的风险敞口大小。
二是**忽视了银行应对冲击的主动防御机制网络**。项目拥有提取同行共现（`co_mentioned_banks`）的能力，却未借此构建同行压力或流动性防守行为的溢出传播网络。

**2. 实质性改进项（宁缺毋滥）：**

*   **改进 A：基于同文提及网络的同业溢出效应（Peer LH Spillover）量化** 
    -> **[标明论文依据]**：论文 Page 2 与 Page 10 指出同业对 EPU 反应剧烈时，本行囤积流动性的反应更为剧烈（Spillover effects）。 
    -> **[预期边际贡献]**：利用当前流水线模块三（阶段21）中已精准提取的 `co_mentioned_banks` 字段，构建基于舆论共现的“银行同业溢出网络”，提取非地理层面的信息与情绪传染效应。这能有效突破传统靠资产规模距或地域就近判定同行范围的内生性限制，增强实证发现的深度与独创性。
*   **改进 B：从单维“情感(Sentiment)”向“微观不确定性暴露(EPU Exposure)”扩维** 
    -> **[标明论文依据]**：论文利用股票市场收益率测算银行级的 $\beta_{EPU}$ 异质性暴露。
    -> **[预期边际贡献]**：利用阶段21的 LLM CoT 能力，增加对“政策变数、监管合规压力、宏观紧缩”等不确定性信号的抓取，构建高频的“文本级银行 EPU 暴露度 ($\beta_{EPU}^{text}$)”。此举能够利用丰富的新闻语料作为替代指标，解决非上市中小银行缺乏股票高频数据测算 $\beta_{EPU}$ 的痛点。
*   **改进 C：整合前瞻性陈述（FLS）刻画预期防御意图**
    -> **[标明论文依据]**：论文提到流动性囤积源于“面对不确定性时，预期到未来贷款损失（expected loan losses in the face of greater uncertainty）”的防御。 
    -> **[预期边际贡献]**：激活并深化流水线中的 `forward_looking_words` 模块，将其与风险/流动性词汇共现做加权关联，能够更精准地分离银行是“被动接受负面结果”还是“在预期不确定性下的事前主动防守机制”。

**3. 冗余剥离：**
明确建议剔除当前项目中缺乏深度泛化能力且与识别系统性冲击无关的浅层 BERT 模型验证（特别是 `hw2942` 和 `Erlangshen 110M`）。论文明确指出需要通过区分息差（Spreads）变动来屏蔽供需层面的噪声（Demand-side vs Supply-side），而低参数量且训练语料单一的情感 BERT 在面临系统性的经济政策论述时极易将中性事实错判为主观负面，产生严重的测量噪音，实属“伪需求”模块。


=========================================
第二部分：项目重构与优化执行计划书
=========================================

**1. 优先级排布：**
*   **速赢项（Quick Wins）**：基于存量数据快速聚合计算 `co_mentioned_banks` 同行业网络中心度与度并列指标，剥离冗余的边缘 BERT 模型，并强化前瞻性特征词典。
*   **核心攻坚项**：重构 LLM 提示词模板以抽取实体维度的不确定性暴露量度；在数据对接层面，跨区联通存款/贷款定价数据（如参考论文中的 RateWatch 或 DealScan 息差替代数据）以剥离借款人需求侧内生性干扰。

**2. 阶段化执行指令 (SOP)：**

*   **阶段一（机制重塑与数据清洗）：**
    *   **核心动作**：修改 `config.yaml` 中的 `prompt_template`，在 JSON 输出强制格式中增加字段 `"epu_exposure_level": "None/Low/High"` 和 `"liquidity_stance": "Expansion/Tightening/Neutral"`。
    *   **交付标准**：LLM 成功完成新 Prompt 的小样本重跑（500条），返回的 JSON 不仅包含情感，还能识别出面临政策与市场不确定性时的资产防守表述（如收紧授信或增加备付）。

*   **阶段二（实证与面板网络模型重构）：**
    *   **核心动作**：在阶段 40 面板数据生成（`45_panel_export_main.py`）中，加入基于 `co_mentioned_banks` 生成的动态邻接矩阵，并据此计算各银行的 `Text_Peer_EPU_Shock`（即舆论共现对象的加权 EPU 暴露值均值）。
    *   **稳健性标准**：必须在进行面板回归时将此指数作为交乘项（$EPU \times Text\_Peer\_EPU\_Shock$），以还原验证论文中的信息溢出效应（Spillover效应）。

*   **阶段三（结论重构与内生性控制深化）：**
    *   **核心动作**：借鉴论文 Section 5 排除客户需求影响的做法，要求提取银行利差、存款成本数据，建立 $Text\_Sentiment/Text\_EPU \rightarrow Spread$ 的联动检验回归模型。
    *   **交付标准**：通过利差数据证实，银行端出现舆情不确定性时，是通过自身拉宽信贷息差、变相获取流动性，从而排除了纯粹的需求衰退解释。

**3. 风险预案 (Plan B)：**
*   **致命卡点预判**：日常 PR 新华体新闻通稿中关于“流动性收紧”的表述可能受到高度美化与扭曲，导致 LLM 判断 `liquidity_stance` 存在极为严重的假阴性（即全部报 Neutral）。
*   **替代方案**：若提取主动防守描述失败，则降维采用工具变量思路替代。直接将新闻内“宏观不确定性词汇频次”加总映射作为微观EPU代理维度，不强求直接从文本读取主观收缩信号，而是利用最终在财务报表端的资产量（Call Report数据库）与该文本映射指数做交叉回归。
