# 基于参考论文《Enhancing Investment Decisions with Sentiment Analysis: A Probabilistic Ranking Framework》的项目评估与执行计划

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**论文核心机制提取**：
该论文提出了一种基于概率排序框架的半参数文本情感提取模型（SESTM）。其核心思想是：不依赖预设的主观情感词典，也不采用黑盒深度学习模型，而是将文档与“序数响应变量”（如股票代码关联的相对收益率排名）直接挂钩。通过第一步的**词语筛选（Word Screening）**和第二步基于**归一化排名（Normalized Ranks）的主题建模**，自动学习领域驱动的正负情感词典（及其具体词频权重 $\hat{O}_+$, $\hat{O}_-$），进而使用惩罚最大似然法估算每篇文章的连续极性得分，实现精准的情感排序。

**当前项目（news_process）的盲区**：
项目当前在 `阶段22_words_tone`（词典法）使用预置的金融倾向词典外加复杂的程度副词/否定词乘数运算；在 `阶段23_bert_tone` 使用了泛化能力的黑盒开源预训练 BERT；在 `阶段21` 使用 LLM 进行三分类（正面/中性/负面）。
主要落差在于：
1. **脱离市场反馈**：当前词典权重与 LLM 判定均是“先验”的，未利用市场真实反馈（如银行股票的量价反应）作为监督信号。
2. **绝对分值 vs. 相对排序**：当前系统强行赋予了“正”、“负”标签，但忽略了投资和经济效益在截面上更依赖于具有连续深度的“排序（Ranking）”信息，三元分类（Ternary Classification）会极大折损截面差异性。
3. **词语权重的强设定**：配置中的程度副词倍数（如“极其=3.0”、“稍微=0.6”）为主观拍脑袋，缺乏实证依据，而论文证明数据驱动词频权重（Data-Driven Topic Weights）具有更优的样本外解释力。

### 2. 实质性改进项（宁缺毋滥）

> **改进 A：由“手工参数词典”向“监督式概率主题模型（SESTM）”重构**
> - **具体修改建议**：在情感阶段引入基于有序响应（如关联上市银行在新闻发布前后的超额收益排名或波动率排名）作为监督标签的 SESTM 模型。构建专属于“中国金融科技与银行业态”的动态高频特定词频向量 $(\hat{O}_+, \hat{O}_-)$。
> - **论文依据**：Section 2.1 “Data generating processes” 与 Section 2.2 “A sentiment extraction and ranking algorithm”。
> - **预期的边际贡献/解决的内生性问题**：彻底消除预置词典的代表性偏差（Representation Bias）和人工设定权重（Ad-hoc Weighting）带来的测量误差。直接产出以金融资产价格为引导的连续情感得分，显著提升对面板回归中企业真实绩效和维度的解释方差 ($R^2$)。

> **改进 B：从“绝对分类”转为“相对排序（Normalized Rank）”抽边**
> - **具体修改建议**：摒弃预测绝对收益或直接使用二元逻辑回归分类（如将涨跌强行按0/1划分），采用归一化的位序作为替代响应变量（$\hat{p}_i$）去训练底层架构。
> - **论文依据**：Section 2.2 公式(9) $\hat{p}_i = \frac{\text{rank of } y_i}{n}$。
> - **预期的边际贡献/解决的内生性问题**：解决股票收益分布存在肥尾效应、极端离群值对基于一般回归的情感提取导致的扭曲，能够利用排名获得极为稳健的（Robust）词语信号关联性。

### 3. 冗余剥离
明确指出当前项目中偏离主线或价值极低的“伪需求”模块，建议剔除：
- **剥离 `22_words_tone.py` 复杂的语法树规则**：`config.yaml` 里面的 `negation_words`（否定词）、`sentence_end_markers`（句末断句）、`degree_words`（程度副词）等极其繁琐复杂的规则逻辑属于高度主观拟合的遗留产物。它们计算巨大却毫无弹性。建议废弃整套基于人为计算权重的静态词典法。
- **剥离泛用领域的通用 FinBERT/Erlangshen 模型 (`23_bert_tone.py`)**：论文 Table 3 论证了 BERT 泛用情感标注因为词汇关注力极易遭遇“样本外过拟合”陷阱，特别是针对等权组合预测时表现劣于 SESTM。可直接跳过这些开销巨大的纯预测黑盒。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：
  直接融合股票交易数据，获取文章标的银行在 $t-1$ 到 $t+1$ 期间的超额收益并计算归一化顺位排名，用作现有文章级别的监督标签（Response Variable），合并进 `40_article_bank_level.parquet` 数据集。
- **核心攻坚项**：
  开发 `24_sestm_tone.py` 模块，执行：分词映射 -> 单词与标签方向（sgn(y)）的共现频率筛选 -> 组建 $(\hat{O}_+, \hat{O}_-)$ 矩阵 -> 利用岭惩罚极大似然法（Penalized MLE）反推测试集每日截面打分。

### 2. 阶段化执行指令 (SOP)

#### 阶段一（机制重塑/数据清洗）
- **核心动作指令**：
  1. 抓取外部 CRSP（或 CSCS/Wind 中国A股/港股银行盘面）数据，获取匹配的新闻曝光标的银行在当日（涵盖盘后至次日开盘）的股票多日累计超额收益 $y_i$。
  2. 实现 $y_i$ 的排序化处理：为每一个训练周期（Rolling Window），计算各个新闻 $i$ 关联收益在当期的横截面分位数 $\hat{p}_i$ （0 到 1 之间）。
  3. 通过中文分词工具（如 Jieba + 自定义金融科技分词）提取文本 Bag-of-Words （词袋模型）。
- **明确的交付物标准**：输出附带股票 $y_i$, \text{sign}(y_i) 以及归一化排序 $\hat{p}_i$ 标签的稀疏词袋矩阵（Sparse BoW Matrix）数据集。

#### 阶段二（实证/模型重构与检验）
- **核心动作指令**：
  1. **构建 Word Screening 函数**：依据 $sgn(y_i)$ 按论文式 (5) 获取 $f_j$，并以阈值 $(\alpha_+, \alpha_-, \kappa)$ 过滤出含有实质金融与科技情绪反应的保留字词。
  2. **矩阵运算生成 SESTM**：利用论文式 (10) 对过滤后的词矩阵求和拟合出 $\hat{O}$，从而求得 $O_+$ ($f_j \ge \hat{\pi} + \alpha_+$)与 $O_-$ ($f_j \le \hat{\pi} - \alpha_-$) 两极分布。
  3. **Penalized MLE 评分**：开发利用 L2 正则化的非线性优化求解器（可用 `scipy.optimize.minimize`），求得每篇文章最终的 $p^*$（Rescaled Sentiment Score）。
- **稳健性检验标准**：使用10年训练+5年Validation+1年OOS Rolling Window 方法测试；进行参数敏感度交叉检验（Grid Search of $\lambda, \alpha, \kappa$ 寻找使得样本外 Rank Correlation 最大的一组）。

#### 阶段三（结论重构）
- **核心动作指令**：
  1. 在面板分析中（Stage 45-51）将原始使用 `sentiment_il` 等离散定性的代理变量，替换为由 SESTM 生成的连续定量得分 `SESTM_tone`。
  2. 生成《词汇权重云图（Most Impactful Words）》（参照原论文 Figure 6），实证解释到底哪些非标中性词语在银行业转型升级过程中隐含了真实的“超额收益正负极导向”。

### 3. 风险预案 (Plan B)
- **致命卡点预判**：
  由于本项目侧重“金融科技新闻”，词汇空间极大，而关联收益数据的频次不够或带有高噪音，导致使用 Bag-of-Words 构建的 $\hat{O}$ 稀疏不收敛，或极易因特定舆论事件出现矩阵奇异性。
- **替代预案 (Plan B)**：
  放弃彻底的 Bag-of-Words，转而使用当前已有的“金融科技专属词表”+“LLM自动总结生成的核心实体事件Embedding”，在低维的特征空间里复用本论文的“概率顺序建模排序思想”进行监督学习降维与回归；即 **LLM-assisted Ordinal Regression**。采用 $\hat{p}_i$ 作为惩罚损失函数对 LLM 层特征施加影响，以保留“无需主观打分、根据市场自然反馈排序”的核心精神。
