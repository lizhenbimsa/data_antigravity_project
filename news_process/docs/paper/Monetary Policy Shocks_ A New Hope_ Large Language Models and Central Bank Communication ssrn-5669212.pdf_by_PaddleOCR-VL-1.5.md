第一部分：基于参考论文的项目分析与诊断报告

1. 范式映射与盲区诊断：
参考论文《Monetary Policy Shocks: A New Hope》构建了**“多智能体（Multi-Agent）预期与冲击分离框架”（Agent IB结合前序文本建立经济分布，Agent IM提取前期意图，Agent II融合先验，Agent III对比事后声明算出Surprise）**，将金融文本测度从传统的“静态截面情感打分”推向了“非线性全维事前预期误差（Ex Ante Surprise）”萃取。
当前项目（新闻情感分析流水线）的盲区在于：
- **静态情感替代效应**：我们当前的 `21_tone_llms.py` 模块仅执行简单的上下文情感多极打分（正面/负面），未考量信息在市场中的“已预期（Expected）”与“超预期（Surprise）”成分。纯情感打分具有严重的内生性信息污染（Information Effect Contamination），难以作为外生冲击变量。
- **单维评估与融合推理缺失**：目前的架构为单一 LLM 执行单步 CoT，要求其同时分辨事件真因与情感倾向。对于大批量新闻文本，单智能体的处理不仅极其容易受到局部噪声干扰，也无法实现“提取宏观基准”与“推算微观个体事件预期偏差”的序贯对比结构。

2. 实质性改进项（宁缺毋滥）：
    - 改进 A：将单一静态情感测度重构为“事前预期 vs 事后冲击（Ex Ante Expectation & Surprise）”多层提取机制。
      -> [标明论文依据：依据 Agent II 的概率加权先验融合方法与 Agent III 对比预期计算 Surprise 的偏差逻辑]
      -> [预期的边际贡献：将当前的简单好坏评分进化为“非线性超额冲击得分”，有效消除新闻中由于宏观大势带来的同质化信息污染，从而获得因果效度极强的纯外生金融科技新闻冲击。]
      
    - 改进 B：引入多智能体序贯结构以拆解“全行业宏观指引”与“微观单体新闻事实”。
      -> [标明论文依据：论文设计Agent IB（褐皮书读懂宏观）与 Agent IM（纪要读懂先导意图）来消解单一模型负荷，避免前瞻性偏差（Look-ahead Bias）和幻觉]
      -> [解决的内生性问题：系统化正交分离“全行业数字化转型的背景渲染”引发的虚高打分与“目标银行核心技术突破”带来的实质突变。]

3. 冗余剥离：
**直接剔除词汇库层与早期向量层（`22_tone_words.py` 与 `23_tone_berts.py`）**。参考论文充分证明，缺乏非线性长序语境捕捉能力的线性残差模型和基础文本量化工具会产生严重的衰减偏差（Attenuation Bias）。这两部分占用了庞大流水线调度但所带来的信息增益几乎为负，属于价值极低的“伪需求”。

第二部分：项目重构与优化执行计划书

1. 优先级排布：
- 速赢项（Quick Wins）：清理流水线冗余，果断移除字典法与基础BERT情感模块相关的所有脚本和配置文件；对 `config.yaml` 进行改造以支持复杂的多级 LLM Agents 定义。
- 核心攻坚项：基于现存的大模型评估层进行多智能体编排（Orchestration），重塑底层逻辑链路：环境认知 -> 先验预期分布设定 -> 真实新闻对比决断与计算 Surprise。

2. 阶段化执行指令 (SOP)：

阶段一（机制重塑与数据基础整理）：
- 核心动作指令：在 `config.yaml` 层面及主调度文件 `00_preprocessing.py` 之后，阻断所有向 `22_words_tone.parquet` 和 `23_bert_tone.parquet` 分流的数据与任务，精简依赖节点。
- 交付物标准：输出全新的纯净型 LLM 专用文本投喂输入池，包含可切分的前序基准（T-1期及相关行业研报）组与实际宣告事件文本（T期单体新闻）组。

阶段二（实证/模型重构与检验）：
- 核心动作指令：重构 `21_tone_llms.py`，实现三阶段多智能体（Multi-Agent）管线：
  1. **Macro Agent（宏观基准代理）**：综合当前时点（或滚动前驱窗口期内）所有银行相关新闻的大气候环境，生成对银行在相应细分领域的行为概率分布先验。
  2. **Signal Agent（新闻事实发现代理）**：负责独立提取评估当期实体新闻中的明确科技研发或重大突破信号与事实认定。
  3. **Surprise Agent（冲击评估测算代理）**：比对上述两组信息源，根据新闻结果事件偏离市场大环境预期的程度计算 `Financial_Tech_Surprise` (机械冲击额) 及 `Contextual Salience` (情境显著度系数)。
- 稳健性检验标准：验证合成输出的 Surprise 指标是否呈现高偏态/尖峰分布特征，确保小部分真正产生重大意外的技术事件具备厚尾分化。

阶段三（结论重构）：
- 核心动作指令：全面修改 `41` 至 `45` 面板聚合逻辑及计量回归模型验证模块，将 `Fintech_Sentiment_Score` 核心自变量替换为由 LLM 输出得到的 `Fintech_Surprise_Index`，并基于此指数重新运行检验。

3. 风险预案 (Plan B)：
- 预判执行中的致命卡点：由于单个媒体的新闻具有高度碎片化且时间离散特征，可能无法构建稳定且包含足够多样本以供训练生成精准时序先验（Prior Bayesian Expectation）的前提材料池（如同论文中连续严密的 FOMC 褐皮书发布节奏）。
- 替代方案：若时序事前预测逻辑数据源匮乏，则直接改为“截面横向对齐机制（Cross-sectional Peer Alignment）”。指令化一个 Peer Baseline Agent 用来分析新闻发生期内的全体横截面同业新闻表述基准，以此替代 T-1 时序基线，使用截面对比来提取属于个体异质性的 Cross-sectional Surprise 冲击分数。
