# THE EXECUTIVE PLAN: Local newspaper closures and bank loan contracts

=========================================
## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**核心范式提炼**：
参考论文的核心范式是“物理距离/本地环境效应与信息摩擦的因果交互”。论文证实，本地化媒体（地方报社）具有独特的信息生成体系（特别是深度的负面非财务信息调查）以及对当地机构的外部硬性监督（Watchdog）功能。这种特有的本地信息供给和监督环境一旦被削弱（地方报纸停刊），将加剧本地银行或借贷网络中的逆向选择与道德风险，直接传导至更高的信贷利差及更严苛的契约条款。

**当前项目盲区诊断**：
当前基于 `F:\WiseSearch\data_antigravity_project\news_process` 的金融科技（FinTech）新闻数据流线存在显著的空间物理属性“刻画盲区”。尽管项目的 `config.yaml` 内置了丰富的媒体维权与结构（如中央/异质性媒体分类），并在预处理抓取了“国家地区/省份/城市”等多级空间字段，但在聚合为 Bank-Year 面板时，将所有的舆论信息池作了扁平化吸收。**当前项目忽略了“媒体地理总部溯源”与“银行及其分支网络物理距离”对信息监督硬度与信号传导效能的根本性影响。** 简单的全国性汇总会稀释本地媒体对微观银行实体的真实监督涟漪。

### 2. 实质性改进项（宁缺毋滥）
> - **改进 A：嵌入“媒体-银行”地理邻近度与本地监督溢价机制**
>   - **[具体修改建议]**：全面激活 `bank_addresses.json` 的价值。在面板合成期，引入新闻报道来源媒体所处省区市与被报道银行总部（或核心网点）的坐标判定，以此剥离构建本地金融科技媒体指数（Local Media FinTech Exposure）和异地指数。
>   - **[标明论文依据]**：论文采用以公司总部范围 50 miles 为缓冲圈界定处理组（Treatment firms），印证了物理“接近性（Proximity）”是区分泛媒体公关和核心媒体监督的根本性指标。
>   - **[预期的边际贡献]**：能极为有力地回答：当地的创新及风险新闻到底是更受本地原生硬核监督掣肘，还是受全国宽泛风潮的影响。能够剔除掉全国媒体同质化的“噪音公关”，使得研究发现具有更稳固的地理经济学微观基础和外生防卫力。

> - **改进 B：将 LLM 情绪识别引擎向“实质性风险监督揭示”倾斜**
>   - **[具体修改建议]**：在 `21_tone_llms` 的 prompt 中，不能仅仅局限于单纯判定科技新闻的“正面/负面”，需强制指令大语言模型对文章是否存在“特定非财务风险暴露、合规隐患、消费者侵权或监管处罚的客观监督披露”进行结构化打标（添加 `is_watchdog_monitoring` 字段）。
>   - **[标明论文依据]**：直接源于论文中 “unique nonfinancial information... particularly negative news” 以及 “watchdogs that can discipline corporate behavior” 的发现。
>   - **[预期的边际贡献/解决的内生性问题]**：使项目不再局限在单一研究金融科技“向好”的一面，而是揭示真正发挥信贷环境改良作用的是本地新闻对负面偏差行为的矫正威慑力。化解了简单计算情感倾向可能遭遇的“同义反复（Tautology）”内生偏误。

### 3. 冗余剥离
- **多阶小规模 BERT 情感模型的严重冗余**：
明确剔除当前跑在 `23_tone_berts.py` 内的多达 5 个中小型 BERT 情感模型组合并列流（如 hw2942, erlangshen 等）。在我们要深入探究“本地非财务实体负面监督属性”这一复杂的长期上下文时，传统 BERT 标签体系不仅无力下沉至因果事理的解释层面，对 GPU 推理并行的调度和存储也构成了灾难性阻碍与“伪需求”。
  - *建议直接剔除大部分BERT冗余算力消耗，只保留 `FinBERT` 作为传统深度学习对照基准，将其余计算资源全盘让渡给统一的高参数大语言模型（LLM CoT）去捕捉因果逻辑。*

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：
  1. 裁减配置并重新调整算力流：精简或移除重叠的 BERT 模型群（配置文件层级缩容）。
  2. Prompt 扩维重构：更新 `config.yaml` 中的 `prompt_template`，增设负面监管事件和非财务调查内容的标定节点。
- **核心攻坚项**：
  1. 在地理面板特征工程（`43_panel_indicators_geography.py` 与 `45_panel_export_main.py`）中实现新闻报道源同银行驻地的多叉树空间连接算法。
  2. 匹配寻找中国地级市传统媒体/报纸关停、数字化转型或并购等重镇媒体生态破局的时间线，构建基于历史区域的交乘变量。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑与数据深度清洗）：**
- **核心动作指令**：
  1. 修改 `config.yaml` 配置文件：清理不需要的预定义 BERT 路径，扩写并强化 `tone_llm_processing` 下的任务语义，要求验证是否为实质性的本地新闻风险监督与揭示类报道（输出 `watchdog_alert` 原生布尔值）。
  2. 于 `00_preprocessing` 增加空间匹配模块，硬性要求合并本地政区白名单库，以提炼出最精华的带锚新闻文本。
- **明确的交付物标准**：一个高纯度、带精确情感标量且携带 `media_local_match_flag` 的强化基座特征宽表 Parquet。

**阶段二（实证与模型坐标重构）：**
- **核心动作指令**：
  1. 打开 `45_panel_export_main.py`，根据“城市-银行”进行 `groupby`。分别聚合计算以同城及同省范围内的 $Local\_Sentiment\_Index$ 和异地 $Non\_Local\_Sentiment\_Index$。
  2. 构建媒体关注意外流失差分表。结合预定义好的外部历史冲击年份（需引入额外地理或报业萎缩数据集与银行节点拼表）。
- **稳健性检验标准**：
  强制在 `51_falsification_test.py` 中编入基于“随机打乱总部地理关联的伪分配网络（Randomized Counterfactual Geolocation Match）”执行 1000 轮安慰剂组合测试，确保溢价效应并非时间自然通胀。

**阶段三（结论体系破茧）：**
- **核心动作指令**：
  剥离单调的“新闻总量决定信贷能力”的旧视角，输出聚焦于本地监督干预在缓解因金融科技黑盒引发的高额试错摩擦中所充当的外挂约束力量，并将核心估计量通过多层 Fixed Effect（省份 $\times$ 年份）进行严苛因果锁闭。

### 3. 风险预案 (Plan B)
- **卡点预判**：
  1. 银行银团层面具体的、逐笔微观信贷合同条款（契约苛刻度、利差 bp 细数）极难通过一般财报公开获取，甚至可能面临底层微观交割数据缺失的毁灭性风险。
  2. 中国国内可能不存在类似美国这种“地方性大报社密集无序倒闭”的标准化事件窗口。
- **切实可行的替代方案 (Plan B)**：
  1. 【冲击替换】：用近年推行的数字经济/官方媒体融媒体转型合并事件作为冲击性替换变量，不再衡量关闭影响，而是衡量“媒体中心化整合/撤销地市级独立性”对银行风险容忍或操作规范的监督震荡。
  2. 【终点替换变量】：由于信贷微观合约难觅，应当沿用现有的宏观变量架构，将因变量直接替换为财报附注中被证实的**“核心一级资本充足率”、“贷款不良率动态劣变（NPL Formation）”与“罚单总额”**，同样能作为反映逆向选择叠加道德风险的绝佳代理变量。
