## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断

#### 1.1 论文核心机制提炼

李元琨 (2025) 的核心方法论创新体现在以下四个维度：

| 维度 | 论文做法 | 当前项目现状 | 落差诊断 |
|------|----------|-------------|----------|
| **AI语义测度** | S-BERT 对中美专利摘要做向量化，计算余弦相似度，构建专利级突破性创新指数和跨国知识流动指数 | 项目使用 3 个 LLM (GPT-5nano/Gemini3/Claude4h) 多数投票 + 5 本词典 + 5 个 BERT 模型进行情感分析，**输出为情感极性，非语义相似度** | **不存在实质落差**。两者的AI应用场景完全不同：论文的S-BERT用于专利文本间的语义距离测度（研究问题是"创新"），项目的LLM/BERT用于新闻情感分析（研究问题是"媒体情感对银行行为的影响"）。两者任务性质不同，不宜机械移植。 |
| **DID 识别策略** | 以2018年美国对华加征关税为准自然实验，构建连续处理强度DID | 项目的DID模块 (`44_panel_iv_did.py`) 使用 DCEP数字人民币试点 + 金融科技沙箱两个政策冲击，支持交错DID (Callaway & Sant'Anna, 2021) | **落差极小**。项目的DID设计已涵盖 Event Study 动态效应 (lead/lag虚拟变量)、端点合并 (endpoint binning)、多政策正交性诊断 (G-05 Cramer's V)，成熟度高于论文的标准DID设计。 |
| **双路径机制检验** | 以研发投入、内/外部现金流为"资金流"中介；以中美专利文本相似度为"知识流"中介 | 项目聚焦于**信息渠道** (新闻情感 - 银行行为)，不涉及资金流或知识流分解 | **研究问题不同，无可比性**。论文的"双路径"是贸易经济学框架，项目的核心机制是"媒体情感传导"，属金融文本分析范畴。 |
| **企业级冲击强度** | 利用HS6位码关税清单匹配海关企业出口明细，加权平均构建企业关税暴露指数 | 项目无企业出口数据、无关税清单数据 | **数据结构差异**。项目样本为142家商业银行（非出口企业），银行业不直接承受关税冲击，该变量构建思路不适用。 |

#### 1.2 核心诊断结论

**论文与项目在研究问题、数据结构和分析对象上存在根本性差异**：
- **论文**: 贸易经济学 → 关税冲击 → 专利创新 → 制造业上市公司面板
- **项目**: 金融文本分析 → 媒体情感 → 银行行为 → 商业银行面板

两者的方法论交集仅限于"AI大语言模型的文本分析"和"DID因果识别"两个维度。**不存在需要大规模重构的落差**。

### 2. 实质性改进项（宁缺毋滥）

经严格筛选，论文对当前项目有**两项具有边际贡献**的方法论启示：

#### 改进 A：基于股价事件研究法 (CAR) 的情感指标外部效度检验

- **具体修改建议**: 在 `34_tone_validation.py` 或新增独立验证模块中，增加新闻发布日前后窗口期的**银行股价累计超额收益率 (CAR)** 回归，检验项目构建的 LLM 投票情感指标、词典情感指标和 BERT 情感指标是否能对银行股 CAR 产生显著正向影响。
- **论文依据**: 李元琨 (2025) 第三节第3-4小节使用事件研究法 (Event Study) 验证基于 S-BERT 文本相似度构建的突破性创新指数和跨国知识流动指数的有效性："研究发现，基于文本相似度构建的突破性创新，在不同窗口期内均对CAR产生显著正向影响。"
- **预期边际贡献**: 补充了当前验证框架中缺失的**外部效度 (External Validity)** 环节。现有 `34_tone_validation.py` 主要执行内部一致性验证 (Cronbach's alpha、交叉相关)，而CAR检验提供了"指标是否反映真实经济价值"的市场化证据。若 LLM 情感对股价有显著影响，则证明情感指标捕捉到了有经济含义的信息，而非纯噪声。
- **实施前提**: 需获取上市银行股票日度收益率数据 (CSMAR 或 Wind)。若数据不可得，此项改进建议搁置。

#### 改进 B：异质性分析中引入"数字化前沿距离"维度

- **具体修改建议**: 在面板聚合阶段 (`43_panel_indicators_geography.py`) 中，利用 `bank_addresses.json` 已有的银行类型 (`nfra_type`) 和规模 (`enterprise_scale`) 分组信息，构建**银行数字化水平代理变量**，用于异质性分析中的子样本分组回归。
  - `digital_frontier` = 1 if 金融科技新闻覆盖量 >= 同组中位数（代理银行数字化前沿距离）
  - 与 DID 交互项形成三重差分 (DDD): Treated_i x Post_t x DigitalFrontier_i
- **论文依据**: 李元琨 (2025) 第四节第5小节异质性分析："关税壁垒对处于技术前沿的企业、全球价值链(GVC)参与度高的企业以及规模较大的企业的影响更为显著。"
- **预期边际贡献**: 当前项目面板已具备银行类型分组 (`bank_type`: soe/joint/city/rural/private/foreign) 和规模分组 (`bank_scale`: L/M/S/XS)，但**未显式构建"数字化前沿距离"这一连续代理变量**。新增该变量可为 Stata 回归提供低成本的异质性分组列，无需修改任何核心流水线代码。

### 2. 阶段化执行指令 (SOP)

#### 阶段一：速赢项——数字化前沿距离异质性变量 (改进 B)

**核心动作指令**：

1. 在 `43_panel_indicators_geography.py` 的 `compute_composite_indicators()` 函数中，**新增以下变量构建逻辑**：

```python
# -- 数字化前沿距离代理变量 (李元琨 2025 异质性分析启发) --
# 用银行金融科技新闻覆盖量（相对同组中位数）代理银行所处"数字化前沿"的位置
# bank_type 分组内的 n_articles 中位数作为基准
if 'bank_type' in panel.columns and 'n_articles' in panel.columns:
    panel['digital_frontier'] = 0
    for bank_type_group in panel['bank_type'].dropna().unique():
        group_mask = panel['bank_type'] == bank_type_group
        group_median = panel.loc[
            group_mask & (panel['n_articles'] > 0), 'n_articles'
        ].median()
        if pd.notna(group_median) and group_median > 0:
            panel.loc[group_mask, 'digital_frontier'] = (
                panel.loc[group_mask, 'n_articles'] >= group_median
            ).astype(int)
    logger.info(f"  digital_frontier: "
                f"{panel['digital_frontier'].sum()}/{len(panel)} 前沿银行")
```

2. 在 `45_panel_export_main.py` 的 `STATA_LABELS` 字典中添加：

```python
'digital_frontier': 'Digital Frontier Dummy (Above Group Median)',
```

**交付物标准**：
- `40_panel_yearly.parquet` 和 `.dta` 中包含 `digital_frontier` 列 (0/1)
- Stata 回归命令示例：`reghdfe Y c.dcep_post#c.dcep_treated#c.digital_frontier X, absorb(bank_id year)`

---

#### 阶段二：核心攻坚项——CAR事件研究效度检验 (改进 A)

**警告：此阶段依赖外部股价数据 (CSMAR/Wind 日度收益率数据库)。若数据不可得，整个阶段应跳过，不影响项目核心完整性。**

**核心动作指令**（条件执行）：

1. **数据准备**：获取上市银行（约20-30家）的日度收益率和市场基准收益率 (沪深300/中证银行指数)。

2. **新增模块** `52_car_validation.py`：
   - 输入：`21_tone_llms.parquet`（含 `target_bank`、`日期`、三种情感指标）+ 外部股价数据
   - 对每条新闻的发布日（`日期`），计算 CAR[-k, +k], k = 1, 2, 3
   - 回归模型（OLS + 银行固定效应）：CAR = alpha + beta * Sentiment + Controls + epsilon
   - 核心检验：beta 应显著为正（正面情感新闻 → 正超额收益）

3. **输出**：`eval_reports/52_car_validation.csv` 含回归系数、t值、R-squared

**稳健性检验标准**：
- LLM投票情感、词典情感、BERT情感三种指标的 beta 应同向显著
- 窗口期敏感性：至少一个窗口期显著（1%或5%水平）
- 伪事件检验：将新闻日期随机打乱后 beta 应不显著

## 审计总结
## =========================================

**核心判断：维持原状，仅做微量增量优化。**

李元琨 (2025) 是一篇优秀的贸易经济学论文，其方法论创新（S-BERT专利语义测度、关税冲击分解、"资金流"vs"知识流"双路径机制检验）与本项目（金融科技新闻情感 → 银行行为面板分析）的研究领域和数据结构存在根本性差异。**盲目移植将导致"为改而改"的形式主义**。

项目当前架构（29套Bartik IV + 交错DID + LLM三角验证 + 词典/BERT交叉验证 + Fama-MacBeth标准化 + 距离衰减敏感性检验）的方法论成熟度已达到顶级期刊水准。唯一可借鉴的增量价值为：

1. **速赢项**：新增 `digital_frontier` 异质性变量（约30分钟完成）
2. **条件攻坚项**：CAR事件研究外部效度检验（视数据可及性定）
