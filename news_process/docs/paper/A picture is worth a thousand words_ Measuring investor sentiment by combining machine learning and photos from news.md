# 基于《A picture is worth a thousand words》的新闻情感项目诊断与重构计划

=========================================
第一部分：基于参考论文的项目分析与诊断报告
（功能：学术与逻辑诊断）

1. 范式映射与盲区诊断：
目前的 `news_process` 项目为典型的单模态（纯文本）分析范式，严重依赖大语言模型（LLM）、BERT 模型和传统的词典匹配法进行新闻文本情感（TextPes）的提取。
对比之下，参考论文揭示了一项在金融学中被严重低估的维度：**新闻图片包含了超越文本结构维度的独特情感信息（PhotoPes）**。该论文实证表明，非理性的“视觉悲观情绪”能够显著且有效预测股市的短期反转、交易量放量，并对套利限制高的股票影响更甚。当前项目的最大盲区在于完全忽视了新闻的多模态（视觉）特征及其对投资者心理的冲击力，这导致在衡量因技术安全事故、重大违规或宏观恐慌等高冲击震荡事件时，单纯的文本情绪可能存在严重的遗漏变量偏误。

2. 实质性改进项（宁缺毋滥）：
- 改进 A：构建多模态视觉情绪指数（引入 PhotoPes） 
  -> 依据：论文 Section 2.1 创新性引入基于 CNN（深度学习）的图像情感分类模型完成对新闻图片的降维抽取。 
  -> 边际贡献：打破当前的纯文本视野局限，捕捉财经新闻中更为直观、更具煽动性的“视觉情绪”，极大地解决对突发性银行业务风波或金融科技安全事件因文本模态“粉饰太平”而导致的度量失调问题。

- 改进 B：引入图文交互的“替代效应”与注意力机制检验 
  -> 依据：论文 Section 3.1.2 证明大量财经场景下图片情绪和文本情绪呈现显著的“替代关系（Substitutes）”；且极端图片能够夺走（Grab Attention）投资者的对文本客观事实的关注。 
  -> 边际贡献：通过在面板模型中加入 `PhotoPes × TextPes` 交互项及“显著图片期(Salient Photo Period)”分组定性，挖掘不同模态信息传导的挤出效应，这能成为本项目在顶级财管类期刊（如 MISQ, MS 或 JF/JFE）突破的核心亮点。

- 改进 C：极端风险与视觉恐慌的非对称敏感性检验 
  -> 依据：论文 Section 3.1.4 证明在极高恐惧/恐慌时期（如次贷危机），图片传递严重悲观情绪的渗透力要远好于文本。 
  -> 边际贡献：针对目前银行数字化转型中涉及数据泄漏、监管约谈的负面冲击时间轴添加冲击哑变量，与 PhotoPes 进行三重交乘检验，确证视觉模态对极端恐慌具有杠杆放大作用。

3. 冗余剥离：
- 冗余指控：当前 `config.yaml` （阶段22）中维护了极其庞大的“情绪词典集合（tone_words）”及数十项前后缀、否定词权重表。论文明确批评指出：“基于字典的方法在面对结构简短的文本（如新闻标题、快讯摘要）时处理能力极差（超90%被错误标记为中性），无法捕捉上下文非线性关联。”
- 剥离建议：直接冻结甚至剔除词典法模块。针对金融科技高频且复杂的文本与语境，全面舍弃基于字典的情感计量，使主干模型彻底让位于性能更强劲的“LLM 语义分析 + CV 视觉模态”双轮驱动矩阵。

第二部分：项目重构与优化执行计划书
（功能：工程落地指南）

1. 优先级排布：
- 速赢项（Quick Wins/一月内）：优化并裁减 `config.yaml` 残留的词法模块，精简主分析通路，完成基于大语言模型（LLM）基座的图文对齐准备方案探讨。
- 核心攻坚项（架构重构/跨季度）：评估与回溯原始新闻数据集的图像资产，并全量构建部署“视觉-语言多模态大模型（VLM）”用于图片情绪推理、打分与存算；对 `45_panel_export_main.py` 的建库结构进行彻底升维。

2. 阶段化执行指令 (SOP)：

阶段一（机制重塑与多模态数据清洗）：
- 指令 1.1（评估视觉资产）：对现有 `raw_data_dir` 中的原始爬虫数据进行盘点。提取是否存在 `image_url`、富文本 `<img src="">` 等标签字段。
- 指令 1.2（回溯与抓取）：若原始 Excel 完全剥离了图片，启动补偿机制提取新闻原链接及 `pubcode` 发起聚焦型异步爬虫回溯补抓关联图片资产，并落盘至 `data_images/` 存储集群。
- 指令 1.3（视觉洗刷）：加载轻量过滤模型剔除占位符、网页UI截图图标、纯文字版面扫描件、以及纯广告图，仅保留具有新闻现场感或有效意象的新闻主图。

阶段二（实证模型与特征重构）：
- 指令 2.1（部署视觉情感打分卡）：弃用论文中较过时的 Inception v3，改为引入具有高阶语义能力的开源多模态大模型（如 Qwen-VL 或 LLaVA），按 `{"sentiment": "negative/neutral/positive", "confidence": float, "is_salient": boolean}` 结构输出各有效图片的情感定性倾向。
- 指令 2.2（构建图文张量）：横向修改 `config.yaml` 的模块三输出结果，利用 `docid` 将 `TextPes` (语义层面悲观程度) 与 `PhotoPes` (视觉层面悲观程度) 完成内连接映射拼接。
- 指令 2.3（回归方程底座搭建）：重构核心回归方程代码簇：`Performance_i,t+1 = β1*PhotoPes_i,t + β2*TextPes_i,t + β3*(PhotoPes × TextPes)_i,t + Controls + ε` 并聚焦测试交互项符号是否显著为正（验证替代效应）。

阶段三（异质性结论挖掘）：
- 指令 3.1（实施眼球吸引效应测试）：从样本中切分出 `PhotoPes` 位于最高或最低10%（两端极值组）的分区定义为“凸显图片期”，并在代码上加入虚拟变量分组回归：验证在此区间内文本变量 `TextPes` 显著性丧失、视觉变量独占回归权重的假设。
- 指令 3.2（恐惧期冲击叠加）：截取银行同业拆借利率飙升期、股灾期间等高恐慌时刻进行分布检视。

3. 风险预案 (Plan B)：
- 致命卡点：版权或技术限制导致的“原始新闻数据集合完全不支持提取或抓取历史图片数据（缺失率极高）”。
- 补救方案 (Plan B)：若真实新闻图像物理不可得，则将研究重心转移至“广义排版与视觉显著性效应”。如定义 `Visual Salience（视觉张力特征）` 作为代理变量：
  ① 标题文字密集度 / 平均段落长度倒数。
  ② 富文本内是否标识并含有图表描述（"附图/图表揭示"）等排版元数据。
  ③ 感叹号与极端标点密度的几何学特征。
进而采用文本本身带来的“排版视觉冲击力”变量来替代“新闻图片”，依然能够论证核心由于视觉抓取注意力的机制，挽救整篇论文的故事框架。
