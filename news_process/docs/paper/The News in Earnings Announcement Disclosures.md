第一部分：基于参考论文的项目分析与诊断报告
（功能：学术与逻辑诊断。侧重 Why & What）

1. 范式映射与盲区诊断： 
Siano (2025) 的核心突破在于：抛弃传统NLP任务中对文本的主观离散情感分类（如正面/负面），转而通过为BERT架构添加线性输出层，进行连续的经济结果回归（预测股票CAR的大小与方向）。同时，他证实了“数字的上下文”（描述财务/业务数据的句子）以及“新颖内容”（与历史信息不重复的文本）蕴含着绝对的信息增量。
**当前项目盲区**：目前项目配置（如 `config.yaml` 所示）高度依赖大语言模型的离散判定标签（`21_tone_llms.py` 输出真伪与正中负情感）以及词袋架构的词典法（`22_words_tone.py`）。直接提取离散情感忽略了文本信息的**冲击幅度（Magnitude）**；同时，项目未对时间序列上的“公关稿复读”和“纯修辞无数字”的软文进行降权，这会导致提取出的金融科技信号包含大量缺乏实质经济增量的信息噪音。

2. 实质性改进项（宁缺毋滥）： 
- 改进 A：在自然语言提示以及文本输入前，引入序列层面的“文本新颖度（Novelty）”过滤机制与数值上下文注意力机制。
  -> [论文依据]：论文第5.3节（Table 8）指出，包含了具体数字表现的定量文本句子，以及与过去公告差异极大的“新颖句子”，其所含的市场反馈信息量（R2）是陈词滥调和非数值文本的两倍以上。
  -> [预期的边际贡献/解决的内生性问题]：可直接削减银行业通稿带来的严重测量误差（Measurement Error）。通过时序消重（剔除与过去3个月高度重复的新闻表述）和量化数值关注，能够提取出商业银行发生实质性金融科技动作（如具体投入金额、系统上线次数）的净信号，大幅提高核心自变量的信噪比。

- 改进 B：将 `23_tone_berts.py` 中的分类任务重构为预训练回归任务（Regression），直接对齐连续的外部指标。
  -> [论文依据]：论文第3.2与4.1节强调，带有线性损失函数并用于拟合短窗口股票回报（CAR）的BERT微调模型，完美克服了离散分类低估文本经济内涵的缺陷，其解释能力达到分类架构和非LLM机器学习算法的数倍。
  -> [预期的边际贡献/解决的内生性问题]：金融科技新闻的情感不单是好与坏，核心在于市场对其技术转型的真实反映幅度。通过将金融科技新闻向量直接映射或拟合至短窗口的异常波动或个体关注度连续数据，为下游的面板构建建立具备方向及强度的连续型“金融科技冲击（Tech-Shock）”变量。
  
- 【维持原状声明】：对于 `21_tone_llms.py` 模块中的第一阶段“语义真伪精筛”机制，鉴于现行流水线调用的是最新一代具有纯熟思维链（CoT）及零样本推理能力的大模型（GPT-5, Gemini 3），其定性能力已能有效识别金融科技复杂语境，该子模块在执行“真伪鉴别”逻辑上高度自洽，**坚决维持原状**，无需为迎合论文而对真伪分类器进行回归剥离。

3. 冗余剥离： 
明确指出，必须立即剔除基于词典的分析流（`22_tone_words.py`）及配套词典文件。
论文证据（Table 4 & Figure 1）无情地证明了：忽略词汇顺序上下文（Word context）的传统词典方法，其解释力不及深度学习大模型的十分之一乃至完全不显著。在已具备 API LLM 与本地 BERT 双轨运作的现有项目中，词典法不仅边际增量为零，还会因金融特定语境中的多义词导致极宽的置信边界与显著的系统性偏误。

第二部分：项目重构与优化执行计划书
（功能：工程落地指南。侧重 How，指令化语言）

1. 优先级排布： 
- 速赢项（Quick Wins）：禁用词典模块；更新大模型 Prompt 的权重导向，强制 LLM 关注定量描述。
- 核心攻坚项：嵌入“新闻时序新颖度（Novelty Score）”算法；深度重构 BERT 微调逻辑，从 CrossEntropy 分类切换至 MSE 回归输出。

2. 阶段化执行指令 (SOP)： 

阶段一（机制重塑/数据清洗）： 
- 动作指令 1（剥离）：修改 `config/config.yaml` 的 `sentiment_analysis.enabled_methods`，移除 `tone_words`；流水线总控脚本完全绕过阶段 22。
- 动作指令 2（Prompt 速调）：在 `21_tone_llms.py` 情感判断的 Prompt （`<step2_sentiment>`）中追加硬性约束：“请赋予包含具体业务数值、上线时间及投资额等「定量描述」段落更高评分权重；对缺乏定量支撑的纯概念铺陈进行降权。”
- 动作指令 3（新颖度特征计算）：在阶段12（`12_news_fintech.py`）输出后额外植入清洗函数，对目标银行 `target_bank` 每一条新闻基于发文时间戳与前序90天内该银行所有历史新闻计算 TF-IDF 余弦相似度，计算求其补集作为 `content_novelty_score` 并入后续计算流。

阶段二（实证/模型重构与检验）： 
- 动作指令 1（模型端改造）：重构 `23_tone_berts.py` 的顶层架构设计，将分类的 `num_labels=3` （正面/负面/中性）置换为 `num_labels=1` 的回归层（Regression Head），定义损失函数为 MSE。
- 动作指令 2（监督信号构建）：抽取新闻发生日 [0,1] 两个交易日的个股异常收益率绝对值或异常换手率（代表市场吸收信息强度）作为监督训练的目标标签（Target Label），微调后产生一个反映金融科技动作冲击烈度的连续变量并输出到最终 parquet 中。

阶段三（结论重构）： 
- 动作指令 1（变量交互）：在 `45_panel_export_main.py` 的面板汇聚中，带入求均值（或衰减求和）后的 `novelty_score`。
- 动作指令 2（引入动态环境检验）：顺应论文关于“整体不确定性较高时，文本更具增量价值”的发现，构建银行层面的“盈余低持续性”虚拟变量或宏观的 EPU（经济政策不确定性）环境指数，并在跨行和面板主回归方程里加入 `Fintech_News_Shock * Macro_Uncertainty` 的交乘项机制检验。

3. 风险预案 (Plan B)： 
- 致命卡点预判：如果中国银行业的新闻密度过高、大盘共线性太强，导致阶段二中由股票日频 CAR 形成的微调目标极其嘈杂不收敛，直接影响 BERT 训练。
- 替代方案（Plan B）：放弃外部股票数据配对微调步骤。转而在 `21_tone_llms.py` （阶段21）中改变 Json 结构，让原生顶配大模型在给出三个情感类别外，直接根据推理强制给出一个 `0.0~10.0` 区间的连续值指标 `impact_magnitude` （即基于文字语境判定该科技突破的绝对幅度），从而无损保留回归逻辑的测量优势。
