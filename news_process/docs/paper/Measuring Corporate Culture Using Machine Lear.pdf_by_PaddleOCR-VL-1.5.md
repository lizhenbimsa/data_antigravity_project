# 基于参考论文《Measuring Corporate Culture Using Machine Learning》的项目重构与优化执行计划书

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**论文核心机制**：Li 等提出采用半监督机器学习方法——局部词嵌入模型（word2vec），利用具有极低先验依赖的种子词（Seed Words）在目标语料空间中计算特征向量的余弦相似度，动态延展出语境高度契合的“文化词典”，并结合 TF-IDF 加权计数方法深度刻画公司的非结构化文本属性并量化。
**当前项目落差**：当前 `news_process` 项目在情感计算（`22_tone_words.py`）和主题字典过滤环节（`11_news_bank.py`, `config/fintech_dict.json`）严重依赖静态预设列表和外部现成学术词典（如 jiang_2021, yao_2021）。尽管后置了复杂的验证分析，但前端捕获依然是基于“词袋（BoW）匹配”。这种静态的查找方式剥离了词语间的分布式语义联系，导致面对如缩写、行话衍生或新闻特殊修饰搭配时不可避免产生覆盖遗漏（即被证明的“边际通过率问题”），缺乏捕获数据内生文本异质性的能力。

### 2. 实质性改进项（宁缺毋滥）
> - **改进 A：由“专家预设字典”向“词嵌入半监督自适应字典”平替**
>   - **建议细节**：加载项目内部独有的庞大金融媒体语料训练专用 Word2Vec 词嵌入网络。针对金融科技或多维面情感分别设定几组共识的核心种子词，提炼它们的高维质心向量，自动拓展寻找并召回被隐式表达的其他实质相关词汇。
>   - **论文依据**：参考论文应用 word2vec 模型在数百个模糊关联语境中发现了传统方法无法枚举的文化暗示短语组合。
>   - **预期的边际贡献**：彻底解决跨时间段新闻术语演化带来的词典退化假象，有效补全由于拼写变体、金融新词生造造成的低召回率漏洞。从根源上减弱研究中由于字典覆盖局限导致的度量偏误（Measurement Error）内生性。

> - **改进 B：重构计分体系：由“字面频率叠加”跃升为“动态特征相关距与 TF-IDF 共混加权”**
>   - **建议细节**：剥离现有使用固定常数的计分体系，以词嵌入余弦聚类相似度做为加权因子基准衰减，并深度融合词条在句子中的文档特定 TF-IDF （当前仅将 IDF 作为一次性全局预设修正）；将对新闻文本的判定转化为平滑分布的动态赋值 `Score = TF-IDF_i * CosSimilarity_i`。
>   - **论文依据**：论文在 Section 3.3 通过上述混合打分模型有效削弱了公关套话堆砌高频词所触发的高估影响，抵制了“廉价表述（Cheap Talk）”对指标效度的侵蚀。
>   - **预期的边际贡献**：能够大幅度抑制短新闻靠高浓度重复关键词造成的权重扭曲，准确区分稀缺核心术语与宽泛普通用语对主题或情感的边际贡献。

### 3. 冗余剥离
- **剔除静态词库堆叠模式与伪增强的联合评分基座**：在现阶段的情感模块中留存了过于分散交叠的各方现成情感词典集（存在权重0.5强制干预）。这种通过拼凑外部多异构学术词典来掩盖单项字典精度不足的“特征污染式叠加”，毫无严密的语汇一致性理论支撑。建议一并剔除这类缺乏本数据集适用性自证的非标定词库，改由语料驱动型向量延展单一专属字典进行直接替代。

## 第二部分：项目重构与优化执行计划书 (SOP)

### 1. 优先级排布
- **速赢项（Quick Wins）**：基于此前已被分词归一化清洗完的底层文本（`00_preprocessing.parquet`），直接跑批部署 Gensim 系统进行 Word2Vec 模型训练。生成专属语汇分布库无需波及现有验证链路。
- **核心攻坚项**：引入余弦匹配与混合计算机制替代原有的硬规则 Aho-Crosick 或直接字典匹配（对应 `22_tone_words.py` 和主题打分流程），实施底层映射函数的深度更换。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑/数据清洗）：构建与训练语料专属 Word2Vec 嵌入网络**
- **核心指令**：使用 python 中 `gensim.models.Word2Vec` 对于结构化预处理通过的语汇文本实施自监督训练，锁定 `vector_size=300`, `window=5`, `min_count=5` 等参数并开启 Skip-Gram 模型对齐原研究规范。
- **交付物标准**：输出金融短文本嵌入向量模型 `F_News_W2V_v1.model`，及生成在空间中聚集完整的上下文映射索引库。

**阶段二（实证/模型重构与检验）：半监督领域字典扩展及打分平滑接入**
- **核心指令**：在情感打分和科技筛选功能脚本内写入种子词抓取逻辑。分别输入如“创新、技术、云计算、违规、降级、突破”等纯度极高的种子，通过 `most_similar` 取余弦值 > 特定常量的关联扩展数组构成自适应词表。使用 `cosine_score * TF-IDF` 作为该词针对该新闻的最后实效得分，并做归一化相加。
- **稳健性检验标准**：重置执行 `37_dict_coverage_audit.py`，观察该连续数值法对于之前处于边界模糊（阈值为极度偏斜的命中数量 1 或 0）的文章的识别效变。执行一轮与原有被筛选极高置信度（High Confident）新闻的一致性相关测试校验新系统准确性下界。

**阶段三（结论重构）：多维度自回归校验**
- **核心指令**：通过计算替代版金融科技敏感度或者特定文本环境的“焦点因子值”，复用后游面板数据汇总回归链路，出具具有创新理论背景强背书且不依赖生硬第三方数据字典的完整报告输出。

### 3. 风险预案 (Plan B)
- **致命卡点预判**：特定新闻类型的口径或者术语表达过于离散导致自适应训练的词嵌入向量图谱发生混叠（比如由于短文本语境断裂造成不同倾向的词强制拉近距离），最终生成一堆高信噪比垃圾扩展词。
- **替代方案 (Plan B)**：放弃完全半监督自推导生成，实行带有约束框架的“监督型向量膨胀”（Supervised Embedding Inflation）。即将学术界原有高认可字典强标定到空间极点中心防止其偏移，仅对那些高关联核心词外侧 1 步内的近亲特征进行小心试探拓展以补齐由于分词切碎或者词尾变化导致的死角遗漏，稳妥兼顾创新性和数据平稳性。
