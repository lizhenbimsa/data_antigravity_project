# 基于《Going digital: implications for firm value and performance》的项目审计与执行计划

=========================================
## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**范式映射**：
参考论文的核心机制在于发现：非科技企业（如银行）的数字化活动（Digital Activities）通过信号传递（传递未来生产力提升的预期）显著提升了市场估值（M/B），且这种效应尽管在短期基本面上（如利润率与销售增长）缺乏即时兑现，但从长期来看能带来显著的异常收益。
**当前项目盲区**：
- **指标降噪盲区**：当前 `news_process` 项目高度依赖提取高频的连续数值（如频次、提及量等），忽视了文本度量中极高的异方差与长尾噪音。论文明确点出并采用“三分位序数化（Quantized Terciles）”机制过滤噪音，这是我们极度欠缺的手段。
- **时间动态（持续性）盲区**：项目多偏向年度横截面提取，忽视了“持续披露（Continuing Disclosure）”机制（即持续三年披露才是估值定价的核心条件），缺乏跨年时序持久性的刻画。
- **维度定义割裂**：当前项目中的 `fintech_dict.json` 偏宽泛，而该论文提供了一个经过同侪审议的、严密的七维科技划分标准（Analytics, Automation, AI, Big Data, Cloud, Digitization, Machine Learning），更贴近“数字化（Going Digital）”的核心本质。

### 2. 实质性改进项（宁缺毋滥）
- **改进 A：引入三分位量化指数（Quantized Digital Score）与连续披露度量（Persistent Disclosure）**
  - **论文依据**：论文采用 0-3 编码的三分位分数应对原始词数的高噪音，并在投资组合回报预测中指出，三年持续高频披露组（Continually Disclose High Levels）才有显著的超额收益。
  - **边际贡献**：极大缓解绝对词频度量带来的偏度与离群值干扰，解决“单次事件炒作事件”与“实质性战略转型”的内生性区分问题，增强数字化变量在下游价值回归模型中的经济学稳健性。

- **改进 B：被解释变量的资本化约束剥离（Capitalization Restrictions Controls）**
  - **论文依据**：由于金融与非科技企业的研发及数字化投入往往计入当期费用（SG&A）而非资本化，这人为推高了市净率（M/B）。论文证明通过加入控制或使用保守会计纠正（Conservatism-Corrected M/B），可以剥离 25% 的伪增长。
  - **边际贡献**：填补项目下游实证时的核心遗漏变量问题，利用财务变量控制（甚至通过仪器变量暴露度）确立数字化转型真正“新增”的价值属性，满足顶刊关于无形资产价值评估的严苛要求。

### 3. 冗余剥离
- **明确剥离项**：大幅精简并剥离阶段22“复杂词典法情感”与阶段23“多重BERT模型堆叠情感”管线，全面让位于“阶段21（大模型事实核实）”。
- **冗余原因**：论文结果表明，新技术的资本市场反应（ERC响应与估值提升）主要是由 **“采纳事实的发生本身（活动披露的频次和强度）”** 驱动的（投资者追求成长机会红利），而并非媒体文本表面上的细微褒贬。维持一套具有几十种程度副词、复杂转折倒装处理以及 5 种不同 BERT 模型混合的情感判别管线，存在严重的过度设计（Over-engineering），它与“识别数字化本质价值”的核心逻辑脱节。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：在面板数据（阶段4x）融合阶段，立刻执行数据降噪，新增三分位与持续性指标。清理剥离冗余的传统情感代码计算，大幅降低运算算力损耗。
- **核心攻坚项**：底层知识库（fintech_dict.json）按论文提出的七大核心底层技术范式重组；下游回归模型补充保守型财务约束控制变量体系。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑与数据清洗）：**
1. **重构底层概念树**：更新/重写 `fintech_dict.json`，在现有架构之上抽离或映射出论文明确指配的七大维度：`[Analytics, Automation, AI, Big Data, Cloud, Digitization, ML]`。
2. **切除伪需求**：在 `config.yaml` 中将 `sentiment_analysis.enabled_methods` 中的 `tone_words` 与 `tone_berts` 移除。依靠现有的 `tone_llms` 执行精梳理实事（判定真伪数字化落地）。

**阶段二（面板层指数重构与稳健特征提取）：**
1. **三分位离散化指派**：在 `45_panel_export_main.py` 等数据拼装代码中，对于银行每年的 Fintech 提及度得分（或文章数），根据当年的总体分布，计算四分位/三分位切分。添加构建新列 `Quantized_Fintech_Score` (取值0, 1, 2, 3)。
2. **长期韧性指标（Persistence Index）**：在面板生成后，通过窗口函数向后滚动 3 年，生成长效标识列 `Persistent_3yr_Adopter`（即过去连续三年 `Quantized_Fintech_Score >= 2` 的银行赋值为 1，否则为 0）。

**阶段三（检验与下游回归重配）：**
1. **估值指标净化指引**：明确向实证回归模块输出指标要求——下游执行价值（Firm Value/Tobin's Q等）面板回归时，必须强制将 SG&A（以及作为代理变量的 IT 高管比例）纳入基准控制变量。有条件时加入保守会计系数纠正的账面价值（Conservatism-corrected Equity）。

### 3. 风险预案 (Plan B)
- **预判卡点**：三分位降噪技术（Quantization）可能会在银行这一高度同质化的寡头样本（只有几十到百余家银行）中导致面板内过度平滑，抹杀有效变异，造成固定效应回归系数不显著。
- **替代方案**：如果三分位变量缺乏统计解释力，弃用硬切分，改用 `Log(词频 + 1)` 或文章中使用的基于**AI专利的行业间技术暴露度（Technology Exposure via Title/Abstract embeddings）**构建工具变量（IV），进行两阶段（2SLS）因果识别。
