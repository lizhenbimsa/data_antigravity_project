# 基于 "FinBERT: A Large Language Model for Extracting Information from Financial Text" 的项目诊断与执行计划

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**论文核心机制**：论文严密论证了经过金融领域文本（如财报、分析师报告、电话会议纪要）预训练的大语言模型（FinBERT）在解决金融文本情感分类任务时，显著优于传统的 Loughran-McDonald (LM) 词典法和非领域相关的机器学习/深度学习模型（如 NB, RF, LSTM 以及 基础版的 BERT）。其核心优势不仅体现在高准确度（88.2%），更体现在即使面对极小规模训练样本（10%子集）仍具备卓越性能，以及在处理多义金融特定词汇（Finance Vocabulary）时的强上下文理解能力。

**当前项目盲区**：审查项目 `news_process` 当前现状发现，管线中同时混杂着基于传统词典的特征抽取脚本（如 `22_tone_words.py` 及其覆盖率测试 `37_dict_coverage_audit.py`）与预训练语言模型打分模块。这种混合结构忽视了 FinBERT 已经能够“降维打击”传统词袋模型的既定事实，导致在文本分析阶段引入了词典法的固有测量误差（例如孤立截取文本、忽略上下文导致的高 Type II 误差），使得情感变量的测度掺杂了噪音，且增加了后期管道维护成本。

### 2. 实质性改进项（宁缺毋滥）
> - **改进 A：全面废弃词典情感法，将基础情感测度引擎整体重构为单一的 FinBERT 架构** 
>   - **论文依据**：表1（Table 1）表明 FinBERT 对比 LM 词典在准确率上具备压倒性优势（88.2% vs 62.1%），更显著地在“负面情感”召回率（89.7% vs 49.5%）上表现优异。
>   - **预期的边际贡献/解决的内生性问题**：彻底消除因多义词泛化导致的语义误判内生噪声。量化金融指标对负面情感更敏感（Loughran and McDonald 2011的理论），更精准的负向情感识别将大幅提升回归检验中情感指标与市场异常收益率（CAR）之间的 explanatory power，提升因果推断可信度。

> - **改进 B：扩展 FinBERT 的小样本领域任务迁移（如 ESG / 特殊金融主题分类）** 
>   - **论文依据**：表2及第4节（Table 2 & 5）证明，即便仅使用 10%-20% 的领域标签小样本进行微调，FinBERT 的测试准确度依旧领跑其他使用全量数据的模型。
>   - **预期的边际贡献/解决的内生性问题**：打破在特定子主题（如 ESG或管理层意图识别）分析中严重依赖大规模人工标注数据的困局，极大地降低新特征衍生的工程成本并保持分类稳健性。

### 3. 冗余剥离
**伪需求判断**：项目当前维护的词典级方法（`22_tone_words.py`, `37_dict_coverage_audit.py` 等依靠文本遍历与正负面字典匹配的模块）在 FinBERT 的上下文表征面前已被证伪且缺乏实证有效性。
**剔除建议**：直接剔除所有涉及硬编码词典维护与静态词频统计的情感计算流水线节点，全面转向依托 LLM 权重的向量计算，实现工程化极简。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：
  剥离无效代码资产，删除传统词典法情感测度脚本；接驳并切换 HuggingFace 上的开源 FinBERT 权重并跑通测试流水线。
- **核心攻坚项**：
  针对实际长篇文本构建切割与集成聚合逻辑（应对 BERT 的 512 Tokens 限制）；更新面板数据生成逻辑，重构并验证新的 FinBERT 情感衍生因子对于后续市场响应验证的边际改善性。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑/数据清洗）：**
- **动作指令**：
  1. 将文件目录中的 `22_tone_words.py` 与 `37_dict_coverage_audit.py` 从管线依赖（`run_pipeline_function.py` 等调度）中剔除或做废弃标记。
  2. 审查 `config.yaml` 或工程环境变量，保证禁用所有静态金融情感词典的预加载进程。
- **交付物**：一套全面告别词袋依赖、更为精简的初始化数据流配置。

**阶段二（实证/模型重构与检验）：**
- **动作指令**：
  1. 重构并升级涉及 BERT 模型的脚本（如 `23_tone_berts.py` / `21_tone_llms.py`），绑定至开源金融预训练模型（如 `yiyanghkust/finbert-tone` 或类似最优权重）。
  2. 针对超长新闻和分析师报告，引入基于段落句子的批量截断分割（Sentence Splitting），执行逐句 Inference 并根据句群得分进行加权汇总，以防丢失上下文。
  3. 利用少量标注样本针对其他维度（如 ESG 等细分分类）验证 Fine-tuning 流程。
- **验证标准**：通过计算抽取得到的负向情感（Negative Sentiment）样本占总体样本分布的比率和置信度，验证识别精度显著高于改造前；完成 `34_tone_validation.py` 中预测有效性的稳健性检验。

**阶段三（结论重构）：**
- **动作指令**：
  1. 基于新的情感特征池，重组最终的面板数据输出（`41_panel_encode_aggregate.py`, `45_panel_export_main.py`）。
  2. 参照论文中市场反响（Market Reaction）回归模型执行对比验证，预期获得相比传统方法更高的超额收益联合解释度（Higher R-squared/Vuong test）。

### 3. 风险预案 (Plan B)
- **致命卡点预判**：将所有语料推入底层大模型 FinBERT 推理可能带来暴涨的显存压占用与极高的运算算时，导致批处理作业内存溢出 (OOM)。
- **替代方案 (Plan B)**：
  1. 降级为半精度计算（FP16/BF16 推理）加快吞吐。
  2. 若设备计算瓶颈导致依然无法覆盖全局语料，采用截断筛选方案，仅对新闻文本的核心摘要或首尾各前两个段落进行 FinBERT 打分，放弃高成本的全局逐句推断，以牺牲部分长尾精度换取可行性。
