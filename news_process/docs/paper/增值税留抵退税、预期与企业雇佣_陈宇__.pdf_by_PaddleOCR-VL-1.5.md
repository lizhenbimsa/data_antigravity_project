# 增值税留抵退税、预期与企业雇佣_执行计划

## 第一部分：基于参考论文的项目分析与诊断报告

**1. 范式映射与盲区诊断：**
- **核心机制映射**：参考论文《增值税留抵退税、预期与企业雇佣》的核心机制在于：政策本身通过“政府预期管理（新闻发文数量度量）”起到极大的放大作用，并且利用企业文本（年报前瞻积极词汇）度量的“预期和信心”作为关键中介机制。
- **项目真实落差**：当前 `news_process` 项目具备了顶尖的情感大模型和词汇覆盖（如 `config.yaml` 中配置了详细的 `forward_looking_words` 及媒体评分），但**盲区在于缺乏将“官方宏观政策新闻发布量”作为交互项（预期管理机制）引入面板回归体系**；同时已有情感配置未能有效拆分出“行业信心预期”这一具有高度解释性的中间变量体系。

**2. 实质性改进项（宁缺毋滥）：**

> - **改进 A：[构建“政策/监管的官方媒体沟通预期管理”指数作为放大器交互项]** -> [标明论文依据：第六部分 “政府预期管理：政策效果的放大器”，利用新闻报道数量刻画预期管理影响政策]。 -> [预期的边际贡献/解决的内生性问题：当前面板数据使用DID评估金融科技政策（如DCEP沙盒等），这属于静态冲击。本改进建议调取流水线在特定省份/城市对特定政策的央媒、官媒密集报道发文量对数（Ln_Gov_News_Volume），构建“DID × 预期管理”模型框架，解决由不同地区对政策推行沟通力度差异所带来的遗漏变量内生性偏差。]

> - **改进 B：[激活并升维词典系统，剥离出独立的“金融科技预期信心”机制变量]** -> [标明论文依据：第四部分（四）机制检验中的 “3. 企业预期”，通过积极消极词典计算语调 Tone，证实政策通过提振预期产生影响]。 -> [预期的边际贡献/解决的内生性问题：项目由于在 `config.yaml` 已经构建了极高学术质量的 `forward_looking_words` 以及相应的情感极性设置。要求流水线增加提取银行的“战略前瞻语气（Expected_Tone）”，将其构建为中介检验变量，有效连接“政策外部压力-银行认知及预期转变-科技投入绩效”，使得故事线的微观认知基础更加详实与符合顶刊。]

**3. 冗余剥离：**
- **明确剔除项**：论文中有关所有制性质（如国有 vs 非国有银行的融资困境和流动性约束机制）分析更贴合制造业等一般企业对税退的渴求度，在银行进行数字化转型的研究情境中牵强附会（银行属于流动性经营机构，一般不以传统意义的主流实体流动性视角评价其对一项宏观科技监管政策的采用）。必须明确在当前项目中**舍去这种生搬硬套的流动性约束解释**，坚决回归对媒体新闻发文密度与文本结构本身挖掘的机制创新。

## 第二部分：项目重构与优化执行计划书

**1. 优先级排布：**
- **速赢项（Quick Wins）**：基于项目现有代码及 `22_tone_words.py` 等脚本的基础，直接增加提取 `Tone_Expectation` （基于文本正面/负面及 `forward_looking_words` 计算预期指数的占比与极性分数），随年度聚合输出至 `40_panel_yearly.parquet` 中。
- **核心攻坚项**：为配合论文中的“放大器机制”，需要开发单独的脚本清洗聚合关于“特定金融科技政策”的官方引导性新闻报道量统计值（Log计数），在面板组装模块并表从而构造交互变量。

**2. 阶段化执行指令 (SOP)：**

- **阶段一（机制重塑与底层指标衍生——短期速赢阶段）：**
  - 使用 Python 和 NLP 词典清洗逻辑，扫描 `22_words_tone.parquet` 中的行级特征。
  - 单独隔离提取出银行被涉及新闻中包含的“前瞻性/宏观预期积极词汇”的数量与比例，构建新的中间变量名 `Bank_Fintech_Expectation_Tone`。
  - **交付物标准**：年度主面板必须新增带有合法性的预期特征列。

- **阶段二（调节变量“预期引导（Gov_Exp_Mgt）”的数据合并）：**
  - 核心动作指令：根据新闻发样（如报纸级、省份级的政策宣发计数），为每个省（或年度）统计政府/央媒向市场传达的相关政策报道数量求取平滑对数，即 `Ln_Policy_Exp_Management`。
  - **交付物标准**：提供能够无缝连接主要银行面板的 `Bank_Geographic_Policy_News_Merged` 交互项数据框，数据层面必须体现该指数非0的基础区分度。

- **阶段三（结论重构实证命令导出）：**
  - **核心动作指令**：升级 Stata 的 Do 文件或 Python Statsmodels 回归导出脚本。
  - 中介方程建立指令：使用 `Bank_Fintech_Expectation_Tone` 作为被解释变量，以评估核心科技冲击对银行“预期信心”的正向确信度。
  - 调节方程建立指令：主结果回归引入交乘核心项：即使用 `DID × Ln_Policy_Exp_Management` 以确认政策宣读广度是否有乘数放大效应。

**3. 风险预案 (Plan B)：**
- **致命卡点预判**：特定区域（部分省市）如果有关该类政策的新闻报道被爬虫系统遗漏，导致零值极多（Sparse Data），在处理取对数时大量缺失导致交互项不可得，降低统计效力。
- **替代方案 (Plan B)**：
  如果是由于省际层面的传播量太稀疏而无法进行微观化分解，则必须放弃地理精细维度的预期管理。转而利用**时间维度**的宏观“信息波动周期密度（央行沟通或国家级媒体对于特定时段对创新的支持性宣传发文频密窗口，如月度滚动的加权新闻集中度）”与个体异质性构建交互冲击影响来测试替代效应，并在发文前通过正交化提取核心信息。
