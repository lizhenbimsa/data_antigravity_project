## 1. 范式映射与盲区诊断

### 1.1 论文核心机制提炼

Chiu & Hung (2025) 的核心创新链条为：

```
长文本 MD&A → AI 驱动两步摘要(LongT5) → 领域微调 LLaMA 2 情感分析 → BHR/CAR 实证检验
```

**三大核心机制**：

| 机制 | 论文具体做法 | 核心发现 |
|------|------------|---------|
| **M1: AI 摘要预处理** | LongT5 两步迭代摘要（滑动窗口→聚合），将 ~9000 词压缩至 ~65 词（压缩率 0.72%） | 全文直接输入 LLM 错误率 >93%；两步摘要后准确率提升至 70.2%，处理时间降低 >95% |
| **M2: 领域微调 LLM** | LLaMA-2 7B + LoRA (r=8, α=32) 微调，融合 FPB + TFNS + CS 三类金融情感数据集 | LLaMA-2 (E5) 年化 BHR 12.37%，显著优于 FinBERT (5.98%) 和最佳传统方法 (7.14%) |
| **M3: Bayesian 后验不确定性** | Dirichlet-Bayesian 框架，迭代抽样 500 次更新后验，量化模型在三类情感上的概率倾向 | 模型对模糊文本倾向 Neutral 分类，揭示了系统性保守偏差 |

### 1.2 当前项目现状映射

| 论文机制 | 当前项目对应模块 | 差距判定 |
|---------|----------------|---------|
| **M1: AI 摘要预处理** | ❌ **缺失**。21_tone_llms.py 直接以全文/上下文片段输入 LLM，未经摘要压缩 | **实质落差** — 论文证明全文直接输入 LLM 错误率 >93% |
| **M2: 领域微调 LLM** | ⚠️ **部分覆盖**。项目使用 GPT-5 Nano / Gemini 3 / GLM-4.5 三模型多数投票，但均为通用 LLM，未进行金融情感领域微调 | **理论落差** — 通用 LLM 缺乏 price-directional 情感捕获能力 |
| **M3: Bayesian 不确定性** | ❌ **缺失**。项目仅有置信度分数 (0-1) 和多数投票一致率，无概率后验分布 | **方法论落差** — 缺乏模型不确定性的系统性量化 |
| **BHR/CAR 经济价值检验** | ❌ **缺失**。项目聚焦于面板回归和 DID 因果识别，无交易策略回测 | **维度落差** — 缺乏情感信号经济价值的直接检验 |
| **传统方法 + 摘要对照** | ✅ **已覆盖**。22_tone_words.py (5 套词典 + IDF 加权) + 23_tone_berts.py (5 个 BERT 模型) 提供了充分的传统基线 | **维持原状** — 项目在此维度已优于论文 |
| **双轨 (全文 vs 上下文)** | ✅ **已覆盖**。21_tone_llms.py 双轨模式 (_full / _ctx) 已实现全文与片段对照 | **维持原状** — 项目已具备类似论文"全文 vs 摘要"的消融结构 |
| **三角验证** | ✅ **已覆盖且优于论文**。LLM×3投票 + 词典×5 + BERT×5 = 13路交叉验证 | **维持原状** — 项目验证体系远超论文 |

### 1.3 盲区诊断总结

> [!IMPORTANT]
> **核心盲区**: 当前项目缺乏论文的核心创新——**AI 驱动摘要预处理层**。论文实证表明，这一层是 LLM 情感分析从"不可用"（93% 错误率）到"可用"的关键转折点。虽然项目使用的 GPT-5 Nano 等模型上下文窗口远大于 LLaMA 2 (4096 tokens)，但中文新闻平均内容长度约 2000-5000 字（约 3000-7500 tokens），仍存在信息过载和注意力稀释问题。

## 2. 实质性改进项（宁缺毋滥）

### 改进 A：引入 AI 驱动摘要层（Summarization-First Pipeline）

- **具体建议**: 在 `21_tone_llms.py` 的 LLM 情感分析前插入一步 AI 摘要预处理，生成 content_summary 列。形成三轨对照：`_full` (全文) / `_ctx` (上下文片段) / `_sum` (AI 摘要)。

- **论文依据**: 
  - Table 1: 两步摘要将平均词数从 8972 压缩至 65，cosine similarity 0.4257 仍保留核心信息
  - Table 3 Panel B: 摘要文本在**所有**传统方法上均产生显著更高的 BHR（Diff_LM: 12.46%***, Diff_RF: 16.70%***）
  - §2.2: 全文直接输入 LLM 错误率 >93%，单步摘要仅 33%，两步摘要 70.2%

- **边际贡献**: 
  1. 解决长文本"注意力稀释"问题——即使现代 LLM 上下文窗口足够长，信息密度仍影响情感判断精度
  2. 摘要文本可同时提升词典法和 BERT 的情感判断准确率（论文 Table 3 Panel B 已实证）
  3. 提供额外的消融维度，强化"信息蒸馏 vs 信息损失"的学术贡献

### 改进 B：构建 Bayesian 后验不确定性量化框架

- **具体建议**: 对 LLM 情感分析结果构建 Dirichlet-Bayesian 后验估计，量化模型在三类情感（正面/中性/负面）上的概率分布偏差。

- **论文依据**:
  - §2.1 及 Fig. 2: LLaMA-2 的 Bayesian 后验分布揭示模型对 Neutral 的系统性偏好（模糊文本 → 保守分类）
  - Table B3: 模型在混合情感线索下倾向 Neutral 分类

- **边际贡献**:
  1. 将当前项目的"点估计置信度"升级为"完整后验分布"，使审稿人可评估模型不确定性
  2. 揭示 GPT-5 Nano / Gemini 3 / GLM-4.5 各自的 sentiment bias（是否同样存在保守偏差），构成 model heterogeneity 的实证材料
  3. 为 39_prompt_sensitivity.py 提供概率空间的补充视角

### 改进 C：增加 BHR/CAR 经济价值检验模块

- **具体建议**: 构建情感信号驱动的 BHR 交易策略回测模块，按情感信号做多/做空，计算 1 周至 1 年的买入持有收益。

- **论文依据**:
  - Table 3: LLaMA-2 BHR_1y = 12.37%，FinBERT = 5.98%，传统方法最佳 7.14%
  - Table 4: CAR[0,5] 回归系数 0.0020***，t-stat = 2.67

- **边际贡献**:
  1. 将当前面板回归（β系数 → 统计显著性）升级为"经济显著性"的直接检验
  2. 如果项目的三路情感（LLM/词典/BERT）在 BHR 上产生差异化表现，可构成方法论比较的核心证据
  3. 满足 JFE/RFS 级期刊对"out-of-sample predictability"的标准要求

## 3. 冗余剥离

| 模块 | 判定 | 理由 |
|------|------|------|
| `22_tone_words.py` (5 套词典 + IDF 加权 + 语言学规则) | ✅ **保留** | 论文 Table 3 证明词典法在摘要文本上仍有价值 (LR_SUM_TONE: BHR_1y = 7.14%)。当前项目的词典法实现已远超论文基线（5 套词典 vs 论文仅 LM 词典），且 IDF 加权（Gentzkow et al., 2019）是论文未涉及的稳健性增强。 |
| `23_tone_berts.py` (5 个 BERT 模型双轨推理) | ✅ **保留** | 项目已实现论文的 FinBERT 基线对照，且额外提供了 4 个中文金融 BERT 模型的交叉验证，是论文框架的自然扩展。 |
| `34_tone_validation.py` (Cronbach's α 交叉验证) | ✅ **保留** | 三角验证框架是项目的核心学术护城河，论文无此设计。 |
| `38_media_diversity.py` (媒体多样性审计) | ✅ **保留** | 论文未涉及媒体来源异质性，是项目独特的方法论贡献。 |
| `39_prompt_sensitivity.py` (Prompt 敏感度测试) | ✅ **保留** | 基于 Carlson & Burbano (2026, SMJ) 的方法论要求，是项目的稳健性检验亮点。 |

> [!NOTE]
> **结论**：当前项目无需剔除任何模块。项目在验证体系、词典深度、BERT 多样性等维度已明显优于参考论文。需要的不是"减法"而是精准的"加法"——补齐摘要层、不确定性量化和经济价值检验三个维度。

## 2. 阶段化执行指令 (SOP)

### 阶段一：AI 摘要层构建（机制重塑）

**核心动作指令**：

1. **新建 `20_summarization.py`**
   - 定位：插入于 `12_fintech_news.py` 之后、`21_tone_llms.py` 之前
   - 功能：对每篇新闻的 `内容` 字段生成 AI 摘要
   - 摘要方法选型（按优先级）：
     - **方案 A（推荐）**: 利用项目已有的 LLM API（GPT-5 Nano / Gemini 3），使用专门的摘要 Prompt（"请将以下金融新闻压缩为 50-100 字的核心摘要，保留关键实体、数字和情感信号"）
     - **方案 B（论文原始）**: 部署 LongT5 (long-t5-tglobal-base-16384-book-summary)，两步迭代摘要
   - 输出列：`content_summary` (AI 摘要)、`summary_compression_ratio` (压缩率)、`summary_cosine_similarity` (与原文余弦相似度)

2. **修改 `21_tone_llms.py`** — 扩展为三轨模式
   - 在现有双轨 (`_full`, `_ctx`) 基础上增加 `_sum` 轨道
   - 新增输出列：`llm_verified_sum`, `llm_sentiment_sum`, `llm_agreement_rate_sum`
   - 多数投票逻辑完全复用现有 `_aggregate_track()` 函数

3. **修改 `22_tone_words.py` 和 `23_tone_berts.py`** — 增加摘要轨道
   - 新增基于 `content_summary` 的情感计算
   - 输出列增加 `_sum` 后缀变体

**交付物标准**：
- `20_summarization.py` 可独立运行，产出 `20_summarization.parquet`
- 摘要平均长度 50-100 中文字（参照论文的 ~65 词英文摘要等价标准）
- 全量数据摘要完成时间 < 4 小时（利用异步并发 API）

### 阶段二：Bayesian 不确定性量化与模型校准（实证检验）

**核心动作指令**：

1. **新建 `35_bayesian_calibration.py`**（或扩展现有 `34_tone_validation.py`）
   - 实现 Dirichlet-Bayesian 后验估计：
     ```
     Prior: Dir(α₀) = Dir(1, 1, 1)  # 均匀先验
     For each batch b = 1...B:
       Sample 500 texts with replacement
       Observe (n_pos, n_neu, n_neg) from LLM predictions
       Posterior: Dir(α₀ + n_pos, α₀ + n_neu, α₀ + n_neg)
     ```
   - 对每个模型（GPT-5 Nano / Gemini 3 / GLM-4.5）独立计算后验分布
   - 生成类似论文 Fig. 2 的后验分布可视化

2. **校准检验**：将后验分布与人工标注样本（`32_human_samples.xlsx`）对比
   - 计算 Expected Calibration Error (ECE)
   - 输出 reliability diagram

**交付物标准**：
- 每个模型的后验分布图（正面/中性/负面三类概率密度）
- 模型间 sentiment bias 比较表
- ECE < 0.10 视为校准通过

**稳健性检验标准**：
- 三个模型的后验分布形状应定性一致（同方向偏差）
- Bootstrap 95% CI 覆盖率检验

### 阶段三：BHR/CAR 经济价值检验（结论重构）

**核心动作指令**：

1. **数据准备**：
   - 需要银行股票日收益率数据（来源：CSMAR / Wind / CNRDS）
   - 映射 `target_bank` → 股票代码 → 日收益率序列
   - 计算市场调整超额收益

2. **新建 `52_economic_value_test.py`**
   - 实现论文 §4.1 的 BHR 策略：
     - 情感 = 正面 → t+1 日收盘价买入，持有 {1周, 2周, 1月, 3月, 6月, 1年}
     - 情感 = 负面 → t+1 日收盘价做空
     - BHR = Σ(正面组收益) - Σ(负面组收益)
   - 实现论文 §4.2 的 CAR 回归：
     - CAR[0,T] = α + β₁·Sentiment_Tone + β₂·Controls + Year_FE + Industry_FE + ε
     - T ∈ {1, 2, 3, 4, 5}
   - 分别对三轨 (_full, _ctx, _sum) × 三方法 (LLM, 词典, BERT) 执行

3. **稳健性子样本**：
   - 市场波动期 vs 平稳期（参照论文 §4.3 的 2000-2009 子样本）
   - 大盘股 vs 小盘股

**交付物标准**：
- BHR 结果表（类似论文 Table 3）
- CAR 回归结果表（类似论文 Table 4，含 Year & Industry FE）

## 3. 风险预案 (Plan B)

### 风险点 1：AI 摘要长度控制不稳定

- **症状**: LLM 摘要可能生成过长（>200字）或过短（<20字）的文本
- **Plan B**: 
  - 在 Prompt 中明确字数约束（"严格控制在 50-100 字"）
  - 后处理截断：若超过 150 字则截断取前 100 字
  - 若 LLM 摘要效果不佳，回退到 TextRank 抽取式摘要（无需 API 调用）

### 风险点 2：Bayesian 采样计算代价过高

- **症状**: 500 次采样 × 多个 batch 的迭代更新耗时不可接受
- **Plan B**: 
  - 使用已有的 LLM 输出数据（21_tone_llms.parquet 中已有每个模型的独立判断），无需重新调用 API
  - 直接在保存的判断结果上计算频率分布，等价于 Bayesian 后验的最大后验估计

### 风险点 3：股票收益率数据不可得

- **症状**: CSMAR/Wind 数据库访问受限，无法获取银行个股日收益率
- **Plan B**: 
  - 使用 Tushare/AKShare 开源接口获取 A 股银行板块数据
  - 若个股数据完全不可得，使用银行板块 ETF（如 512800）作为代理
  - 退化方案：将 BHR/CAR 降级为"方法论附录"而非主检验，面板因果回归仍为主体

### 风险点 4：摘要信息损失过大导致情感判断失准

- **症状**: 压缩率过高（<1%），摘要丢失关键情感线索
- **Plan B**: 
  - 论文已证明 cosine similarity ~0.43 仍可保留定价信息
  - 若中文新闻摘要效果不佳，调整压缩目标为 100-200 字（而非论文的 65 词）
  - 保留 _full 和 _ctx 轨道作为消融基线，即使 _sum 轨道效果不佳也不影响主结论
