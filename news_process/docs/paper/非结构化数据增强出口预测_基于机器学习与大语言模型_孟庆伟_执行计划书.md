### 1. 范式映射与盲区诊断

#### 1.1 论文核心范式

孟庆伟等 (2026) 提出的核心研究范式为 **"机器学习 + 高维结构化数据 + LLM 处理非结构化数据"**，其技术架构可拆解为四个层次：

| 层次 | 论文方法 | 核心创新 |
|------|---------|---------|
| **数据构建** | 263个结构化指标 + 4.7万条研报语段 | 三维度（国内供给/国际需求/全球贸易形势）高维特征空间 |
| **特征筛选** | 层次聚类(Spearman距离) + 弹性网稳定性选择(100次bootstrap) | 263 → 120 → 弹性网动态阈值（T+1: 0.90, T+3: 0.85, T+6: 0.80） |
| **LLM指标构建** | DeepSeek V3.1-671b, temperature=0, [-100,100]连续评分 + 四维度权重评分标准 | ICC人工验证(0.85) + 时间掩码前视偏误检验(ICC=0.96) + 跨版本复现(ICC=0.95) |
| **机制分析** | **残差正交化** (Residual Orthogonalization): LLM_t = g(X_{t-1}) + ε_t | 将LLM情感分解为"宏观可解释部分"与"经验性残差"，证明增量信息的来源 |

#### 1.3 核心盲区判定

经逐项比对，项目存在 **两个实质性盲区** 和 **一个伪需求**：

**🔴 盲区 A — 残差正交化机制分析（论文 §五(四)，公式 3-4）**

这是本论文最具方法论创新性的贡献。论文证明：

$$LLM_t = g(X_{t-1}) + \varepsilon_t$$

其中 $\varepsilon_t$ 为"经验性残差"——即结构化宏观指标无法解释的、源自分析师主观判断的增量信息。**这部分残差才是 LLM 增强预测能力的真正来源。**

**对本项目的适用性：** 在 Bank-Year 面板回归中，LLM 情感得分 `llm_vote_tone` 可能同时反映了：
1. 银行基本面（ROA/NPL/资本充足率等）已经包含的"可解释部分"
2. 纯粹的媒体情感效应（"经验性残差"）

如果不做正交化分解，`llm_vote_tone` 的回归系数可能混淆了基本面信息通道和纯情感信息通道，导致 **机制不清晰、内生性争议难以消解**。

**🟡 盲区 B — 时间掩码前视偏误检验（论文 §四(三).3.(1)）**

论文使用掩码方法将语段中所有年份/月份替换为"XX年XX月"，验证 LLM 评分不依赖时间信息（ICC = 0.96）。

**对本项目的适用性：** 当 LLM 对新闻文本评分时，若文本包含"2023年一季度"等时间标记，LLM 可能隐式利用其训练语料中的后续知识（如 2023Q1 后的银行危机事件）来影响评分，构成 **前视偏误 (look-ahead bias)**。该检验可作为 `34_tone_validation.py` 的稳健性扩展。

**🟢 伪需求 — SHAP 特征重要性分析**

论文的 SHAP 分析服务于 XGBoost 预测框架的可解释性。本项目的核心为 **面板固定效应回归**，系数本身即为可解释性指标（"1σ LLM 情感变化对应 β 个单位因变量变动"）。引入 SHAP 将偏离项目因果推断主线，**建议剔除，维持原状**。

### 2. 实质性改进项（宁缺毋滥）

#### 改进 A：残差正交化 — 分离 LLM 情感的"基本面通道"与"纯媒体通道"

- **具体修改建议：** 在 `43_panel_indicators_geography.py` 的综合指标计算步骤后，新增 **残差正交化模块**：
  1. 将 `llm_vote_tone_full` 作为因变量
  2. 将银行基本面控制变量（若面板中已含 ROA/NPL/CAR 等财务指标）作为自变量
  3. 在每个年度截面内执行 OLS 回归
  4. 提取残差 `llm_tone_residual_full` 作为"纯媒体情感"变量
  5. 同时保留原始 `llm_vote_tone_full` 供审稿人比较

- **论文依据：** 孟庆伟等 (2026), 公式(3)-(4): "将出口预期指标分离成宏观可解释部分和净预期残差部分"。该残差 $\varepsilon_t$ 被证明是预测性能提升的关键来源。

- **预期边际贡献：**
  1. **解决潜在内生性争议：** 当审稿人质疑"LLM 情感不过是银行基本面的噪声代理"时，正交化残差的显著性可直接反驳
  2. **精炼机制识别：** 解耦"基本面信息通道"与"纯媒体效应通道"，使回归系数的经济含义更清晰
  3. **Stata 实现简洁：** `reg llm_vote_tone_full [controls], absorb(year) → predict residual`

- **实施前提条件：** ⚠️ 需要面板中已包含银行财务基本面变量（ROA、不良贷款率、资本充足率等）。若这些变量尚未纳入面板，则需从 CSMAR/Wind 等数据库补充。**如果基本面变量不可得，此改进降级为 Plan B（见风险预案）。**

#### 改进 B：时间掩码前视偏误检验

- **具体修改建议：** 在 `34_tone_validation.py` 中新增 §4.6 模块：
  1. 对全量新闻文本（或分层随机抽样子集），使用正则表达式将所有日期模式（`\d{4}年\d{1,2}月`、`\d{4}/\d{2}`、`\d{4}-\d{2}` 等）替换为 `XXXX年XX月`
  2. 将掩码后文本重新送入 LLM 推理（仅抽样子集，控制 API 成本）
  3. 计算掩码前后评分的 ICC(2,1) 和 Spearman 相关系数
  4. ICC ≥ 0.90 → 通过（Cicchetti 1994 标准）；ICC < 0.75 → 触发警告

- **论文依据：** 孟庆伟等 (2026) §四(三).3.(1): 掩码前后 ICC = 0.96 (F = 50.12, p < 0.001)，证明 LLM 评分不依赖时间信息。

- **预期边际贡献：**
  1. 为 `21_tone_llms.py` 的 LLM 推理结果提供**无前视偏误**的定量证据
  2. 直接回应审稿人关于"LLM 是否利用未来信息"的潜在质疑
  3. 生成可复现的 ICC 统计量，可直接纳入论文方法论章节

- **成本估算：** 若对 300 条分层抽样文本执行掩码重评分，API 调用成本约 3 × 300 × 3模型 = 2,700 次调用，约 $5-15（取决于模型定价）。

### 3. 冗余剥离

经对照分析，以下模块**无需修改**，理由如下：

| 模块 | 判定 | 理由 |
|------|------|------|
| `22_tone_words.py` 语言学规则引擎 | ✅ 维持原状 | 论文 §五(五).2 证实 LLM 优于词典法，但项目中词典法作为**稳健性检验基准**不可或缺。论文恰恰使用大连理工词典作为对比基线，验证了保留词典法的学术必要性 |
| `23_tone_berts.py` BERT 推理 | ✅ 维持原状 | 论文未涉及 BERT，但项目的 LLM×BERT×词典三角验证体系**已超越**论文的 LLM vs 词典二元对比 |
| `34_tone_validation.py` 三角验证 | ✅ 维持原状 | 论文的 ICC 验证已被项目的 Cronbach's α + Agreement Rate + 分层分析 + 年际漂移检测**全面覆盖** |
| `35_radius_sensitivity.py` 半径敏感性 | ✅ 维持原状 | 论文无实体级上下文隔离机制(Hassan et al. 2019)，项目的 `sentence_radius` 检验是独立方法论优势 |
| `44_panel_iv_did.py` Bartik IV/DID | ✅ 维持原状 | 论文为预测框架（无因果推断），项目的 IV/DID 体系为独立方法论贡献，与论文无交叉 |
| `38b_decay_sensitivity.py` 距离衰减 | ✅ 维持原状 | Sautner et al. (2023) 框架，与本论文无关联 |

**明确伪需求剔除：**
- ❌ **不引入 SHAP 特征重要性分析** — 与面板回归因果推断范式冲突
- ❌ **不引入 XGBoost/LightGBM 预测框架** — 项目为因果推断而非预测任务
- ❌ **不引入弹性网稳定性选择** — 该方法服务于 ML 特征筛选，不适用于面板回归
- ❌ **不引入扩展窗口滚动预测** — 与面板回归框架不兼容
- ❌ **不修改连续评分量表 [-100, 100]** — 项目的离散标签 + 多数投票已通过三角验证，稳健性充分

**动作 2.1 — 残差正交化实现（改进 A）**

在 `43_panel_indicators_geography.py` 的 `standardize_panel_variables()` 之后，新增 `orthogonalize_sentiment()` 函数：

```python
def orthogonalize_sentiment(panel: pd.DataFrame) -> pd.DataFrame:
    """步骤 7e: LLM 情感残差正交化 (孟庆伟等 2026, 世界经济, 公式3-4)

    将 LLM 情感得分分解为：
      llm_vote_tone = g(基本面) + ε
    其中 ε = "纯媒体情感残差"，排除了银行基本面已包含的信息。

    学术依据:
      孟庆伟、钟宁桦、郝雨桐、解咪 (2026). 非结构化数据增强出口预测：
      基于机器学习与大语言模型. 世界经济, 2026(3).
      DOI: 10.19985/j.cnki.cassjwe.2026.03.002
      — §五(四), 公式(3)-(4): 残差正交化分离 "经验性残差"

    实现方式:
      在每个年度截面内，以 llm_vote_tone 为因变量，
      银行基本面控制变量为自变量，执行 OLS 回归，
      提取残差作为 "纯媒体情感" 变量。

    新增列:
      llm_tone_residual_full — Full 轨道正交化残差
      llm_tone_residual_ctx  — Ctx 轨道正交化残差
    """
```

**核心逻辑：**
1. 定义基本面控制变量列表：`fundamentals = ['roa', 'npl_ratio', 'car', 'ln_total_assets']`
2. 仅处理有新闻覆盖且基本面非缺失的 Bank-Year 观测
3. 在每个年度截面内执行 OLS（`np.linalg.lstsq` 或 `statsmodels`）
4. 提取残差赋值为 `llm_tone_residual_{track}`
5. 对残差执行年度截面标准化（与现有 `_z` 流程一致）
6. 诊断日志：输出每年 R² 和残差标准差

**Stata 回归模板补充：**
```stata
* 基准回归（原始 LLM 情感）
reghdfe Y llm_vote_tone_full X_controls, absorb(target_bank year) vce(cluster target_bank)

* 正交化回归（纯媒体情感残差）
reghdfe Y llm_tone_residual_full X_controls, absorb(target_bank year) vce(cluster target_bank)

* 两步对比：若残差系数仍显著 → 证明 LLM 情感包含基本面之外的增量信息
```

**交付物标准：**
- 残差列成功生成且非空率 ≥ 90%（在有新闻覆盖的子集内）
- 每年 R² 记录在日志中，预期 R² ∈ [0.05, 0.30]（情感与基本面应有弱-中等相关）
- R² ≈ 0 → 说明基本面几乎无法解释情感变异（残差 ≈ 原始值，正交化意义有限但不有害）
- R² > 0.50 → 触发警告（情感可能是基本面的噪声代理）

```python
def time_masking_lookahead_test(df, logger_inst, sample_size=300, seed=42):
    """§4.6 时间掩码前视偏误检验 (孟庆伟等 2026, §四(三).3.(1))

    将新闻文本中的日期信息替换为占位符，重新调用 LLM 评分，
    比较掩码前后评分的一致性。

    通过标准:
      ICC(2,1) ≥ 0.90 → 通过 (Cicchetti 1994, Psychological Assessment)
      ICC(2,1) < 0.75 → 触发 WARNING

    学术依据:
      孟庆伟等 (2026), 世界经济, §四(三).3.(1):

    """
```

4. 计算 ICC(2,1) 和 Spearman ρ
5. 输出诊断报告（CSV + 日志）

### 3. 风险预案 (Plan B)

#### 风险 1：银行基本面变量不可得

**问题：** 当前面板仅包含新闻衍生变量（情感、覆盖度、暴露度等），不含银行财务基本面数据（ROA/NPL/CAR）。

**Plan B — 使用面板内已有变量作为正交化基础：**

即使没有外部财务数据，面板中已有以下可作为"基本面代理"的变量：
1. `ln_news_coverage` — 新闻覆盖量（代理银行规模/可见性）
2. `media_breadth` — 媒体广度（代理信息环境丰富度）
3. `avg_article_length` — 平均文章长度（代理报道深度）
4. `n_articles` — 文章数量

使用这些变量执行正交化，残差将排除"信息环境"维度的干扰，保留"纯情感信号"。

**学术正当性：** 这等价于 Tetlock (2007, JF) 的做法 — 控制媒体报道数量后提取纯情感效应。

#### 风险 2：LLM API 调用成本/时间制约

**问题：** 时间掩码检验需要重新调用 LLM API，可能受预算/时间限制。

**Plan B — 降级为离线验证：**
1. 仅对 100 条样本执行掩码重评分（而非 300 条）
2. 使用最便宜的 LLM 端点（如 gpt5nano）而非全部 3 个模型
3. 在论文中报告为"pilot test"，注明样本量限制

#### 风险 3：正交化后 R² ≈ 0

**问题：** OLS 回归中基本面变量几乎无法解释 LLM 情感变异（R² < 0.05）。

**应对：** 这实际上是一个**有利结果** — 直接证明 LLM 情感与银行基本面正交，即 LLM 情感捕获的是**纯粹的媒体叙事效应**而非基本面信息的噪声代理。在论文讨论章节中报告此结果即可。

#### 风险 4：正交化后 R² > 0.50

**问题：** LLM 情感大部分可被基本面解释，残差信号微弱。

**应对：**
1. 检查是否存在多重共线性（VIF > 10 → 降维）
2. 报告原始变量和残差变量的系数差异
3. 在论文中将此作为"机制发现" — 即 LLM 情感在该语境下主要是基本面的有噪声代理
4. 转而强调 BERT 或词典法情感指标可能更具增量性
