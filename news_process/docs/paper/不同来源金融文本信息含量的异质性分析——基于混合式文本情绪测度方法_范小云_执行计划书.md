# 第一部分：基于参考论文的项目分析与诊断报告

## 1. 范式映射与盲区诊断

### 1.1 论文核心机制提炼

范小云等(2022)论文的核心学术贡献可精炼为四个机制链条：

| # | 核心机制 | 论文关键发现 | 方法论创新点 |
|---|---------|------------|------------|
| M1 | **混合式情绪测度** | 将词典法提取的 Pos/Neg 词频注入机器学习特征向量 → GBDT 样本外准确率达 **92.9%**（新闻）/ **92.7%**（股吧），远超纯词典法(87.0%) 和纯ML(85.3%) | Stacking 融合架构：词典特征 + 词频向量 → GBDT |
| M2 | **新闻来源分类异质性** | 四类新闻（证券/经济/泛经济/综合）对宏观经济和股市的预测能力存在系统性差异：证券类和经济类新闻对股票收益显著、泛经济类和综合类不显著 | 按主管单位/内容属性四分类 → 分组回归 |
| M3 | **N-gram 领域词典构建** | 基于 Bi-gram/Tri-gram 的金融词典(NSD/ESD) 显著优于单元词词典（准确率: NSD=87.0% vs Jiang=60.6% vs DLUT=45.2%） | 上下文感知词典：`不良率暴涨` 整体为消极词 |
| M4 | **时间异质性** | 股吧情绪在节假日/周末后首个交易日的预测系数是其他交易日的 **2.7 倍** (Fisher P=0.020)；经济下行期预测能力显著增强 | Holiday Accumulation Effect 虚拟变量 |

### 1.2 项目现状对照与盲区定位

#### ✅ 项目已优于论文的维度（维持原状）

| 维度 | 论文方案 | 项目现状 | 判定 |
|------|---------|---------|------|
| **情感方法数量** | 词典法 + 5种ML（NB/RF/LR/GBDT/AdaBoost） | **三方法并行**: LLM集成(3模型) + 词典法(5词典) + BERT集成(5模型) | **项目远优** |
| **多实体归因** | 未处理（上证指数吧/个股吧各自独立） | **双轨道架构**: Full-track + Context-track，O(N log N) 区间合并引擎 | **项目远优** |
| **语言学规则** | 26个否定词翻转极性 | **三层规则引擎**: 否定词(窗口=2) + 程度副词(6级权重) + 转折连词(boost=1.5) + 句法边界重置 | **项目远优** |
| **词典体系** | 自建 NSD/ESD + Jiang/DLUT/Bian 对比 | 5部金融专用词典(Jiang/Yao/Bian/Du/You) + IDF加权稳健性 + 政治正面词0.5权重 | **项目优** |
| **交叉验证** | 80/20 训练测试集 + 样本外词典泛化测试 | Cronbach's α + 跨方法Spearman + 标签多数投票 + 分层稳健性 + 年际漂移检测 | **项目远优** |
| **IDF 加权** | 未实现 | Gentzkow et al.(2019) smooth IDF + 均值归一化 + P1/P99 Winsorization | **项目独有** |
| **可读性指标** | 未涉及 | ASL + TTR + CPW 三维度代理(Loughran & McDonald, 2014) | **项目独有** |
| **前瞻性语言** | 未涉及 | Li (2010) 前瞻性词汇比率 | **项目独有** |

## 2. 实质性改进项（宁缺毋滥）

### 改进 A：GBDT Stacking 混合式情感融合层

- **具体修改**: 在 `34_tone_validation.py` 的合成策略模块(§7)中，在现有的 `majority_vote()` 和 `weighted_average_score()` 之外，新增 `hybrid_gbdt_fusion()` 函数。提取三方法的结构化特征向量：
  - 词典轨: 5词典 × 2值(score + label_numeric) = 10维
  - BERT轨: 5模型 × 3概率(正面/中性/负面) = 15维
  - LLM轨: 3模型 × 2值(score + confidence) = 6维
  - 文本特征: pos_ratio, neg_ratio, forward_looking_ratio, avg_sentence_len, type_token_ratio = 5维
  - 合计: **36维特征向量** → GBDT 5-Fold CV → `hybrid_meta_score`

- **论文依据**: "而在融合词典法的结论后，各个机器学习方法的样本外情绪预测准确率有了明显提高。其中，GBDT 具有最高的样本外情绪预测精度，对新闻和股吧的样本外预测准确率分别达到了 0.929 和 0.927"（论文表7, §三(三)）

- **边际贡献**: 
  1. 将 LLM/词典/BERT 的互补信息非线性聚合为单一 Meta-Score，**从根本上解决进入 Bartik IV / DID 回归时 200+ 情感变量的多重共线性问题**
  2. GBDT 的特征重要度排序可作为"哪种方法对哪类文本最有效"的事后诊断工具
  3. 与现有多数投票共存，互为稳健性检验

### 改进 B：新闻来源四类主题分类与异质性检验

- **具体修改**: 
  1. 在 `config/media_classification.json` 中新增 `securities_media` 和 `economics_media` 字段，将现有32+家媒体按论文表1的逻辑映射为**证券类/经济类/泛经济类/综合类**四组
  2. 在 `42_panel_attention_media.py` 的 `compute_media_heterogeneity()` 中新增四类分组情感均值变量: `tone_securities_full`, `tone_economics_full`, `tone_pan_economics_full`, `tone_comprehensive_full`
  3. 在 `44_panel_iv_did.py` 中新增对应的 Bartik IV（稳健性维度 29~32）

- **论文依据**: "根据报纸侧重的主题，本文将报纸按内容分成4类：证券类、经济类、泛经济类和综合类，分别考察每类报纸包含的信息"（论文表1, §三(一)）。"证券类和经济类新闻文本情绪分别在5%和10%的显著性水平下能够正向预测未来一个交易日的股票收益率...泛经济类和综合类的新闻文本情绪对下一交易日的股票收益率没有显著预测作用"（论文表12, §四(二)1）

- **边际贡献**: 
  1. 直接验证本项目银行金融科技语料中，不同主题来源的新闻是否对情感测度的精度和预测力存在系统性差异
  2. 若证券类和经济类新闻的情感信号更纯净，可据此构建**信息质量加权**的精选情感指标
  3. 四类 Bartik IV 丰富了外源性变异来源，增强因果识别策略的说服力

### 改进 C：交易日/非交易日时间异质性衰减因子

- **具体修改**: 在 `38b_decay_sensitivity.py` 中新增时间维度的衰减断点分析：
  1. 引入 `exchange_calendars` 或 `chinese_calendar` 库标记每日的交易日/非交易日状态
  2. 新增虚拟变量 `is_post_holiday`（前一日为非交易日=1），在衰减回归中加入交互项 `sentiment × is_post_holiday`
  3. 输出诊断报告：节假日后首个交易日的衰减梯度 vs 正常交易日

- **论文依据**: "股吧文本情绪在节假日及周末后首个交易日的系数是其他交易日系数的 2.7 倍，且 Fisher 经验 P 值为 0.020，表明组间存在显著差异"（论文附录附表8, §四(三)4）

- **边际贡献**: 时间堆积效应是空间距离衰减的正交补充维度。在新闻发布日跨越周末/假期时，情感的传播路径和衰减结构与工作日发布的新闻本质不同。加入此因子可以**分离出由发酵时间导致的情绪放大效应**，使现有距离衰减系数更加精确。

## 3. 风险预案 (Plan B)

### 卡点1: GBDT 不收敛或过拟合

**风险描述**: 36维特征 + 有限标注样本(人工验证集约300条)可能导致 GBDT 过拟合或OOF准确率反降。

**替代方案**:
- **Plan B1**: 回退至 Logistic Regression 做线性 Stacking（论文中 LR 样本外准确率也达到 85.3%/78.2%）
- **Plan B2**: 采用 Ridge Regression 做连续型融合，避免分类边界硬切
- **Plan B3**: 保持现有多数投票方案（已经是有效的非参数融合），仅将 GBDT 改为"补充参考"而非主推

### 卡点2: 交易日历数据精度

**风险描述**: `exchange_calendars` 的中国交易所日历存在临时调休等特殊安排，可能与爬虫采集的新闻发布日期(可能为北京时间 vs UTC)产生时区偏差。

**替代方案**: 
- 不使用离散虚拟变量, 改为连续变量 `hours_since_last_trading_close`（距上一交易日收盘的小时数），作为衰减回归中的连续调节变量。这一方案更为鲁棒，且无需处理法定节假日的边界判定。

### 卡点3: 新闻来源数量不均衡

**风险描述**: 项目语料中某些类别（如"泛经济类"）的新闻数量可能极少，导致分组后 Bartik IV 的统计功效不足。

**替代方案**: 
- 将四分类降级为二分类: "高信息密度"(证券+经济) vs "低信息密度"(泛经济+综合)
- 或直接以信息含量为连续权重: 基于分类回归系数的大小动态赋权
