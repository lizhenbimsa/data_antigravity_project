# 项目重构与优化执行计划书

## 1. 优先级排布

**速赢项（Quick Wins）**：
- **清洗劣质特征**：在词典清洗阶段，全局剥离或屏蔽通用性非金融域情感词典的依赖及对应得分序列集成，只引入金融专项领域 N-gram 规则及词汇字典。实施成本极低，预期收益高（极低信噪比降维降低运算负荷）。
- **加入休市期间冲击虚拟变量**：在 `38b_decay_sensitivity.py` 数据处理上游引入 $Hol_t$。计算逻辑直接复用 Pandas 中针对法定节假日以及前置休息日的库即可。

**核心攻坚项**：
- **架构级融合打分重组（Meta-Classifier 搭建）**：对由于并发执行而离散分布于 `21_tone_llms`、`22_tone_words` 以及 `23_tone_berts` 产生的异质测度张量进行聚合开发，建立基于 GBDT 并采用样本内 K-Fold 交叉验证生成的最终融合概率值。

## 2. 阶段化执行指令 (SOP)

### 阶段一（机制重塑/数据清洗）：清理伪需求
**核心指令**：
- 审查 `22_tone_words.py`。全局检索类似于 `DLUT`、`HowNet` (知网情感词集) 等非金融垂直领域的词库调用逻辑。
- 采用正则化或静态屏蔽表剔除调用过程。
- 保留或引入含有金融负向限定阈的基准分析，计算每个句子的纯净版 $Pos$ 和 $Neg$。

**交付物标准**：
- `22_tone_words.py` 的精简版本提交。

### 阶段二（实证/模型重构与检验）：时态衰减因子剥离
**核心指令**：
- 修改 `38b_decay_sensitivity.py`，定位对事件时距 `Δt` 进行计算的逻辑块。
- 新增一维变量，采用 `chinese_calendar` 或金融日历 API 判断时间段 `t-1` 到 `t` 是否涵盖股市休盘日。如果是，则建立一个独立交互作用项作为稳健性检验方程之一。

**检验标准**：
- 运行针对该交互项系数的 $t$-检验。输出单独的交互项衰减梯度诊断报告。预期在休市之后其对应的反应度（波动和异常回报）要显著高出至少两倍范围。

### 阶段三（结论重构）：Stacking 集成计算流水线
**核心指令**：
- 修改或覆盖现存评估流程模块（如 `33_news_llms_evaluation.py`）。
- 将 `tone_llms` 映射生成的分类分数向量 $P_{LLM}$、词典向量 $[Pos, Neg]$ 以及 BERT 的向量空间层作为输入特征 $X_{hybrid}$。
- 调用 `sklearn.ensemble.GradientBoostingClassifier` 构建微调分类器。通过 OOB 预测建立统一口径融合得分 $Score_{Meta}$。
- 在后续进入 `41_panel_encode_aggregate.py` 的全量合并前，所有的非核心情绪指标都应被替换或作为协变量归约为这个统一输出。

## 3. 风险预案 (Plan B)

**卡点1：特征维度不对齐或者样本标注不统一导致的 GBDT 不收敛**。
不同模型对不同粒度（文段粒度与词条粒度）的情感颗粒度评价不一样导致堆叠融合失败。
*替代方案*：如果 GBDT 的训练过程资源超负荷或效果不如预期，回退到逻辑回归（Logistic Regression）做最保守的线性“软投票”集成；赋予LLMs更高的静态固定权重即可，以此规避复杂的深层学习资源耗费。

**卡点2：交易日与日历日由于多期爬虫抓取偏差无法精确对账**。
在测试 `38b` 敏感性阶段可能出现大量爬取的财报附注日期与周日法定发布有对账滞后。
*替代方案*：不追求对具体那一周或节假日的虚拟判定，直接引入日级别的“距离上次开市时间的绝对分钟差”（Time Elapsed Gap）作连续变量衰减项控制，更为顺滑地消解非线性时间差动效应。
