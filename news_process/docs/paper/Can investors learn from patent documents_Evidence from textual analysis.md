# 基于《Can investors learn from patent documents? Evidence from textual analysis》的项目分析与执行计划

=========================================
## 第一部分：基于参考论文的项目分析与诊断报告

**1. 范式映射与盲区诊断**
- **核心机制**：Zheng 利用 BERT 模型直接拟合连续的“专利经济价值”（其标签源自股票市场的短期超额收益），而非传统的离散情感分类。作者充分证实未结构化文本能提供极具价值的增量信息，能预示公司未来真实盈余和长期股票超额收益（纠正了市场短期的反应不足）。
- **当前盲区**：目前本项目（`news_process`）的文本分析模块（如 `21_tone_llms.py` 和 `23_tone_berts.py`）仅停留在离散的粗粒度三分类（正面/中性/负面）层面，缺乏与“连续经济实质（经济价值）”相锚定的深层价值量化。此外，当前项目的有效性验证过度集中于技术准确性（如内部一致性与Prompt敏感度测试，见 `config.yaml` 模块四），而尚未在经济学回测层面验证该文本测度是否能真实预测银行未来长期的核心业绩改善（盈利累积、风险出清）或股票回报。

**2. 实质性改进项（宁缺毋滥）**
- **改进 A：由离散情感分类升级为连续价值锚定评分 (Continuous FinTech Value Score)**
  - **[论文依据]**：论文修改了 BERT 标准分类架构，“integrating an additional linear layer... to directly predict the continuous patent stock market valuation”。
  - **[预期边际贡献/解决的内生性问题]**：针对同等判定为“正面”的金融科技新闻，经济实质必然存在异质性差距。构建基于连续历史股票反应或微调预测的连续评分，能更精准刻画金融技术落地的深层商业价值，消除标签颗粒度过粗掩盖的统计显著性稀释问题。
- **改进 B：引入真实经济后果验证以排除媒体炒作内生性 (Genuine Info vs. Media Hype)**
  - **[论文依据]**：论文通过回归检验文本信息对未来5年累计净利润 (Cumulative Adj. NI) 及1年期长窗口股票超额收益 (CAR_12M) 的预测能力，以区分真实的隐含信息与简单的管理者战略释放。
  - **[预期边际贡献/解决的内生性问题]**：在当前面板（`40_panel_yearly.parquet`）中新增对未来1至3年业绩和股票回报的预测检验，可强有力回击“媒体新闻可能仅为短期舆论炒作，不具有业务落地实质”的内生性质疑，证明提取的新闻测度实质捕捉了银行的技术积累。

**3. 冗余剥离**
- **伪需求模块**：当前流水线中保留且高度复杂的**基于规则的词典法情感分析模块**（即 `22_tone_words.py` 及其在 `config.yaml` 中繁杂的程度副词倍数加权与否定转折逻辑）存在极高冗余度。Zheng 的研究证明，在高度专业化领域（如专利与科技），序列注意力基座大模型（BERT等）对语境的高维压缩具有压倒性优势。单纯靠维护海量词典及硬编码规则，维护边际收益趋近归零，建议直接作为低优先级对照或彻底剥离，以释放算力和代码维护成本。

## 第二部分：项目重构与优化执行计划书

**1. 优先级排布**
- **速赢项 (Quick Wins)**：在现有的合并面板回归模块（如阶段 45 之后）中补充引入银行未来盈余特征（Future Adj. NI）和长窗口市场表现（CAR_12M）作为因变量进行时滞预测试验。
- **核心攻坚项**：采集历史新闻发布后 [0, 3] 交易窗口的股票特质性收益率序列，作为连续标签用于重建 BERT 的回归输出层（增加 Linear Layer，Loss = MSE），生成连续维度的 FinTech 新闻经济价值分。

**2. 阶段化执行指令 (SOP)**

* **阶段一（机制重塑/数据清洗）**：
  - **指令 1**：修改 `config.yaml` 设置配置项 `sentiment_analysis.enabled_methods`，剔除 `tone_words`（注释剥离 `22_tone_words.py` 执行流），仅保留 `tone_llms` 与 `tone_berts` 路线。
  - **指令 2**：提取上市银行在 `12_fintech_news.parquet` 各新闻发布时间点所在交易周的股票特质收益（Idiosyncratic Returns），将其作为每条新闻“金融科技含量经济价值”的连续型目标标签。

* **阶段二（实证/模型重构与检验）**：
  - **指令 1**：针对 `23_tone_berts.py` 创建副本（或新增分支逻辑），将选择使用的 HuggingFace BERT 模型顶层分类器（`BertForSequenceClassification`）中设定 `num_labels=1`，配置其以均方误差（MSE）逼近上一阶段生成的连续股票收益标签，以获得单条新闻文本的“预测市值增量得分”。
  - **指令 2**：在聚合面板脚本（`45_panel_export_main.py` 或同类汇聚逻辑）中引入新聚合字段，加总银行当期获得的所有金融科技新闻中蕴含的总预测经济价值分。

* **阶段三（结论重构）**：
  - **指令 1**：编写实证测算脚本（可并入 `44_panel_iv_did.py` 或独立检验脚本）。执行长期预测验证：使用当期测算出的金融科技综合得分作为核心自变量（$X_t$），去预测该银行 $t+1$ 乃至 $t+3$ 的累计净利润（Cum_NI）以及年化资产受损率变化。
  - **指令 2**：检验该分值对 $t+1$ 至 $t+12$ 个月累积超额收益的预测效力，验证“市场长期对银行金融科技新闻同样存在逐步修正与消化（不足反应）”的理论机制。

**3. 风险预案 (Plan B)**
- **预判卡点**：媒体新闻相较于专利文献本身存在更高的噪音比。直接使用单日/三日短窗口股票超额收益作为连续标签来 fine-tune BERT 时，由于外部宏观噪声的掩盖，模型可能发生不收敛或解释力极低现象（SNR<0.1）。
- **替代方案**：若回归型微调失败收敛，退回并维持现有高准度的 LLM 三分类体系，但在面板阶段计算时，不使用简单的算术加总，而是利用金融同业文本计算该新闻蕴含的“意外惊奇成分（Surprise/Novelty 信息熵测度）”对其进行加权，以构建近似的连续型价值评分，以此替代深层回归分值去跑阶段三的长期验证模型。
