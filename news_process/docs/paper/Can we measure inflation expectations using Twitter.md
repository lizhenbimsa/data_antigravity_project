# 基于参考论文《Can we measure inflation expectations using Twitter》的项目重构评估与执行计划

=========================================
## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**参考论文核心机制**：论文利用推特非结构化文本，通过LDA（潜在狄利克雷分配）过滤掉无价值的噪音，继而基于上下行定向词频 (Up/Down n-grams) 计算宏观预期指数。其核心亮点在于设计了差异化合成指数（如 $ \pi_{ln}^{e} \equiv \ln(\text{Index Up}+1) - \ln(\text{Index Down}+1) $ ），并通过提取专业群体（Econ/News）与体现未来时态的前瞻性词汇构建子样本，从而实现对预期高解释度的有效代理。

**当前项目盲区**：
项目当前 (`news_process`) 是围绕银行金融科技新闻的自然语言处理与情绪分析流水线。我们在预筛和过滤阶段已经采用了比LDA更为先进的LLM CoT与Minhash去重技术，但在后端特征构建（尤其是在`45_panel_export_main.py`面板聚合输出层面）上，尚未充分汲取上述文献所揭示的构建优质外生代理变量的核心直觉：
1. **聚合算法比较单一，易受极值扰动**：目前面临直接聚合成Bank-Year面板时，针对文章评分可能直接取均值或绝对度量加总，没有利用对数差异型聚合范式。这导致一旦某银行在某年因某一重大公关预案产生指数级别的新闻激增量，均值和绝对量会被长尾分布严重偏倚，存在异方差隐患。
2. **缺乏高质金融子样本和前瞻预期的维度交互**：现阶段的异质性分析和前瞻性词汇计算处于平行层级。未能根据论文的思想对“纯前瞻语句”结合“情绪极性”做专门隔离，以提取“无同时期内生干扰的前瞻性数字转型预期”。

### 2. 实质性改进项（宁缺毋滥）
>    - **改进 A：基于对数降噪的定向情感合成指数 (Log-differenced Directional Sentiment Index)**
>      - **标明论文依据**：参考论文 Section 3.3 (Indicator #4) 证明，引入 $ \pi_{ln}^{e} \equiv \ln(\text{Index Up}+1) - \ln(\text{Index Down}+1) $ 的指数构建方式相较于简单的时序平滑和标准化，其与实质趋势的解释度 $R^2$ 最高。
>      - **预期的边际贡献**：引入至 `panel_building` 面板构建阶段，可大幅抑制特定热点事件由于网络媒体病毒式转载所导致的情绪爆量效应，稳健地收缩面板的长尾分布，修正自发性信息披露的截面异方差偏误。

>    - **改进 B：高信噪比专业媒介子样本预期隔离 (Professional/News Media Sub-sample Extraction)**
>      - **标明论文依据**：参考论文 Section 5.1 (Sub-sample of users interested in economics or news) 证明，过滤掉边缘发声群众，仅保留具有专业金融/报业标签的语料框可以萃取出强预见能力的情感特征因子，显著降低噪音与虚假相关。
>      - **预期的边际贡献**：利用现有的媒体类型和权重设置，强制分离出“中央级/财经核心专报”视角的单独细分 Panel。这不单是异质性检验的手段，更是极佳的稳健性检验核心代理变量（剥离了非专业新媒体渠道的信息杂音）。

>    - **改进 C：纯前瞻性情绪指数的剥离 (Forward-Looking Exogenous Sentiments)**
>      - **标明论文依据**：参考论文 Section 5.2 (Tweets with future meaning) 将情感极性限定附着于未来时态词汇（Future Words），以分离事后验证和同步反应，从而证明指数的“前瞻性质”。
>      - **预期的边际贡献**：当前系统词库 `forward_looking_words` 仅计算 `forward_looking_ratio`（词频比）。后续算法应通过交叉滑窗匹配计算“带有前瞻性陈述语句的局部情感净额”，即“市场对该银行未来金融科技投入预期的情绪”。这种微观粒度的操作排除了当期财报发布事实导致的并发因果颠倒（Reverse Causality），有效提升外生纯度。

### 3. 冗余剥离
- **明确指出边界：拒绝引入传统 LDA 去噪范式以“兼容”论文**。论文受所处年代和数据形态所限，退而求其次使用无监督 LDA (Latent Dirichlet Allocation) 聚类概率来过滤高频噪音（如广告或体育类内容），这是因为基于 Twitter 短文本无法运行复杂深度学习。而我们当前配置文件模块 21 (`21_tone_llms.py`) 已经布设了由主流大模型（如 GPT-5, Gemini, Claude 4.5）支撑的 One-Pass Chain-of-Thought (CoT) 语义真伪精筛，具备跨维度的逻辑理解与降噪能力。**故在此环节，必须维持原状，严禁不加思考地向论文倒退看齐去强行植入 LDA 等低级降维模型，避免引入新冗余。**

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项 (Quick Wins)**：在阶段四面板构建（`45_panel_export_main.py` 及对应的配置文件逻辑中），平铺生成一条基于自然对数合成的 `Directional_Index` 生成列。代码修改成本低，即可用于基准回归。
- **核心攻坚项**：实现具备独立视角的“专业媒介子样本截面情绪提取”及“前瞻语义特征叠加隔离”，重构情感统计规则函数。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑/数据清洗）：**
- **动作指令**：维持原状。预处理过滤、Minhash 严格清洗，以及引入的 Unified CoT 机制验证框架在逻辑上远超传统 LDA。明确要求在第一阶段不需要任何变动，直接进入高阶面板变量派生层。

**阶段二（实证/模型重构与检验）：**
- **动作指令 1：定向对数面板合成 (Log-Smoothing Generation)**：
  在 `config.yaml` 文件的 `panel_building` 中增设配置：
  `compute_directional_log_index: true # 基于Angelico(2022)参考`
  开发交付物：在面板构建程序中增加针对年度聚合情感的新变量 `Sentiment_Directional_Index = ln(Count_Pos_Sentences + 1) - ln(Count_Neg_Sentences + 1)`，支持字典法和 LLM 等不同产出源。
- **动作指令 2：财经信息子集面板生成 (Econ/News Panels)**：
  依据底层新闻数据的 `media_heterogeneity`（区分中央/财经等），强制在聚合宽表生成时多带出一个专属子集：`Panel_Professional_Econ_Media`，仅囊括通过设定的高质量信息源发表的内容的情量积分。
- **动作指令 3：前瞻共现特征重塑 (Forward Sentiment Feature)**：
  对 `22_tone_words.py` 等算法进行拓展：扫描窗口内若存在 `forward_looking_words`（如"预计", "致力于", "计划"等），且紧邻窗口包含明显的正面/负面情绪词汇，则形成一次前瞻得分映射 `future_sentiment_score` 供下游面板直接吸纳。

**阶段三（结论重构）：**
- **动作指令**：在实证主回归中加入新生成的 `Subset_Professional_Media`（财经子级）和前瞻性情绪指数以独立运行稳健性判定（Robustness Regression Check）。验证该机制对消解外部偶发巨大舆情冲击的影响能够使得 $T$ 统计量和平行判定更加稳健。

### 3. 风险预案 (Plan B)
- 风险研判（稀疏性阻断）：由于银行金融科技新闻本就具有重度长尾效应（中小城商行相关报道少），若强制采用“细分财经媒体 + 强制前瞻时态匹配”双重筛选，这部分得分矩阵在很多年度可能会导致变量值大规模为 0 或 NaN，导致方差丧失无法进行固定效应回归。
- **Plan B 稳健替代案**：当发现严苛的语句交叉导致特征空间覆盖度 < 30% 时，启动降维代换：不从微观语句级别提取前瞻情感协同，而是改用年度级别的互动项（交互乘数）。定义综合乘数变量：
$ \text{Factor}_{i,t} = \text{Mean\_Sentiment}_{i,t} \times \text{Forward\_Looking\_Ratio}_{i,t} $
借此从全局年度概貌侧面模拟总体对未来的积极信念敞口，规避极端共线性崩溃。
