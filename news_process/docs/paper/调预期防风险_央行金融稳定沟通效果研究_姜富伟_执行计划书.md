# 第一部分：基于参考论文的项目分析与诊断报告

## 1. 范式映射与盲区诊断

### 1.1 论文核心机制提炼

姜富伟等（2024）的核心研究框架包含以下五个关键维度：

| 维度 | 论文做法 | 核心机制 |
|------|---------|---------|
| **情感词典构建** | Word2Vec 扩充 + 人工复核，构建金融稳定沟通专用词典（1541正 + 1461负） | 领域专用词典是测度准确性的根基 |
| **情感单元法** | 以情感词为锚点，前向回溯到上一个情感词，组成"情感单元"；否定词翻转极性 | 比简单词袋法更好地捕捉局部语境 |
| **情绪指数正交化** | 将TONE对宏观经济金融指标（CPI、工业增加值、SRISK、回购利率、宏审指数）回归取残差 | 剥离已知公共信息，提纯"新信息"信号 |
| **异质性设计** | 引入 RETAIL 虚拟变量（散户持股<=P20），用 TONE x RETAIL 交乘项识别截面效应 | 利用投资者结构异质性做因果推断 |
| **双渠道机制** | 信号渠道（引导投资者预期 -> SENTIMENT）+ 协同渠道（降低意见分歧 -> DISAGREEMENT） | 从预期形成和信息不对称两条路径解释效果 |

### 1.2 当前项目的真实落差

> [!IMPORTANT]
> 以下诊断基于论文核心机制与当前管线的严格对标。标注 OK 的维度表示项目当前设计已逻辑自洽或优于论文做法，标注 GAP 的维度指出实质性改进空间。

| 维度 | 项目现状 | 对标论文后的判定 |
|------|---------|---------------|
| **情感词典** | 5套规范词典（姜2021/姚2021/卞2021/杜2022/尤2018）+ 语言学规则引擎 | OK **维持原状**。项目使用多词典交叉验证 + IDF加权稳健性检验，多元化覆盖优于论文的单一词典设计 |
| **语言学规则** | 否定词翻转、程度副词放大/缩小、转折连词增强 | OK **维持原状**。规则引擎严格对标 Jia et al.(2009)、Ding et al.(2008)，且优于论文仅处理否定词的做法 |
| **LLM 多模型投票** | 3模型x2轨道(full/ctx)x多数投票 | OK **维持原状**。三角验证机制是论文所不具备的先进设计 |
| **情绪正交化** | 缺失 | GAP **核心改进项**。论文将TONE对宏观指标回归取残差，剥离公共信息。当前管线无此步骤 |
| **投资者异质性** | 面板数据中有 bank_type 按银行类型分组 | GAP **可扩展**。论文使用散户持股比例(RETAIL)刻画投资者结构异质性，可用银行分组变量(bank_type)做类似截面交乘分析 |
| **双渠道机制检验** | 缺失 | GAP **概念迁移**。可以将"信号渠道"和"协同渠道"的研究范式迁移至银行金融科技领域 |
| **工具变量构建** | 29套 Bartik IV + 省/城市/经济圈 LOO IV + DCEP/Sandbox DID | OK **远超论文**。论文仅使用美国党派冲突指数做2SLS，项目的IV体系更加丰富 |
| **标准误聚类** | Stata导出已支持 bank_province, bank_city 聚类 | OK **维持原状**。与论文公司层面聚类调整等效 |

### 1.3 关键结论

> [!NOTE]
> 论文对项目的边际贡献主要集中在两点：
> 1. **情绪指数正交化**：这是实证金融文本分析的标准做法，是当前管线的真实盲区
> 2. **机制渠道检验范式**：信号渠道/协同渠道的检验思路可迁移到银行金融科技情感对数字化转型行为和市场反应的机制分析中

## 2. 实质性改进项

### 改进 A：情感指数宏观正交化（Orthogonalization）

- **具体修改建议**: 在面板构建阶段（45_panel_export_main.py）中，将年度聚合情感指标（如 `llm_vote_tone_full`, `dict_avg_tone_full` 等）对一组宏观经济/金融控制变量进行截面-时间回归，取残差作为"纯净"情感指标

- **论文依据**: 姜富伟等（2024）第三章第二节：*"参考 Huang et al.（2015）的做法，将央行金融稳定沟通情绪对一系列宏观经济金融指标回归并取残差，残差可以视为央行金融稳定沟通情绪中无法被这些指标解释的新信息"*

  Huang, D., Jiang, F., Tu, J., & Zhou, G. (2015). Investor sentiment aligned: A powerful predictor of stock returns. *Review of Financial Studies*, 28(3), 791-837. https://doi.org/10.1093/rfs/hhu080

- **预期边际贡献**: 
  - 剥离宏观经济环境的系统性影响，提纯金融科技新闻情感中的"新信息"成分
  - 正交化后的残差情感更适合做因果推断（缓解遗漏变量偏误）
  - 直接对标 JF/RFS 的方法论标准

### 改进 B：投资者/银行异质性交乘分析的 Stata 模板

- **具体修改建议**: 在 Stata 回归模板中预置 `TONE x bank_type` 类型的交乘项回归示例，利用已有的 bank_type（soe/joint/city/rural/private/foreign）做截面异质性分析

- **论文依据**: 姜富伟等（2024）公式(3): Y_{it+1} = alpha + beta * TONE_t * RETAIL_{it} + delta * RETAIL_{it} + gamma * X_{it} + lambda_i + mu_t + epsilon_{it+1}

  *"引入股票截面异质性...可以将 TONE_t 替换为时间固定效应 mu_t"*

- **预期边际贡献**: 
  - 现有管线已有 bank_type 分组，只需在 Stata 模板中增加交乘项即可
  - 可检验金融科技新闻情感对不同类型银行（国有/股份制/城商/农商/民营/外资）的差异化影响
  - 这是审稿人几乎必问的异质性分析

## 3. 冗余剥离

> [!NOTE]
> 经严格评估，当前项目不存在需剥离的"伪需求"模块。
> 
> 理由：
> - 多词典、多BERT、多LLM的三角验证体系在方法论上是互补而非冗余的
> - 29套Bartik IV看似过多，但根据GP-S(2020, AER)的Rotemberg权重诊断框架，多维度IV恰恰是稳健性检验的标准配置
> - 项目的双轨(full/ctx)设计服务于消融研究需求，是方法论贡献而非冗余

## 2. 阶段化执行指令 (SOP)

### 阶段一：情感指数宏观正交化（核心攻坚项 A）

#### 动作指令 1.1：新增正交化函数

- **位置**: `43_panel_indicators_geography.py` 或新增 `43b_panel_orthogonalize.py`
- **函数签名**: `orthogonalize_tone(panel: pd.DataFrame, tone_cols: list, macro_controls: list) -> pd.DataFrame`
- **核心逻辑**:

```
对每个 tone_col in tone_cols:
    1. 构建截面 X = panel[macro_controls]（年度频率宏观指标）
    2. OLS: tone_col ~ X + 常数项
    3. 取残差: panel[f'{tone_col}_orth'] = tone_col - X @ beta_hat
```

- **宏观控制变量候选集**（对标论文 + 中国语境扩充）:

| 变量 | 来源 | 对标论文变量 |
|------|------|------------|
| GDP同比增速 | 国家统计局 | CPI同比增速 |
| M2同比增速 | 人民银行 | 银行间七天回购利率 |
| 上证综指年度收益率 | Wind/CSMAR | 系统性风险(SRISK) |
| 金融科技行业指数 | 万得金融科技指数 | 宏观审慎政策指数 |

> [!WARNING]
> **外部数据依赖**: 正交化所需的宏观指标为项目外部数据，需从Wind/CSMAR/国家统计局获取年度频率数据。如果外部数据不可得，执行 Plan B（见下方风险预案）。

- **交付物标准**: 
  - `panel` 中每个 tone_col 对应新增一列 `{tone_col}_orth`
  - 日志输出 OLS 回归的 R-squared 和各系数 t 值
  - R-squared 应较低（论文图3显示残差与原值走势基本重合），若 R-squared > 0.3 需审查宏观控制变量是否过度拟合

#### 动作指令 1.2：Stata 变量标签注册

- **位置**: `45_panel_export_main.py` 的 `STATA_LABELS` 字典
- **新增条目**:

```python
'llm_vote_tone_full_orth':   'LLM Vote Tone (Orthogonalized, Full)',
'llm_vote_tone_ctx_orth':    'LLM Vote Tone (Orthogonalized, Ctx)',
'dict_avg_tone_full_orth':   'Dict Avg Tone (Orthogonalized, Full)',
'dict_avg_tone_ctx_orth':    'Dict Avg Tone (Orthogonalized, Ctx)',
```

#### 动作指令 1.3：诊断输出

- 在 `log_diagnostics()` 中新增正交化前后的 Pearson 相关系数
  - 预期 r > 0.95（论文图3的经验值）
  - 若 r < 0.85，输出警告并建议检查宏观控制变量的选择

### 阶段二：异质性交乘 Stata 模板（速赢项 B）

#### 动作指令 2.1：在 Stata 导出中追加回归模板

- **位置**: `45_panel_export_main.py` 的 `export_panel()` 函数末尾
- **输出**: 在 Stata .dta 同目录生成 `do_heterogeneity_template.do` 模板文件
- **模板内容**:

```stata
* ============================================================
* 异质性分析：情感 x 银行类型交乘 (对标姜富伟等2024,公式3)
* ============================================================
* 基准方程 (不含时间固定效应):
* Y_{i,t+1} = alpha + beta*TONE_t + gamma*X_{it} + lambda_i + eps_{it+1}
reghdfe Y llm_vote_tone_full X_controls, absorb(bank_id) vce(cluster bank_id)

* 交乘方程 (含时间固定效应):
* Y_{i,t+1} = alpha + beta*TONE_t*TYPE_i + delta*TYPE_i + gamma*X_{it} + lambda_i + mu_t + eps_{it+1}
gen tone_x_soe = llm_vote_tone_full * (bank_type == "soe")
gen tone_x_joint = llm_vote_tone_full * (bank_type == "joint")
gen tone_x_city = llm_vote_tone_full * (bank_type == "city")
gen tone_x_rural = llm_vote_tone_full * (bank_type == "rural")
reghdfe Y tone_x_soe tone_x_joint tone_x_city tone_x_rural ///
    i.bank_type X_controls, absorb(bank_id year) vce(cluster bank_id)

* 使用正交化后的情感指标:
reghdfe Y llm_vote_tone_full_orth X_controls, absorb(bank_id) vce(cluster bank_id)
```

- **交付物标准**: `.do` 文件语法正确

## 3. 风险预案 (Plan B)

### 卡点 1：宏观经济数据不可得

- **症状**: 无法获取GDP增速/M2增速等年度宏观数据
- **替代方案**: 
  - **Plan B1 — 年度固定效应替代**: 在面板回归中直接加入年度固定效应 `absorb(year)`，等价于吸收所有年度共同冲击（包括宏观经济变化）。这是论文公式(3)在引入 RETAIL 交乘项后的实际做法。
  - **Plan B2 — 组内去均值**: 对每年的 tone_col 做截面去均值：`tone_demean = tone - mean(tone within year)`。这是年度固定效应的等价数值操作。
  - **经济含义**: Plan B1/B2 控制了所有年度共同冲击（比论文的5个宏观变量更彻底），但代价是无法分解具体哪个宏观因素驱动了情感变化。

### 卡点 2：正交化 R-squared 过高（>0.3）

- **症状**: 宏观控制变量解释了情感指数的过多变异
- **替代方案**: 
  - 检查是否存在共线性（VIF 检验）
  - 减少控制变量至 2-3 个核心指标
  - 改用 Ridge 回归（正则化系数 lambda=0.1）抑制过拟合

### 卡点 3：bank_type 分组过度不平衡

- **症状**: 某些银行类型分组过小（如外资银行可能仅3-5家），交乘项估计不稳定
- **替代方案**: 
  - 合并小组：将 private + foreign 合并为 "other" 类
  - 改用连续变量替代虚拟变量：如银行总资产规模（需外部数据），避免分组边界问题
