# 执行计划书：基于《预期的博弈：央行沟通与国债收益率曲线》的项目审计与重构方案

## 第一部分：基于参考论文的项目分析与诊断报告

**1. 范式映射与盲区诊断：**
该论文的核心机制探讨了“宏观层面超预期信号”的作用：证明了央行沟通情绪（文本数据提取）与国债收益率曲线（金融期限结构）之间存在的相互前瞻指引及双向博弈机制。
反观当前 `news_process` 项目体系：当前项目为“微观层面商业银行实体”的面板实证研究，且 `config.yaml` 明确通过 `bank_names.json` 中移除了“中国人民银行”、“央行”等央行主体。因此，如果生搬硬套让当前管线去处理“央行新闻”，属于越界的伪需求。项目真正的盲区在于：**当前微观维度的“银行-金融科技”面板数据模型中，未能有效控制或交互宏观层面的预期货币政策冲击。** 商业银行的科技投入、信贷投放和对外发声情绪，必然受到央行货币政策意图及整体国债收益率（即市场无风险无套利期限结构）深切的同向或逆向抑制影响。忽略这一外生性宏观周期变量，极易在银行级面板中引入严重的遗漏变量偏误。

**2. 实质性改进项（宁缺毋滥）：**
- **改进 A：在微观面板中引入期限结构与央行沟通的宏观交互项 (Macro Interaction Term)**
  - *论文依据*：论文提出“积极的沟通情绪通常会降低长短期利差，引导金融市场的客观预期与实体经济的投资活动”。
  - *边际贡献/解决的内生性问题*：解决商业银行金融科技发展趋势与国家银根松紧周期正交化的内生性问题。通过将国债收益率的水平(Level)、斜率(Slope)因子与央行沟通情绪提取出来，将其作为外生控制变量或交互项接入 `44_panel_iv_did.py` 或 `45_panel_export_main.py` 的微观面板导出阶段，用以控制时间固定效应无法完全吸收的结构性信贷紧缩波峰波谷影响。

**3. 冗余剥离（维持原状通告）：**
- **拒绝形式主义的“文本测量方法”降级（维持原状）**：该论文在刻画央行沟通情绪时，使用的仅是最基础的词典法情感加总加权法 `Sentiment = (Pos - Neg) / (Pos + Neg)`，且将“对过去信息解读”与“前瞻指引”分拆分析。而 `news_process` 的当前架构已使用了 LLM CoT、FinBERT多模型交叉验证，同时在 `config.yaml` 中业已引入了完善的 `forward_looking_words` (FLS前瞻性陈述测度)，技术维度与变量颗粒度直接碾压了该论文的NLP部分。因此，严禁在当前项目中“降维”复刻该论文的文本提取方法，测量管线结构必须**严格维持原状**。

## 第二部分：项目重构与优化执行计划书

**1. 优先级排布：**
- **速赢项（Quick Wins）**：在阶段 4 的面板组装中抓取宏观控制变量并实施宏观时间序列维度的左侧拼接（控制国债期限结构和央行沟通释放的货币信号）。由于 `config.yaml` 的强解耦性，此部分不需要重跑前面的长耗时 LLM 及 BERT 文本推断模块。

**2. 阶段化执行指令 (SOP)：**

- **阶段一（机制重塑/数据清洗）：**
  - **核心动作指令**：无需进行新闻处理机制重塑。保持 00至30 阶段的所有 Python 脚本和数据完全不动。在 `config.yaml` 阶段 `41-45` (Panel Building) 配置中，声明新的宏观合并字段 `include_macro_yield_curve: true` 和 `include_pboc_tone: true`。

- **阶段二（实证/模型重构与检验）：**
  - **核心动作指令**：修改 `45_panel_export_main.py`（和后续面板处理脚本）。
  - **操作明细**：
    1. 引入宏观时间序列数据流（CPI、工业增加值增速、国债收益率水平向、斜率向因子）。
    2. 基于 Bank-Year 或 Bank-Quarter 的粒度，通过时间维度 (Date/Year) 进行 Left Join 操作。
    3. 在最终微观回归中设定模型规格：将“银行金融科技创新(被解释变量)”对“自身特征属性”、“微观工具变量(Bartik)”、以及新增的“宏观政策冲击(或交互项)”进行回归，通过增加 `(FinTech_Tone_{i,t}) * (PBOC_Communication_Tone_{t})` 交互项验证顺周期叠加或逆周期缓冲效应。

- **阶段三（结论重构）：**
  - **核心动作指令**：升级结论解释。在最终学术输出报告（或 Falsification 验证文件 `51_falsification_test.py`）中，验证商业银行的情感传递 (Tone) 与金融科技关注度是在抵御、跟随还是背离央行的沟通指引趋势，这成为原主线（银行自身业务升级与面板效应）上的重磅机制拓展。

**3. 风险预案 (Plan B)：**
- **预判卡点**：如果因为国债收益率分解和央行沟通情绪的季度/年度计算由于缺乏作者（尚玉皇）论文中的“基于金融情感词典三月移平量”的基础数据集导致无法对齐，或是混频数据在年度降频面板合并中存在样本偏误（Aggregation Bias）。
- **替代方案 (Plan B)**：放弃完全复刻论文复杂的VAR降频预测因子，直接引入最成熟的客观市场利率作为替代，即直接调用现成的宏观公开指标“年度/季度国债三年期与十年期的长段期利差 (Term Spread)”以及“Shibor短期资金利率”作为外围宏观波动的控制变量直接并入面板。
