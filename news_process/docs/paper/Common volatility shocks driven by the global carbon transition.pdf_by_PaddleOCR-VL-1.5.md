【角色设定】
你是一位顶尖的学术评审与项目操盘专家，精通理论框架推演与实证金融学项目落地。输出要求极致精简、直击痛点、逻辑严密。

=========================================
第一部分：基于参考论文的项目分析与诊断报告

1. 范式映射与盲区诊断：
- 论文核心机制：资产波动率的激增并非由通用或正面新闻驱动，而是由特定主题（如“金融与监管”）下的纯负面情绪冲击（Negative Sentiment Shocks）通过非对称性驱动；同时，这类冲击会通过全局或行业共同波动因子（Common Volatility Factor）引发传染机制。
- 当前项目盲区：目前 `news_process` 项目在 `config.yaml` 定义的情感与面板聚合逻辑中，依赖情感的线性等权聚合（计算正向、中性、负面比例），假设所有的情绪在冲击力度上是对称的。项目缺失了捕捉由极端负面新闻引发的“非对称不确定性冲击”（Downside Volatility / Risk）维度，忽略了特定主题（如金融科技监管处罚）对商业银行估值的差异化破坏力。

2. 实质性改进项（宁缺毋滥）：
- 改进 A：提取并构建非对称负面情绪波动冲击指数（Asymmetric Negative Sentiment Shock Index）。
  -> 论文依据：Table 6 证明通用情绪指数作用不显著，只有纯负面情感指数（$CC^-$）能够直接放大全局的资产共同波动。
  -> 边际贡献/解决内生性：打破当前的均值平滑（Mean-smoothing）陷阱。通过构建银行维度上的“极端负面情绪方差/偏度”，能更敏锐地识别金融科技或银行业舆情爆发期的系统性风险传染路径，极大地增强被解释变量（如银行风险、股价崩盘敏感度）的实证说服力。

- 改进 B：引入基于主题异质性的局部震荡拆解（Thematic Shocks Decomposition）。
  -> 论文依据：Table 4 与 Table 5 证实政策和监管（Financial & Regulation）带来的冲击显著主导了物理灾难（Disaster）类新闻，即市场反应是对主题高度敏感的。
  -> 边际贡献/解决内生性：将目前的统一负面指标进一步细化分离为“政策与监管处罚类”、“技术与系统崩溃类”等垂直标签。不仅提供了绝佳的异质性检验机制，还能用于构建更强的工具变量（利用行业共同的政策发布冲击作为当地银行的外生冲击）。

3. 冗余剥离：
- 维持原状项：项目当前的 LLM 思维链情感分析（阶段21）远优于论文早期的纯词频字典法（MCCC），务必维持原状，拒绝退回到简单的规则引擎。
- 剥离/剔除项：建议在面板合成（40-50阶段）中直接剔除基于“通用新闻总量”（Total generic volume）或“等权中性新闻统计”的伪控制变量。论文已证明仅仅谈及该话题的中性报道不带来实质波动，继续纳入这些冗余变量只会过度稀释主效应，并在高阶实证检验中引发多重共线性噪音。

=========================================
第二部分：项目重构与优化执行计划书

1. 优先级排布：
- 速赢项（Quick Wins）：在阶段 45 (面板数据构建) 的现有脚本中，基于已经跑出的 `sentiment=="负面"` 标签，增加负面情绪的波动率（方差）、高峰度指标以及纯负向情感占比，无需重跑 LLM 即可实现改进 A。
- 核心攻坚项：为了实现改进 B，升级阶段 21 的 Prompt 指令，让 LLM 在同一调用中增加对负面舆情的“根因分类（如政策监管、技术风险）”，彻底重构底层机制颗粒度。

2. 阶段化执行指令 (SOP)：

阶段一（机制重塑/数据清洗）：
- 指令：修改 `config.yaml` 模块三中 `tone_llm_processing` 的 `prompt_template` 与 `output_format`。在判定为“负面”且满足金融科技/银行实体时，强制要求 LLM 输出 `negative_theme_category`（枚举: ["监管合规处罚", "技术安全事故", "市场与声誉危机", "无/其他"]）。
- 交付物：带有精细化主题下钻维度的 `21_tone_llms.parquet` 重构版。

阶段二（实证/模型重构与检验）：
- 指令 1（非对称指标构建）：修改阶段 45 聚合逻辑。按 Bank-Month/Year 层级，计算：1) `Negative_Shock_Idx` (当期负面声量占比减去历史均值的突增差值)；2) `Sent_Volatility` (期内情绪波动惩罚项)。
- 指令 2（行业共同波动分离）：引入时间固定效应或行业情绪基准均值，分离出单家银行的“特质性负面冲击（Idiosyncratic Shock）”。
- 交付物：包含新一代结构化非对称情绪/波动因子的 `40_panel_yearly.parquet`。

阶段三（结论重构）：
- 指令：彻底变更实证检验的核心故事。不再探讨“金融科技新闻是否带来正面/负面影响”，而应深挖“不同主题的结构性负面舆情，如何非对称地推升银行的下行风险与脆弱性”。要求主回归报告 `监管合规处罚负面主题` 与 `其他负面主题` 的系数差异检验（Chow test）。

3. 风险预案 (Plan B)：
- 致命卡点：全量重跑增加 LLM 负面主题标签（阶段一）耗费成本极高（超百万并发 Token），可能导致项目彻底停滞或超时。
- 替代方案（后处理轻量方案）：放弃阶段一重跑。在阶段 41 之前增加一个本地脚本 `25_theme_regex_labelling.py`。读取现存的 `21_tone_llms.parquet`，针对其中判定为 `sentiment == "负面"` 的子集，写三套高精度的本地正则表达式（如提取“罚单|违规|监管”作为合规类），快速对这数万条语料打标签，当天即可无缝对接实证分析模型重构。
