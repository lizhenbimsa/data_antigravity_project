# 基于《How much can machines learn finance from Chinese text data?》的项目评估与重构执行计划

=========================================
## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**论文核心机制**：该研究提出了一种纯数据驱动的“因子增强正则化预测模型 (FarmPredict)”，通过对高维文本的词频向量进行无监督 PCA 降维提取隐藏主题因子，再结合 L1 惩罚（Lasso）以资产收益率为监督目标（Y）筛选出条件情感词。其核心发现是：在中国以散户为主导的市场，词汇间的交互关联至关重要；且市场存在**非对称的冲击效应**（正面新闻主要驱动交易情绪如“涨停/抢反弹”，负面新闻主导基本面反馈如“造假/立案”，反映了卖空约束的制度特征）。

**当前项目盲区**：项目（`news_process`）现有的情感提取深度依赖于规则嵌套的词典法（`tone_words` 中设定了复杂的否定、转折和极大/弱程度副词乘子，见 config.yaml 385行起）和通用大模型提示词。盲区在于：
1. 人工词典无法自适应中国特色金融语境中新生的特定隐喻组合（如论文识别的“敢死队”等特定名词代指市场行为）；
2. 未能在银行年度面板构建中充分应用新闻情感冲击带来的“非对称性”机制；
3. 将所有词汇作为孤立特征叠加计算，对新闻文本中潜在的高维共现因子（隐含话题）挖掘不足，内生性受限。

### 2. 实质性改进项（宁缺毋滥）
- **改进 A：基于目标变量监督（Target-guided）的文本特征特异性提取（引入 FarmPredict 降维思想）**
  - **论文依据**：论文 2.2 节 FarmPredict 强调跳出主观设定，采用对特定 Y（如 Beta-adjusted return）具有惩罚预测力的词汇作为核心度量。
  - **预期边际贡献/解决的内生性问题**：当前词典属于无条件单变量静态判定。在实证阶段引入以特定宏观或微观目标（如银行净息差、不良贷款率）监督训练出来的“特异性词汇回归因子”，能有效剔除媒体公关中“假大空”的宣传套话，解决传统 NLP 方法无法区分“表层概念炒作（Symbolic）”与“底层实体科技投入（Substantive）”导致的测量偏误，直接锁定具有经济学后果的信号。

- **改进 B：构建金融科技新闻冲击的非对称效应（Asymmetric Impact）度量与多维实证设计**
  - **论文依据**：论文 4.1.1 与 1 Introduction 发现，正面情绪使得收益变化达 83 bps，而负面仅为 26 bps，且词汇属性高度异质（正面重交易，负面重法务/基本面）。
  - **预期边际贡献/解决的内生性问题**：当前我们的面板数据（阶段 40 `40_panel_yearly.parquet`）如果只是通过得分对冲计算整体注意力，将掩盖中国信贷市场和资本市场的明显非对称性。在回归模型中必须分离“正面金融科技新闻”与“负面金融科技新闻（如技术故障、处罚泄露）”作为独立解释变量，并引入“银行所有制结构”或“是否上市（卖空约束替代）”作为调节变量，这能捕捉由于我国差异化监管/约束所带来的截面异质效应，极大提升机制检验的丰富度。

### 3. 冗余剥离
- **剥离建议**：**显著弱化或直接摒弃模块 22 中过度复杂的“规则词典机制（`tone_words.py`）”在主实证中的地位。**当前的 `config.yaml`（385-548行）投入大量算力设置了不同倍数的转折加强（`adversative_boost: 1.5`）及七个层级的多级程度加权词表（极强级 x 3.0，极弱级 x 0.3）。但在中国强降噪和复杂修辞的媒体语境中，基于静态边缘加权的组合极其脆弱。当前流水线已有强大的 LLMs 作为精筛（阶段 21）与基于句法树推理的高级引擎，应把这种工程累赘的传统词典重降级为仅供 Appendix 稳健性比对的 Baseline 控件，切勿在此浪费主要的解释权重。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：立即在 `45_panel_export_main.py` 的指标聚合逻辑中，分拆正面与负面得分指数，构建正负冲击非对称分布的基础宽面板数据。
- **核心攻坚项**：引入 FarmPredict 的机制，通过高维词频矩阵的 PCA 降维配合 Lasso 惩罚，以股票市场数据（针对上市银行）生成一套基于监督学习的“数据驱动金融科技有效信号指数”，与现有 LLM 得分组成复合验证维度。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑与数据清洗）：**
- **动作指令**：在情感分析模块（阶段 22~23的后处理段），利用当前的词库构建文档词表矩阵 (DTM/BoW)。设立过滤阈值筛选高频词汇（如设定 $\kappa$ 滤除词频极低的词）。对于上市银行子样本，对接日度资本市场数据。
- **交付物标准**：不直接修改当前以 LLM 为主干的预测链，而是生成增量特征矩阵 `24_farmpredict_features.parquet`，用主成分提取隐式主题信息（$F_k$）。

**阶段二（实证/模型重构与检验）：**
- **动作指令**：
  1. 在最终分析模型中修改回归方程，由原先的绝对评分整合，改为分离解释变量：$FinTech\_Positive_{it}$ 和 $FinTech\_Negative_{it}$。
  2. 加入调节效应（Interaction Terms）：引入上市状态（Listing Status）或国有属性（SOE）约束，检验非对称市场信号（如“抢反弹”和“立案”式反应）对风险承担的影响差异。
- **稳健性检验标准**：使用 LLM 生成的高置信度情感分类结果替代基于 FarmPredict （或词典法）的结果重复非对称回归测算。两次实验如果在 $Pos$ 和 $Neg$ 维度上的弹性系数呈现数量级差异，则通过稳健性检验。

**阶段三（结论重构）：**
- **核心动作指令**：在最终的研究论述与讨论部分，必须聚焦于“不同信息维度的非对称吸收”：为何正面金融科技报道容易诱发“市值管理或散户追捧”，而负面报道（如同行事故）才能真正推动深层的“机构性防风险技术整改”。将这些现象与中国金融市场（零售驱动+严监管防卖空）环境的特有制度摩擦深度绑定。

### 3. 风险预案 (Plan B)
- **特定数据不可得**：若发现因城商行/农商行（非上市未发债银行）缺乏市场收益率的高频数据，导致无法大面积使用 Lasso 在个体每日级别进行带有监督信号的 Y-回归提取 FarmPredict 特征。
- **替代方案 (Plan B)**：果断退而求其次。放弃全局因子的精准预测拟合，转而采用基础的 **Ad Hoc Topic Model (SESTM) 边缘筛选方案**。利用有公开市场股价的一两百家上市银行的超额收益或使用“行业平均利差”做 Y 进行边缘相关性截断筛选，提炼出中国特色的特定金融科技语料库“正交话题词池”，然后将该训练得出的静态词池及权重以外推形式映射至非上市银行群体。
