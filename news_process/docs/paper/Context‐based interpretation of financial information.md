# 基于《Context-based interpretation of financial information》的项目审计与重构执行计划

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
**范式映射：** 参考论文的核心机制在于“Contextuality（语境关联度）”，即文本信息（如MD&A）的真正价值并不在于其直接独立传递的情感增量，而在于它通过复杂的非线性交互，**改变了投资者对量化财务数字的理解与解释**。论文通过对比不含交互的“部分连接神经网络”和深度融合的“全连接神经网络”，证明了后者的预测能力有质的飞跃。
**盲区诊断：** 当前 `news_process` 项目在本质上属于传统范式（相当于论文中的 benchmark 或部分连接模型）。在当前配置（`config.yaml`）中，不仅模块二、三独立运作，输出的也仅仅是关于银行或金融科技词汇的“情绪倾向性（正面/中性/负面分类）”这样的标量指标。然后这些标量在阶段45被简单合并为 Bank-Year 面板数据，这意味着新闻文本完全剥离了财报数据而独立完成特征提取。这割裂了“新闻事件改变财务基准预期”的真实金融逻辑，未建立文本信息与数字信息间的乘数或非线性协同机制。

### 2. 实质性改进项（宁缺毋滥）
- **改进 A：基于局部锚点的文本特征提取窗口重构 (Local Context Window)**
  - **建议**：摒弃现阶段简单的“上半篇/下半篇(split_ratio: 0.5)”或以全篇为单位提取特征的方式。改为定位文中提及【目标银行】与【特定业绩/金融科技事件】的核心锚点句，并仅提取其紧邻的前一句与后一句（前后共3句构建局部语境区块），进行高维编码输入。
  - **依据**：论文原文：“We extract sentences that contain earnings-related terms... We then extract the adjacent sentences on each side to capture the earnings context more fully.” (页码2/Section 1)。
  - **边际贡献**：大幅提高金融文本特征的信噪比，避免由于冗长的官方新闻报道中充斥格式化套话而严重稀释提取到了真实 Context。

- **改进 B：从单纯的情感极性标注，升级为与财务数据深度交互的多模态特征预测 (Text-Numeric Deep Interaction)**
  - **建议**：终止仅输出情感概率/分类得分的做法。在阶段23 (BERT模型) 中，导出基于目标银行的最后隐藏状态层聚合向量（如 [CLS] 词向量，降低至固定低维度如10维）。在后续分析时，构建类似论文中 Fig 1(a) 描述的结构，使这些新闻上下文的低维向量与企业过去的会计数据同时输入全连接的前馈神经网络。
  - **依据**：论文模型设计：“allowing for interactions through which text contextualizes the numeric input... fully connected model performs 11% higher.” (Section 1/3.2)。
  - **边际贡献**：弥补金融科技新闻或媒体关注度单纯作为一个线性回归控制变量的内生性短板，真正捕获不可观测的“由于技术新闻引发的价值与风险重估”，构建独一无二的文本-数字非线性交互模型。

### 3. 冗余剥离
- **剔除项**：`config.yaml`中的 `tone_words` (词典法情感分析体系)。
- **理由**：包含庞大的否定词列表、程度修饰加强倍数、前瞻性词汇频次等复杂手工特征工程构建。该方法在自然语言处理中已被证伪或效力大幅衰减。正如论文指出通过“unidimensional attributes (如Fog index、手工sentiment)”解释力极弱，必须依赖高维向量以挖掘语义（Section 2）。保留LLMs推断与BERT足矣，耗费算力实现“基准对比方案(TF-IDF dictionary)”是对高频海量新闻处理能力的巨大浪费，应果断剔除。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：
  重构文本取样机制（阶段11与23相关），以句为最小分割单位寻找银行提及，实施三句话截断机制（锚点及其临近上下文）替代全文输入缩减资源开销，同时剔除词典法依赖提升整流水线的吞吐效能。
- **核心攻坚项**：
  在面板数据构建端（阶段40~45之后），不再只把通过 LLM 打标签的离散数值导出成 Stata 面板，而是基于新闻的特征向量（经 BERT [CLS] 或 LLM 降维）搭建带有交互功能的深度学习预测推断框架，证明带有新闻语境（Context）下的模型比传统量化预测效能更好。

### 2. 阶段化执行指令 (SOP)

**阶段一（机制重塑/数据清洗）：基于核心语义窗口的特征降维**
- **动作 1.1**：在预处理/筛选流的 `11_news_bank.py` 或 `12_news_fintech.py` 内部引入 `nltk` 或类似断句工具。对于识别到银行实体的每一有效段落，使用论文的方法获取 `[前一句, 包含实体的句, 后一句]` 拼接为 `local_context_text` 新字段。
- **动作 1.2**：停用/注释掉 `config.yaml` 内有关 `tone_words` 的一切配置执行路线。
- **交付标准**：新产生的 Parquet 数据文件中，存在提取的高信噪比上下文片段特征，且整体预处理运行速度提升。

**阶段二（模型重构与特征交互）：[CLS] 向量注入与联合表征网络搭建**
- **动作 2.1**：修改 `23_tone_berts.py`。除了传统的正面情绪分类预测，增设一个选项在调用 HuggingFace 模型时，抓取最终层特征（Last Hidden State），并利用池化（如平均或者[CLS]本身）产生一个表征当前新闻语境的 dense vector（降维保存以控制存储）。
- **动作 2.2**：编写一个全新的 Python 面板深度学习推断流（替代传统的固定效应面板线性回归代码），要求包含两个输入流并具备全连接层架构（Text Layer 与 Numeric Value Layer），在目标变量为下一期现金流/收益变更（Increase or Decrease）时进行联合优化。
- **稳健性标准**：必须展示部分连接网络（Partially Connected，即文本流与数字流并行无交叉）与全连接网络（Fully Connected，存在节点相互激励）在预测上的 ROC AUC 与 F1 差异，后者作为实质性改进的证据。

**阶段三（结论重构）：引入新闻语境下银行持续力（Context-based Persistence）**
- **动作 3.1**：通过计算新闻的动态交互项变化，构造年度企业层面的盈利与风险持续性异质指标，并从“新闻如何改变传统会计特征认知”的角度重写研究论文（或报告）的核心结论。

### 3. 风险预案 (Plan B)
- **预判卡点**：如果因为导出并使用海量样本数级别下的高维 [CLS] Context Variables 导致极端的显存溢出与存储爆炸（例如千万条新闻对应的浮点数组直接干爆单机内存）；深度神经网络很可能在噪音极大的财务预测中标现出灾难性过拟合。
- **Plan B替代方案 (LLM Proxy Interaction法)**：若 ANN 机制不可得，完全舍弃 [CLS] 抽取，改用 LLM Prompt 直接“模拟”融合作用。直接在 Prompt (阶段21的 Prompt模板进阶版) 中输入：“目标分析银行: {target_bank}，其上期核心财务增速为 {financial_data}。当前金融科技新闻背景为：{content}。请判断该新闻揭示的语境是增强了该银行由于财报所显示的增长确定性，还是削弱了？输出增强/维持/削弱的离散指标。”，依靠大模型的隐层交互来代替自己建模。在技术条件不允许时直接实现文本对数据的 Contextualize。
