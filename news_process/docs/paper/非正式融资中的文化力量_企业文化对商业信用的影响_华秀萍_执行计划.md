# 第一部分：基于参考论文的项目分析与诊断报告

## 1. 范式映射与盲区诊断

### 1.1 论文核心机制提炼

华秀萍等（2023）的核心贡献链条如下：

| 维度 | 论文方法 | 关键创新点 |
|------|----------|-----------|
| **文化度量** | 词向量(Word2Vec) + K-Means聚类 → 从A股上市公司官网文本中数据驱动地发现13种文化维度 → 选取Top-5（道德/创新/勤勉/质量/合作） | 构建了中国特色的**多维度**企业文化词典，突破了 Li et al. (2021b, RFS) 五维度对美国市场的局限性 |
| **词典构建** | 腾讯AI-Lab中文词向量 + 余弦相似度扩展种子词 → 人工筛选 → 各维度保留Top-3000相似词 | 相比传统词袋法，使用词向量模型从语义层面保留上下文信息，解决同义词覆盖问题 |
| **文化强度指标** | TF-IDF加权词频统计 → 各维度文化强度 → 五维等权加总 → 综合文化强度(Culture) | TF-IDF加权避免高频通用词主导，文化度量**逐年演变** |
| **因果识别** | ① 行业均值IV (Wang et al. 2021); ② 1970年农田生产潜力IV; ③ 高管非正常离任多期DID | 双重工具变量 + 准自然实验(外生冲击)的三重因果识别策略 |
| **机制检验** | 分文化维度检验 × 调节变量交互项（Z-Score/Small/Durables）→ 而非传统中介效应 | 避免了"中介滥用"，直接通过交互项验证机制的条件异质性 |
| **异质性分析** | 信息透明度(Trans) × 社会信任(SocialTrust) × 营商环境(BusinessEnv) | 从企业、区域两个层面考察文化替代效应的边界条件 |

### 1.2 当前项目与论文的范式对标

| 论文方法论模块 | 当前项目对应实现 | 落差判断 |
|---------------|-----------------|---------|
| **文本源**: 年报MD&A | **新闻全文/上下文片段** (content_ctx) | ✅ **项目优于论文** — 新闻比年报更高频、更及时，且已实现双轨(full/ctx)消融设计 |
| **词典构建**: Word2Vec + K-Means | **五部权威金融情感词典** (Jiang 2021, Yao 2021等) + IDF加权 | ✅ **项目已覆盖** — 且IDF加权与论文TF-IDF思想同构 |
| **语义增强**: 词向量余弦扩展 | **LLM三角验证 + BERT集成** | ✅ **项目优于论文** — 论文用Word2Vec仅做词典扩展，项目用LLM做全文语义理解 |
| **多维度文化变量** | **单一情感极性(正/中/负)** | ⚠️ **论文优于项目** — 论文从5个文化维度分别检验，项目仅有情感极性一个维度 |
| **TF-IDF加权** | `build_idf_weights()` 已实现 | ✅ **完全对标** — 项目22_tone_words.py已内建IDF加权稳健性检验 |
| **工具变量**: 行业均值IV | `compute_leave_one_out_sentiment()` + 29套Bartik IV | ✅ **项目远超论文** — 省/城市/经济圈LOO + 29维Bartik IV，识别策略密度远超论文的2个IV |
| **工具变量**: 农田生产潜力(1970) | **无对应** | 🔴 **项目缺失** — 但此IV对当前项目（银行金融科技）不适用，无需补充 |
| **DID**: 高管非正常离任 | `merge_policy_shocks()`: DCEP试点 + 金融科技沙盒 | ✅ **项目已覆盖** — 且使用了Callaway & Sant'Anna (2021)多期DID最新方法 |
| **机制检验**: 交互项调节 | **当前缺少分维度交互项回归** | ⚠️ **可借鉴** — 项目可构建情感与银行特征的交互回归 |
| **异质性分析**: 透明度/信任/营商环境 | **媒体异质性(财经/综合/中央/地方) + 地理异质性** | ✅ **项目已有替代方案** — 且媒体维度更契合新闻舆论研究 |
| **固定效应**: Year + Industry + Province | **Bank FE + Year FE** (待Stata端实施) | ✅ **完全对标**，面板结构支持更精细的银行固定效应 |
| **标准误**: 行业聚类 | **bank_province / bank_city 聚类标准误** (已输出) | ✅ **完全对标** |

### 1.3 关键盲区总结

经过严格的范式对标，当前项目在以下方面**真正存在落差**：

> **盲区A**: 缺乏**主题维度分拆**（类比论文的五个文化维度分别回归）。当前项目的LLM情感仅输出正/中/负极性判定，未对新闻的金融科技主题（如AI风控、区块链、数字支付等）进行子主题维度的情感分拆检验。
>
> **盲区B**: 缺乏**机制渠道的交互项回归设计**。论文通过 Culture × Z-Score、Culture × Small、Culture × Durables 等交互项直接检验机制渠道的条件异质性，这种方法论优于传统的逐步中介回归(Baron & Kenny 1986)。

## 2. 实质性改进项（宁缺毋滥）

### 改进 A: 金融科技子主题维度情感分拆

- **具体建议**: 利用项目已有的 `fintech_category`（底层技术/应用场景）分类，以及 `canonicalize_topic()` 函数的二级分类体系，构建子主题维度的情感指标（如 `tone_AI`, `tone_blockchain`, `tone_digital_payment` 等），并在面板回归中分别检验各子主题的效应差异。
- **论文依据**: 华秀萍等 表3 — 五个文化维度（道德/创新/勤勉/质量/合作）分别对商业信用有显著正向影响，但系数大小不同（Quality系数0.0988最大，Integrity系数0.0274最小），揭示了**分维度异质性**。
- **预期边际贡献**: 当前项目仅报告"金融科技整体舆论基调→Y"的回归，无法区分"AI风控类舆论"与"区块链类舆论"对因变量的影响差异。分维度检验可揭示哪类金融科技主题的舆论效应最强，增强论文的政策含义精度。

### 改进 B: 引入机制渠道的交互项回归设计

- **具体建议**: 在45模块的Stata导出面板中，增加以下交互回归变量的预计算：
  - `Tone × bank_type`（SOE vs非SOE的舆论效应差异）
  - `Tone × bank_scale`（大型vs中小型银行的差异化响应）
  - `Tone × has_coverage`（高低媒体关注度下的效应边界）
- **论文依据**: 华秀萍等 表7-表8 — 通过交互项（而非中介回归）检验机制的条件异质性，方法论上更加稳健，避免了传统中介效应的"坏控制"(Bad Controls)问题 (Angrist & Pischke 2009)。
- **预期边际贡献**: 揭示金融科技舆论效应的**异质性边界**，回答"什么条件下舆论基调影响更大"这一核心机制问题。

## 3. 冗余剥离

经审查，当前项目**不存在**明显偏离主线的伪需求模块。关键理由：

- 29套Bartik IV虽数量庞大，但均服务于因果识别的过度识别稳健性检验（over-identification robustness），逻辑自洽
- 双轨(full/ctx)设计虽增加计算量，但属于Hassan et al. (2019, QJE) proximity-based归因的核心方法论要求
- 三种情感方法(LLM/词典/BERT)的三角验证与论文的多维度文化度量异曲同工，非冗余

**结论: 维持原状**，无需剥离现有模块。

## 2. 阶段化执行指令 (SOP)

### 阶段一: 交互变量预计算（Speed Win, P1）

**目标**: 在45_panel_export_main.py的面板导出中，预生成机制检验所需的交互项变量。

**核心动作指令**:

1. **在 `45_panel_export_main.py` 的 `main()` 函数中**, 在步骤 7b (standardize_panel_variables) 之后增加交互变量生成模块：

```python
# --- 7f. 机制检验交互项预计算 (华秀萍等 2023, 金融研究, 表7-8) ---
logger.info("步骤 7f: 机制检验交互项预计算")
# (a) SOE × Tone: 国有 vs 非国有银行的舆论效应差异
if 'bank_type' in panel.columns:
    panel['is_soe'] = (panel['bank_type'] == 'soe').astype(int)
    for track in ['_full', '_ctx']:
        tone_col = f'llm_vote_tone{track}'
        if tone_col in panel.columns:
            panel[f'tone_x_soe{track}'] = panel[tone_col] * panel['is_soe']

# (b) Scale × Tone: 大型 vs 中小型银行的差异化响应
if 'bank_scale' in panel.columns:
    panel['is_large'] = (panel['bank_scale'] == 'L').astype(int)
    panel['is_small'] = panel['bank_scale'].isin(['S', 'XS']).astype(int)
    for track in ['_full', '_ctx']:
        tone_col = f'llm_vote_tone{track}'
        if tone_col in panel.columns:
            panel[f'tone_x_large{track}'] = panel[tone_col] * panel['is_large']
            panel[f'tone_x_small{track}'] = panel[tone_col] * panel['is_small']

# (c) Coverage × Tone: 高/低媒体关注度下的效应边界
if 'has_coverage' in panel.columns:
    for track in ['_full', '_ctx']:
        tone_col = f'llm_vote_tone{track}'
        if tone_col in panel.columns:
            panel[f'tone_x_coverage{track}'] = panel[tone_col] * panel['has_coverage']
```

2. **在 STATA_LABELS 字典中**补充对应的变量标签：

```python
# 机制检验交互项 (华秀萍等 2023, Table 7-8)
'is_soe':                 'SOE Bank Dummy (0/1)',
'tone_x_soe_full':        'Tone × SOE (Full)',
'tone_x_soe_ctx':         'Tone × SOE (Ctx)',
'is_large':               'Large Bank Dummy (0/1)',
'is_small':               'Small Bank Dummy (0/1)',
'tone_x_large_full':      'Tone × Large (Full)',
'tone_x_large_ctx':       'Tone × Large (Ctx)',
'tone_x_small_full':      'Tone × Small (Full)',
'tone_x_small_ctx':       'Tone × Small (Ctx)',
'tone_x_coverage_full':   'Tone × Coverage (Full)',
'tone_x_coverage_ctx':    'Tone × Coverage (Ctx)',
```

**交付物标准**:
- 面板 `.dta` 文件中新增 10+ 个交互项列
- Stata 端可直接运行: `reghdfe Y tone_x_soe_full tone_x_large_full controls, absorb(target_bank year)`

# 子主题维度情感分拆 (对标 华秀萍等 2023 表3 分维度检验)
for topic in ['AI', 'blockchain', 'digital_pay', 'bigdata', 'cloud', 'other_ft']:

## 3. 风险预案 (Plan B)

| 致命卡点 | 概率 | 替代方案 |
|----------|------|---------|

## 附录: 华秀萍等（2023）对本项目最具价值的方法论启示

1. **TF-IDF加权与等权版共存** — 论文使用TF-IDF加权计算文化强度，项目 `22_tone_words.py` 已实现 `build_idf_weights()` 函数，方法论完全同构。**维持原状**。

2. **文化变量的自相关检验** — 论文通过年度自相关系数证明企业文化的"延续性"。项目可在面板阶段对 `llm_vote_tone` 计算 AR(1) 系数作为情感指标时序属性的质量控制。**属于锦上添花**，非阻塞项。

3. **工具变量的排他性论证** — 论文的"行业均值IV"对应项目的Bartik IV和LOO IV，其排他性论证逻辑完全对标。论文的"1970年农田生产潜力"属于面板外部数据，对金融科技研究场景不适用。**维持原状**。

4. **高管非正常离任DID的外生冲击设计** — 论文巧妙利用企业内部的人事变动作为文化变量的外生冲击。项目已使用DCEP+沙盒作为金融科技的政策冲击源，逻辑更简洁直接。**维持原状**。
