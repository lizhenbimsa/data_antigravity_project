# 执行计划：Measuring Corporate Culture Using Machine Learning

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断
- **理论范式映射**：参考论文提出通过词向量模型（Word Embedding，具体为Word2vec）对定性文本资料进行半监督机器学习。利用极少量的初始种子词汇，依据上下文共现关系，在特定业务语料库中泛化生成具有高度语境适应性的专属主题分类词典。然后通过计算这些生成词汇在文档中的 TF-IDF 加权词频，来度量和界定特定的企业属性（文中为企业文化），该方法能在有效避免高频无意义虚词（Cheap Talk）的同时敏锐捕捉具体语境下的隐含意义变迁。
- **当前项目盲区**：目前项目（`news_process`）在识别与度量银行的“金融科技”战略与主题时，极度依赖于**静态的人工维护字典**（如 `config/fintech_dict.json`）。金融科技正在随着云计算、AI、DeFi 的发展而快速进化演变，依靠静态词典匹配存在严重的“词汇更新滞后”与“语境不适配”等固有缺陷，这在测量以时间跨度长为特征的跨年度面板数据时尤为敏感。且项目偏重通过对命中关键词进行绝对计数来计算关注度，未剥离不同词汇的信息熵差异（例如“系统”和“零信任架构”在反映科技含量时的权重本应有云泥之别）。

### 2. 实质性改进项（宁缺毋滥）
- **改进 A：基于 Word2vec 的自适应“金融科技”特征词库生成**
  - **具体建议**：摒弃单纯依赖预置人工字典的做法，以几个最核心的金融科技概念汇集成为“种子词”，在现有的新闻预处理脱敏语料（`00_preprocessing.parquet`）上训练本地的 Word2vec 神经网络语言模型。通过计算余弦相似度，抓取该语料本身衍生的 Top-500 紧密关联特征词，构建动态词典。
  - **论文依据**：Section 3.2 (Generating the culture dictionary) — 将人工标定的种子词进行均值池化，从当前语料库中寻找最高余弦相似度的近义词/共现短语建立词库。
  - **边际贡献/解决的内生性问题**：彻底消除人工维护字典所带来的选择偏差与主观片面性；自动发现当前金融市场新闻中的黑话或新名词，提高指标跨时期的平稳识别度，缓解因新兴科技不断迭代演变造成的衡量指标失效问题。

- **改进 B：引入 TF-IDF 指数加权，深化“技术重度”的指标测度体系**
  - **具体建议**：重构目前仅仅用词汇统计（词频计数）计算的新闻浓度分数。转而在聚合时，采用 TF-IDF 为各个领域特征词赋予区分权重。利用低词频的高优权重，更精确描绘银行机构对前沿领域关注的锐利程度，而非被常规的官方通稿高频词汇（如“数字化”）所稀释。
  - **论文依据**：Section 3.3 (Scoring corporate culture) — 根据词汇在单一文档出现的频率（tf）与涉及范围（逆向文档频次 idf）计算加权矩阵进行评分。
  - **边际贡献/解决的内生性问题**：有效过滤新闻稿中常见的表面化宣导（Window Dressing / Cheap Talk）。防止频繁使用低效术语（即泛泛的商业用语）的套话新闻将具有核心深度的文章淹没，极大提高所构建面板指标的精确度。

### 3. 冗余剥离
- **剔除项**：直接摒弃纯依靠基于人工极性词典的情感分析系统与粗略字典计数模块的扩充维护需求。由于将过渡到“词向量领域扩展+TF-IDF 加权+LLM验证”三位一体的新框架，诸如基于机械维护的繁冗静态字词判定模块可作大幅精简，逐步退出业务主线。

## 第二部分：项目重构与优化执行计划书

### 1. 优先级排布
- **速赢项（Quick Wins）**：基于现有分词语料，训练初始的 WordEmbedding 模型并提取 Top-N 金融科技相似词，进行人工或利用现成的 LLM 并行审核（借助项目的验证阶段功能）组建专属动态词典，替换现有的静态 JSON 文件。
- **核心攻坚项**：在主干业务分类流程及面板聚合流水线（阶段12、42、45）体系下全盘引入基于动态词典与 TF-IDF 倒排权重的计算计分模块。

### 2. 阶段化执行指令 (SOP)

- **阶段一（机制重塑）：自适应领域特征提取（Word2vec）**
  - **动作指令**：
    1. 新增脚本 `11b_train_word_embedding.py`，接收来自 `00_preprocessing` 的文本语料执行中文精确分词和停用词剥离。
    2. 基于 Gensim 库搭建并训练 Word2vec 模型（嵌入维度定为 300，窗口 5）。
    3. 圈定“区块链、人工智能、大数据分析、云计算”等 10-20 余个金本位术语作为种子词。使用余弦相似度计算获取最相关的金融科技同源特征词。
  - **交付物**：形成一个由数据语境驱动的原生动态特征语料库文件（`fintech_dynamic_embedding_dict.json`）。

- **阶段二（实证重构）：基于 TF-IDF 权重的特征向量测量**
  - **动作指令**：
    1. 升级分类与计算分块 `12_news_fintech.py`，在计算命中率之时不再采取“包含几项特征”的布尔策略或等权重词次相加方案，转而在新闻段落级引入针对动态词典的 TF-IDF 打分函数。
    2. 将原“金融科技提及频次”指标更替为连续复合变量`fintech_tfidf_score`。
  - **交付物**：在中间级 Parquet 文件中，银行每一条被识别新闻获得更可靠真实的结构化强度特征变量，并在保留原布尔判定基础上赋予连续权重。

- **阶段三（结论输出）：整合深度指标构建学术面板**
  - **动作指令**：
    1. 修改 `45_panel_export_main.py` 的数据切片与组装逻辑，在生成的面板 `40_panel_yearly.parquet` 中增补新测度指标。
    2. 基于 Bank-Year 年度层面汇总平均 `fintech_tfidf_score`，进行年度纵深观察指标（如 TF-IDF 聚合均值、中位数），为后续回归与冲击响应研究输送可靠度高、防衰变、降噪音的关键控制面板。

### 3. 风险预案 (Plan B)
- **致命卡点预判 1：NLP 语境过窄导致训练收敛极差，模型捕捉不到有效的衍生技术词汇。**
  - **替代方案 (Plan B)**：若 `news_process` 原始语料数据量不够庞大导致 Word2vec 词组联结匮乏，则退回引入预训练的成熟财经语料开源中文向量底座库（如腾讯开源词向量词典、或者哈工大的金融领域词向量底座），在已有底座上固定空间进行余弦相似向量检索，而不进行从零训练。
- **致命卡点预判 2：TF-IDF 与部分银行特定命名实体产生过度耦合放大（例如某些银行业务专有词极其稀有但并没有技术深度，却因罕见造成了高 IDF）。**
  - **替代方案 (Plan B)**：在提取相关词条阶段，使用预构设的过滤词白名单与黑名单。对于识别出的 Top-500 特征词汇，加入 LLM 精筛审阅校验机制（调用阶段已集成的 Claude/GPT 函数接口），对过度拟合的人名、机构缩写与非功能用语予以定向屏蔽。
