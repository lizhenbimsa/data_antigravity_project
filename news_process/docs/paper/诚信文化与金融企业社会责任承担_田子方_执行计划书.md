# 诚信文化与金融企业社会责任承担 — 项目分析与执行计划书

> **参考论文**: 田子方, 左从江, 李涛, 赵宣凯 (2025). 诚信文化与金融企业社会责任承担. 《金融研究》, 2025(09), 152-169. JEL: Z10, M14, G30.
>
> **当前项目**: `news_process` — 基于多元NLP的中文财经新闻银行级情感分析与面板数据构建系统

## 第一部分：基于参考论文的项目分析与诊断报告

### 1. 范式映射与盲区诊断

#### 1.1 论文核心机制提炼

田子方等 (2025) 的核心研究范式可拆解为三层：

| 维度 | 论文范式 | 核心要素 |
|------|---------|---------|
| **文化量化** | 有监督ML + LLM (Qwen1.5-110b) | word2vec种子词筛选 → SVM深度筛选 → LLM逐句标注 → 字数/句数占比指标 |
| **因果识别** | OLS + 2SLS IV + 多重稳健性 | IV₁=高管学术经历, IV₂=地级市历史书院数; 6类替换度量 |
| **机制路径** | 信息透明度 + 经营风险 | LR/ILL/GAM (信息不对称代理); ROA标准差 (经营风险) |

#### 1.2 当前项目与论文的真实落差诊断

**▶ 落差A: LLM文本度量的方法论深度**

论文采用 **三阶段有监督文本筛选管线** (word2vec → SVM → LLM)，构建了"诚信文化强度指标"。当前项目的LLM模块 (`21_tone_llms.py`) 采用的是**多模型多数投票(Majority Vote)的情感分类**，而非论文式的"文化维度提取 + 强度量化"。

- **论文的核心创新**: 不是让LLM直接分类情感，而是让LLM**判断每句话是否体现诚信文化特征**，再通过字数/句数占比构建连续型文化强度指标。这是一种**概念度量(Concept Measurement)**范式，而非情感极性判断。
- **项目现状**: `21_tone_llms.py` 已实现CoT推理链+多模型投票+双轨对照，方法论严谨度**在情感分析维度已超论文水准**。论文的Qwen1.5-110b单模型方案无多模型三角验证，学术说服力反而弱于当前项目的多模型投票架构。

> **诊断结论**: 项目在情感分析技术上无需向论文对齐。但论文提供了一个**值得借鉴的上游变量构建思路**——可将类似的"文化维度标注"逻辑嫁接到项目中，构建"金融科技文化/创新文化强度"等中间变量。

**▶ 落差B: 因果识别策略的多工具覆盖**

论文的2SLS IV策略值得关注：
- **IV₁ (高管学术经历)**: 微观个体层面IV，通过"学术背景 → 道德标准 → 诚信文化"的排他性机制发挥作用
- **IV₂ (历史书院数量)**: 地理-历史层面IV，利用明清时期的儒家教育资源分布作为外生冲击源

当前项目 (`44_panel_iv_did.py`) 已构建了**29维Bartik Shift-Share IV + 经济圈LOO + 省/城市LOO**，在IV维度的覆盖广度**远超论文**。但论文的IV设计思路——利用**历史/文化地理变量**作为IV——是项目可以借鉴的增量维度。

> **诊断结论**: **维持原状**。项目的29维Bartik IV + DID Event Study体系在因果识别的广度和深度上已显著优于论文的2个IV。

**▶ 落差C: 异质性分析的分组维度**

论文的异质性分析涵盖5个维度: 企业年龄、经营绩效(ROA)、股权集中度(Top10)、市场化水平(樊纲指数)、外部关注度(百度指数)。项目目前的面板 (`45_panel_export_main.py`) 中已包含银行类型、规模、地理等分组维度，但**缺乏论文特有的外部制度环境变量**。

> **诊断结论**: 市场化指数、百度搜索指数等外部变量属于Stata回归阶段的控制/调节变量，不属于`news_process`管线的职责范畴。**维持原状**。

### 2. 实质性改进项（宁缺毋滥）

#### 改进A: 基于LLM的"金融科技文化维度"概念强度指标构建

- **具体建议**: 参照论文的 word2vec → SVM → LLM 三阶段范式，在 `21_tone_llms.py` 的Prompt中增加一个**"金融科技创新文化强度"维度**的输出。具体而言：让LLM在输出情感标签的同时，判断该新闻片段是否反映了目标银行的"创新文化"或"数字化转型决心"，并给出0-1的置信度。
- **论文依据**: 田子方 (2025) §三(二) "如何度量金融企业诚信文化"——通过LLM逐句判断是否体现特定文化特征，再聚合为连续型占比指标。Li et al. (2023, SSRN) 同样使用LLM+有监督分类构建企业文化指标。
- **边际贡献**: 当前项目的多因子面板中，情感变量(tone)和关注度变量(attention)已非常成熟，但缺乏一个**"文化/价值观"维度的变量**。这一变量可作为独立的解释变量或调节变量进入Stata回归模型，填补face validity的空白。

> [!IMPORTANT]
> **实施成本评估**: 🟡 中等。仅需修改Prompt模板增加一个JSON输出字段 + 在`41_panel_encode_aggregate.py`中增加聚合列。不影响现有管线。

#### 改进B: LLM分类验证集的系统化构建（SVM预筛逻辑的思路迁移）

- **具体建议**: 论文使用SVM模型对700万句文本进行预筛（阈值5%），人工标注400句作为验证集。当前项目的`32_news_llms_human.py`已实现分层随机抽样+双盲标注，但**缺乏论文中的SVM/ML预筛环节**——即用一个轻量级分类器先过滤"确定不相关"的文本，以大幅降低LLM API调用成本和提高信噪比。
- **论文依据**: 田子方 (2025) §三(二) "诚信文化相关句子的筛选" — SVM预筛将700万句压缩至可管理规模，显著提升效率。
- **边际贡献**: 在大规模生产中 (千万级语料)，SVM/FastText等轻量ML预筛可节约50%+的LLM API成本。但对于当前项目已经完成数据处理的场景，**此改进为前瞻性设计建议**，不影响已有结果。

> [!NOTE]
> **实施成本评估**: 🔴 高（需要训练集构建和模型选型）。建议列为`v2.0`版本的技术债。**当前阶段不执行**。

### 3. 冗余剥离

经逐模块对照审查，**未发现偏离主线或价值极低的"伪需求"模块**。

理由：
1. 论文的研究范畴是"诚信文化 → 社会责任"，属于**非正式制度 → 非财务绩效**的因果链条，与当前项目"金融科技新闻情感 → 资本市场异象"的因果链条**并行但不冲突**。
2. 当前项目的29维Bartik IV、DID Event Study、距离衰减敏感性、词典/BERT/LLM三轨情感比对等全部模块，均有明确的学术服务对象和顶刊文献支撑。
3. 论文中的特定模块（如华证ESG评级作为被解释变量、高管学术经历作为IV）属于**Stata回归层面的变量选择**，不涉及`news_process`管线的功能模块。

> **结论: 无需剔除任何现有模块。**

#### 阶段一：Prompt维度扩展（机制重塑）

> **核心动作**: 在`21_tone_llms.py`的Prompt模板中新增一个JSON输出字段

**SOP-1.1**: 修改`config/config.yaml`中的`tone_llm_processing.prompt_template`:

## 总体评估

| 维度 | 论文水平 | 当前项目水平 | 判断 |
|------|---------|------------|------|
| LLM文本度量 | 单模型(Qwen1.5-110b), 无三角验证 | 多模型投票+双轨验证+CoT | **项目优于论文** ✅ |
| 因果识别 | 2个IV + OLS | 29维Bartik IV + DID Event Study + LOO | **项目远优于论文** ✅ |
| 稳健性检验 | 6类替换度量 + 聚类调整 | 窗口半径敏感性 + 距离衰减 + 实体遮蔽 + Rotemberg诊断 | **项目优于论文** ✅ |
| 文化维度变量 | ✅ 有 (诚信文化强度) | ❌ 缺失 | **可借鉴论文思路** ⚡ |
| 机制路径检验 | 信息不对称 + 经营风险 | 未直接覆盖 (属Stata阶段) | **维持原状** (下游任务) |

> [!TIP]
> **唯一实质性改进项**: 借鉴论文的"LLM文化维度度量"思路，在现有Prompt中增加"创新文化强度"输出维度，为面板新增一类全新的概念度量变量。其余维度当前项目已逻辑自洽或显著优于论文。
