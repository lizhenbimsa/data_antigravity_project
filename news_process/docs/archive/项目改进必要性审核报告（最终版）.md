## ❌ 错误处理和重试机制 - 已实现

### 代码证据

**文件**: `pipeline/sentiment/tone_llms.py` 第 212-239 行

```python
async with semaphore:
    for attempt in range(MAX_RETRIES):  # ✅ 已有重试循环
        sleep_s = _compute_retry_sleep(attempt)  # ✅ 已有指数退避
        try:
            async with session.post(...) as resp:
                if resp.status == 200:
                    # 成功处理
                    return row_idx, model_id, result_text, track
                elif resp.status in (429, 500, 502, 503, 504):  # ✅ 已处理临时错误
                    logger.warning(f"API HTTP {resp.status} - 等待 {sleep_s:.1f}s 后重试...")
                    await asyncio.sleep(sleep_s)
                else:
                    # 永久错误，不重试
                    break
        except asyncio.TimeoutError:  # ✅ 已处理超时
            logger.warning(f"请求超时 - 等待 {sleep_s:.1f}s 后重试...")
            await asyncio.sleep(sleep_s)
        except Exception as e:  # ✅ 已处理其他异常
            logger.warning(f"异常: {e} - 等待 {sleep_s:.1f}s")
            await asyncio.sleep(sleep_s)

# 所有重试均失败
logger.warning(f"所有 {MAX_RETRIES} 次重试均失败")
return row_idx, model_id, None, track
```
