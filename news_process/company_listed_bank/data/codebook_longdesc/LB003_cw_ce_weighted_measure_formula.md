## CORE

本家族记述的不是一个具体列, 而是贯穿整份银企共现面板与七个替代权面板的一条通用构造公式, 即份额加权臂乘等权算术平均臂两条并排的加权测度通式。给定银行乘年层面任意一个非缺失数值型源列, 例如某银行当年的资产规模、资本充足率或某项情感测度, 通式把它转写为公司乘年层面的加权测度: 份额加权臂以该公司当年在该轨的共现分布作为权重, 对该公司当年涉及的全部银行的源列取值做份额加权求和; 等权臂则不使用共现份额, 直接对同一批银行的源列取值做算术平均。两臂并排呈现, 互为稳健性对照, 不设主次之分, 也严禁把两臂混入同一过度识别的联合检验。

份额加权臂在方法论谱系上直接承接经济学文献中份额乘冲击的构造范式。这一范式最早由 Bartik 在评估地方经济发展政策效果时提出, 用行业全国增长率作冲击项、以地区行业构成作份额项, 构造出地区层面的暴露测度; 该书至今仍是份额乘冲击构造思想的奠基文献。Goldsmith-Pinkham、Sorkin 与 Swift 在美国经济评论上系统梳理了此类工具变量的识别逻辑, 明确指出份额加权设计的有效性取决于份额本身是否满足外生性假设, 并给出了罗腾伯格权重等诊断工具帮助研究者判断哪些份额单元对识别结果贡献最大; 本家族的份额加权臂正是同一逻辑骨架在银企共现语境下的具体实例化, 份额项换成了公司当年对各银行的媒体共现占比, 冲击项换成了银行侧的候选源列。Borusyak、Hull 与 Jaravel 在经济研究评论上进一步区分了份额外生路径与冲击外生路径两种不同的识别叙事, 并证明常规份额加权回归系数在数学上等价于以冲击项本身作工具变量的转换回归; 二〇二五年他们在经济展望杂志上发表的实践指南把两种识别路径整理成便于研究者对照使用的检查清单, 明确列出份额不完整、份额需要重新归一化等常见处理方式的取舍利弊, 本家族分母限定为该测度该年非缺失共现银行并重新归一, 正是遵循了这份检查清单里对不完整份额情形的正面处理建议。Adão、Kolesár 与 Morales 则从推断层面提醒研究者, 份额加权设计下常规的聚类标准误往往过窄, 需要采用对暴露稳健的标准误估计方法, 这一提醒同样适用于任何以本通式构造出的加权测度在后续回归分析中的推断环节, 不可掉以轻心地套用普通最小二乘的默认标准误。

等权臂的存在则是为了从另一个角度检验份额加权臂的结果是否被少数高权重银行所驱动。当某公司当年的共现高度集中在极少数银行身上时, 份额加权臂几乎退化为对该少数银行源列取值的直接读取, 此时若把结果单纯归因于加权设计本身, 便可能掩盖了背后其实是极端集中分布在发挥作用这一事实; 等权臂不使用份额信息, 把公司当年涉及的全部银行一视同仁地取算术平均, 因而能够揭示出加权臂与等权臂之间的系数差异究竟在多大程度上是由共现分布的不均衡驱动的。两臂对照读法在本项目的加权测度体系中反复出现, 是理解加权测度稳健性的关键工具。此外, 通式对源列本身没有任何限制, 意味着理论上凡是银行乘年层面存在的数值列都可以套用本通式生成对应的公司乘年加权测度, 这也是本项目刻意不逐列枚举全部组合、转而把构造逻辑本身作为一个独立家族收录的根本原因: 逐列枚举会产生远超本项目其余全部家族总和的列数, 而构造逻辑只有一份, 理解了通式便理解了全部实例。

【公式逐项拆解与手算示例】为了让通式的运作机理更为具体, 不妨以一个简化的手算示例说明份额加权臂的计算步骤。设某公司在某一年份该轨涉及三家银行, 去重共现篇数分别为六篇、三篇与一篇, 合计十篇, 则三家银行的共现份额分别为十分之六、十分之三与十分之一; 若这三家银行当年在银行乘年主面板上的源列 X 取值分别为八十、五十与三十, 且三者均非缺失, 则份额加权臂的取值为十分之六乘八十加十分之三乘五十加十分之一乘三十, 计算结果为四十八加十五加三, 合计六十六; 与之对照, 等权臂的取值则是三者的算术平均, 即八十加五十加三十除以三, 结果约为五十三点三三。两者的差异, 即六十六与五十三点三三之间的差距, 直接反映了份额分布的不均衡: 份额最高的银行同时也是源列取值最高的银行, 使得份额加权臂系统性地高于等权臂。若反过来, 份额最高的银行恰好是源列取值最低的银行, 则份额加权臂会系统性地低于等权臂, 这正是两臂对照能够揭示份额分布与源列取值之间协同关系的直观体现。若三家银行中有一家当年源列缺失, 例如份额最高的那家银行 X 取值缺失, 则该银行须从加权计算中剔除, 分母重新归一为其余两家银行的份额之和即十分之四, 份额加权臂退化为十分之三除以十分之四乘五十加十分之一除以十分之四乘三十, 即四分之三乘五十加四分之一乘三十, 结果为三十七点五加七点五, 合计四十五, 与三家银行均非缺失时的六十六相比出现明显跳变, 这一跳变并非计算错误, 而是加权口径下分母限定非缺失银行并重新归一这一设计的必然结果, 使用者在观察到跨年度加权测度剧烈波动时, 应首先核查是否存在成分银行的缺失结构发生变化, 而非直接将波动解读为经济含义上的真实变动。

【设计选型的取舍与被放弃的备选方案】在确定当前的分母重新归一规则之前, 本项目实际考虑过至少两种备选处理方式。第一种备选方案是分母恒定取该公司该年该轨涉及的全部银行份额之和即恒为一, 缺失银行对应的份额直接损失而不重新分配给其余银行, 这一方案的优点是份额权重本身与源列是否缺失完全解耦、便于跨列横向比较同一份额结构, 但缺点是当缺失银行占份额比重较大时, 加权测度会系统性地向下偏移且偏移幅度因源列而异, 使得同一份额结构在不同源列上产生不可比的隐性缩水, 这一缺陷被判定为不可接受, 因而被放弃。第二种备选方案是对缺失银行的源列取值做某种插补, 例如用同年同轨全体银行的均值或中位数填补后再纳入加权计算, 这一方案的优点是保留了原始份额结构的完整性, 但缺点是插补值本身携带的不确定性会被无声地混入加权测度, 且插补方法的选择本身即引入了额外的、难以向读者充分说明的建模自由度, 有悖于本项目一贯追求构造逻辑透明、可复核、零臆造插补的原则, 因而同样被放弃。最终采纳的方案, 即分母限该测度该年非缺失共现银行并重新归一, 是在偏移系统性与插补不确定性之间权衡后的选择, 其代价是加权测度的可比性会因缺失结构的变化而在跨年度、跨公司之间产生细微不一致, 这一代价通过覆盖率诊断列即另一家族记述的加权测度可用比例被显式披露给使用者, 而非被悄悄掩盖, 这正是本项目一贯的透明化设计取向。

【与七替代权面板及两替代聚合面板的通式复用关系】本通式并非仅服务于媒体共现主面板, 而是被七个替代权面板与两个替代聚合面板共同复用的底层引擎。七替代权面板把份额项的输入从媒体共现分布替换为贷款关系、网点地理邻近、董事联结、监事联结、高管联结、董监高合并联结与股东持股七类关系强度, 但份额加权求和与等权算术平均两臂并排、分母限非缺失银行并重新归一的运算逻辑逐字节相同; 基期冻结面板则在时间维度上对份额项做了一次性冻结处理, 即不再逐年重新计算份额, 而是固定沿用该公司该轨面板窗内首次出现非零共现年份的份额分布, 此后各年仅更新被加权的源列 X 本身, 通式的份额加权求和步骤在数学形式上保持不变, 只是份额项不再是当期变量而是历史常量; 当年主办银行面板则把份额项极端化为独热向量, 即权重全部集中于当年共现篇数最高的单一银行, 其余银行权重归零, 此时份额加权求和退化为直接读取该主办银行的源列取值, 等权臂同样退化为对单一银行取值的算术平均, 二者在数值上恒等, 这是通式在极端份额分布下的自然退化情形而非另立新公式。由此可见, 全部八套权重版本与两套替代聚合口径, 本质上都是同一条份额加权乘等权对照通式在不同份额项定义下的具体实例, 使用者一旦完整理解本家族记述的通式本身, 便无需在七个替代权面板与两个替代聚合面板的各自长文中重复学习加权计算的数学细节, 只需关注各衍生面板在份额项定义上的差异化设计动机即可, 这正是本项目把通式单独抽出收录为独立核心家族、而非在每张衍生面板文档中逐一重复完整公式推导的根本用意。

【推断层面的稳健标准误注意事项深化】除前述 Adão、Kolesár 与 Morales 关于对暴露稳健标准误的一般性提醒外, 本通式在具体应用中还存在若干值得展开的推断细节。其一, 由于同一家银行的源列取值会同时出现在多家公司的加权测度构造中, 跨公司的加权测度观测值之间通过共享的银行侧源列产生了机制性的相关性, 这种相关性并非样本抽样偶然性所致, 而是加权构造设计本身内生的结构性关联, 常规假设观测值相互独立的推断框架会低估标准误, 建议在正式推断中按银行侧聚类或采用对暴露结构显式建模的推断方法; 其二, 当研究设计把加权测度用作解释变量而非结果变量时, 还需额外考虑份额项本身是否与误差项相关这一更根本的识别问题, 即前述份额外生性假设是否在具体应用情境下成立, 这一假设的可信度需要结合份额形成的时间先后关系、份额是否可能预期到未来结果等制度背景知识逐案判断, 不存在放之四海而皆准的默认结论; 其三, 罗腾伯格权重诊断作为识别贡献分解工具, 建议作为加权测度构造完成后的常规诊断步骤纳入分析流程, 用以核查估计结果是否被极少数份额单元过度驱动, 尤其是在共现分布高度不均衡的公司子样本上, 这一诊断的价值更为凸显。

【与相邻家族的边界辨析】本家族与另一份记述七替代权面板总纲的家族长文、以及分别记述基期冻结与当年主办银行两种替代聚合口径的家族长文, 在内容分工上须明确区分边界, 避免重复或遗漏。本家族的职责边界严格限定于加权测度通式本身的数学构造、参数选取与方法论根据, 即分母重新归一规则、两臂对照的诊断价值、备选方案取舍的理由等与具体权重来源无关的共性内容; 七替代权面板家族的职责边界则是逐一说明七类关系强度权重各自的经济学构念动机与数据来源, 不重复推导加权公式本身; 基期冻结与当年主办银行两个家族的职责边界是说明份额项在时间维度冻结、在银行维度极端压缩这两种特殊处理各自的设计动机与配套诊断列, 同样不重复推导公式本身。这一分工原则镜像了本项目在文献综述部分反复强调的构造逻辑与具体实例分离的收录哲学, 目的是避免同一份数学推导在多篇长文中被反复誊抄, 既节省篇幅, 也降低未来若通式本身发生迭代修订时需要同步更新多处文档的维护成本, 使用者若想理解某一具体权重来源背后的经济学动机, 应查阅对应的衍生面板家族; 若想理解加权测度本身的数学机制、参数敏感性与推断注意事项, 则应以本家族为唯一权威来源, 不应在其余衍生面板家族中寻找与本家族内容重复的公式推导。

【构念效度与测量误差的进一步讨论】源列 X 本身的测量质量直接决定了加权测度的下游有效性, 这是通式设计中一个容易被忽视但至关重要的前提假设: 通式本身只负责把银行侧已经存在的数值列正确地转写到公司乘年层面, 并不能修正或弥补源列 X 自身可能携带的测量误差, 若 X 是某项基于大语言模型或情感词典构造出的语调测度, 则该测度本身的构念效度、稳健性水平会原样传导至加权后的公司层面测度, 加权过程本身既不放大也不缩小这一测量误差的相对比例, 只是按份额结构重新分配。这意味着使用者在解读任何具体的 cw 或 ce 加权测度实例时, 应首先追溯该测度所对应的银行侧源列本身的构造逻辑与已知局限, 而非孤立地评估加权测度本身的统计性质。此外, 由于源列 X 在银行乘年层面本身可能存在三轨、多词典、多语言模型等并置稳健性设计, 加权测度通式会忠实地把这些并置结构原样保留到公司层面, 即公司层面同样会出现对应轨道、对应词典、对应模型的多个平行加权测度列, 这些平行列之间遵循与源列相同的互为稳健性、禁止混入同一过度识别检验的铁律, 通式本身不改变、也不应改变这一上游已经确立的稳健性并置结构。理解这一点有助于使用者在面对本项目规模庞大的加权测度列集合时, 建立起正确的心智模型, 即列数虽多, 但背后只有一份构造公式与一套继承自银行侧的稳健性并置逻辑, 不应把每一个具体的 X 实例都当作需要单独重新理解方法论的孤立测度。

【小结】综上, 本家族记述的份额加权乘等权对照通式是本项目全部加权测度体系的数学地基, 其设计吸收了份额乘冲击文献关于份额外生性、诊断权重与稳健推断的核心洞见, 并结合本项目自身的门控双宇宙、三轨并置、缺失处理透明化等既有设计原则, 形成了一套逻辑自洽、可推广至任意银行侧源列、可复用于八套权重版本与两套替代聚合口径的统一构造框架。使用者理解了本家族记述的这一份公式与其背后的取舍逻辑, 便掌握了解读本项目全部加权测度衍生列所需的全部数学工具, 后续遇到任何具体的 cw 或 ce 实例列, 只需回到本家族查证公式细节, 无需在各衍生面板文档中重复求证。这也解释了为何本项目在收录哲学上刻意采用结构性长文加表格继承的两层结构而非逐列独立长文, 因为对于以通式批量生成的衍生列而言, 逐列撰写独立长文不仅工作量呈组合爆炸式增长, 更会造成同一段数学论证在成百上千篇文档中被逐字重复, 既无助于使用者理解, 也大幅增加未来维护成本, 唯有把构造逻辑收敛到本家族这一单一权威源头, 才能让整套加权测度体系保持长期可维护、可审计, 这一收敛也为未来若新增第九、第十套替代权重版本时的文档扩展提供了现成的模板, 新增权重版本只需说明份额项的经济学构念动机与数据来源, 加权计算的数学细节可直接援引本家族既有论证, 无需另起炉灶重新推导, 这一可扩展性正是把通式单独收录为独立核心家族、并坚持结构性长文加表格继承两层收录哲学所换来的长期收益。
