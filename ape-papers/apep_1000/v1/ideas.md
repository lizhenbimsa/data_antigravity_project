## 创意 1：州公务员养老改革对地方劳动力流动性的影响  
**政策：**多州在2010-2018年间依次实施公务员养老福利改革（增加缴费比例、调整退休年龄）。  
各州实施时间（部分示例）：加利福尼亚2012，纽约2013，伊利诺伊2015，密歇根2017，德克萨斯2018。  

**结果变量：**  
- 劳动力流动率（从CPS微数据推断，CPS地址变动率，公共API可利用Census ACS的“迁徙率”指标）  
- 就业稳定性（ACS就业状态变动变量）  
- 变量代码可借助Census ACS REST API的迁徙相关表格（例如IPUMS数据集公开变量）  

**识别策略：**  
利用各州改革实施的时间差，采用双重差分（DiD）方法估计改革前后，实施州与未实施州之间的劳动力流动差异变化。改革时间的州级交错实施为变化识别提供可行性，假设各州之间潜在趋势平行。  

**创新性：**  
现有大量研究关注养老改革对财政影响或退休行为，但鲜有系统证据检验养老改革对劳动力流动及就业稳定性的因果效应，尤其在跨州异质性背景下。  

**可行性检验：**  
- 变异性：处理州约10个，对照州约20个  
- 数据可访问性：Census ACS REST API覆盖迁徙及就业状态指标，数据公开且更新及时  
- 未被过度研究：养老改革对劳动力流动影响目前文献较少，具备创新空间  

**DiD 早期可行性评估：**  

| 标准             | 评估 | 说明                               |
|------------------|------|----------------------------------|
| 处理前期数量     | 一般 | 多州分布，但非全部州都有改革         |
| 进入处理的选择性 | 一般 | 改革多因财政压力驱动，涉及选择性       |
| 对照组质量       | 强   | 有足够未改州作为比较                  |
| 处理集群         | 一般 | 约10个处理州，存在一定集群限制         |
| 并行政策         | 一般 | 需控制同期劳动力市场相关政策变化        |

**主要关切：**  
需额外检验改革前的平行趋势假设，控制异质性同时防止遗漏变量偏误。

## 创意 2：最低失业保险金增加对就业入职率的断点回归分析  
**政策：**部分州按照失业者过去工资设置失业金发放临界阈值，存在固定最低失业保险补助额的年龄和收入断点（例如某收入边界）。  

**结果变量：**  
- 月度新入职率（BLS JOLTS数据中的就业开岗数及入职数，API变量如“hire rate”）  
- 失业率（BLS季节调整数据，API变量“UNRATE”）  

**识别策略：**  
利用失业金最低补助标准中的年龄或收入临界阈值，实施断点回归（RDD）。通过比较断点两边失业保险待遇不同群体的新就业率，估计失业保险金对就业入职的因果影响。  

**创新性：**  
失业保险对失业持续时间的影响已有研究，较少基于严格RDD设计运用断点清晰的最低失业金规则来估计就业流入。  

**可行性检验：**  
- 变异性：多州采用不同补助规则，断点设计具有清晰针对性  
- 数据可访问性：BLS JOLTS及失业率数据公开，可利用公共API获取分州数据  
- 未被过度研究：基于断点的就业影响评估较少，填补文献空白  

**DiD 早期可行性评估：**（主要为RDD，DiD评估仅供参考）  

| 标准             | 评估 | 说明                                |
|------------------|------|-----------------------------------|
| 处理前期数量     | N/A  | 断点构成自然实验，即时估计             |
| 进入处理的选择性 | 强   | 断点由法定规则决定，选择性弱           |
| 对照组质量       | 强   | 断点两边样本高度可比                  |
| 处理集群         | N/A  | 断点局域效应，非集群式政策              |
| 并行政策         | 一般 | 其他失业相关政策需控制                |

**主要关切：**  
断点附近样本量需足够，且断点外效应不可过大以免扰动估计。

## 创意 3：带薪产假法律对女性劳动参与率的动态双重差分评估  
**政策：**2010-2020年间多州分阶段实施带薪产假政策，规定最低带薪产假天数。  
已实施州示例：新泽西2010，加州2004已延长，罗德岛2014，华盛顿2017等。  

**结果变量：**  
- 劳动参与率（Census ACS “LFPR”变量）  
- 女性劳动力市场退出率（ACS中就业状态）  

**识别策略：**  
采用带薪产假实施时间点的州级DiD设计，利用交错政策实施在时间和空间上的变异，控制州和年份固定效应，检验政策实施对女性劳动参与率的影响。  

**创新性：**  
带薪产假效应已有文献，但多为单州或短期分析，缺少跨州扩展、动态效应的严格因果识别。  

**可行性检验：**  
- 变异性：至少8-10个实施州，20多个未实施州作为对照  
- 数据可访问性：ACS中详细就业参与变量可通过Census API获取  
- 未被过度研究：动态差分分析和全面跨州数据应用较少  

**DiD 早期可行性评估：**  

| 标准             | 评估 | 说明                               |
|------------------|------|----------------------------------|
| 处理前期数量     | 强   | 多州实施，处理样本及时分布均匀          |
| 进入处理的选择性 | 一般 | 政策多受政治经济因素影响，存在选择性        |
| 对照组质量       | 强   | 多对照州可用，基础平行趋势较好             |
| 处理集群         | 强   | 处理州数较多，集群效应可内部控制            |
| 并行政策         | 一般 | 需控制其他女性权益政策变动                 |

**主要关切：**  
需严格检验异质性效果和潜在并行趋势偏误。

## 创意 4：职业证书门槛改革对青年就业匹配的断点回归分析  
**政策：**部分州对某类技术工种设置最低考试分数线，考试合格即获得证书，影响职业进入资格。  
典型断点：考试分数线（如70分）为准入门槛。  

**结果变量：**  
- 年轻人（20-30岁）正式就业率  
- 职业匹配度指标（可通过ACS行业编码推断）  

**识别策略：**  
围绕分数线断点采用局部线性回归RDD，比较正负临界考生成绩的就业率及匹配差异，因证书资格赋予的自然实验性质保证识别可信。  

**创新性：**  
市场准入门槛对青年就业匹配影响研究相对缺乏，现有文献多为描述性或工具变量估计，利用断点识别更具说服力。  

**可行性检验：**  
- 变异性：多州存在考试分数线标准，样本覆盖较广  
- 数据可访问性：ACS行业及就业数据可以通过API获取，考试成绩部分需通过州政府公开数据补充  
- 未被过度研究：断点设计下对青年就业匹配的研究较少，有创新点  

**DiD 早期可行性评估：**（主要RDD设计）  

| 标准             | 评估 | 说明                               |
|------------------|------|----------------------------------|
| 处理前期数量     | N/A  | 断点即时构成处理                  |
| 进入处理的选择性 | 强   | 分数线为制度设定，非个体选择         |
| 对照组质量       | 强   | 符合断点设计要求，临界两边可比         |
| 处理集群         | N/A  | 非集群型处理                      |
| 并行政策         | 一般 | 技术职业相关政策需控制              |

**主要关切：**  
数据需能获取考试分数及就业匹配详细度，需注意样本规模和有效断点窗口宽度。

## 创意 5：增加最低劳动时间标准对兼职劳动力的收入和就业影响——州级双重差分  
**政策：**部分州在2010-2020年内逐步提高“最低劳动时间标准”，即规定工作小时数下限影响兼职工类别认定及福利获取。  
示例州：马萨诸塞2012，俄勒冈2015，佛罗里达2019等。  

**结果变量：**  
- 兼职就业人数（CPS“按小时分类”变量）  
- 平均小时工资（BLS CPI数据细分可获取）  

**识别策略：**  
利用州与时间上政策实施的交错差异，通过DiD评估最低劳动时间标准调整对兼职就业结构及小时工资的因果影响。  

**创新性：**  
关于小时标准微观调整对兼职群体影响的政策评估相对缺乏，现有研究多集中最低工资或总体就业，不区分兼职影响。  

**可行性检验：**  
- 变异性：处理州约6-8个，多个未调整州作对照  
- 数据可访问性：CPS和BLS数据通过公共API可获得小时就业和工资信息  
- 未被过度研究：兼职劳动市场微观调整影响尚属较新研究领域  

**DiD 早期可行性评估：**  

| 标准             | 评估 | 说明                              |
|------------------|------|---------------------------------|
| 处理前期数量     | 一般 | 处理州不多，但覆盖重要经济体         |
| 进入处理的选择性 | 一般 | 政策调整有一定选择性               |
| 对照组质量       | 强   | 有享有稳定对照州                   |
| 处理集群         | 一般 | 处理州数量有限                   |
| 并行政策         | 一般 | 需控制最低工资及福利相关政策           |

**主要关切：**  
兼职劳动市场的异质性较高，需注意个体层面差异控制和政策外部性。
