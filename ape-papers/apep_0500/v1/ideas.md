## 创意 1：最低工时保障法对女性劳动参与率的影响
**政策：**州级最低工时保障法（部分州自2015年至2021年间分阶段实施）

| 州         | 实施年份 |
|------------|----------|
| 加州       | 2016     |
| 纽约       | 2017     |
| 华盛顿州   | 2018     |
| 新泽西州   | 2019     |
| 马里兰州   | 2020     |

**结果变量：**女性劳动参与率（CPS API变量：LFPR，ACS中性别+劳动状态交叉变量）

**识别策略：**采用双重差分法，利用不同州在不同年份实施最低工时保障法的时间错位，比较实施前后该政策州女性劳动参与率与未实施州的变化差异。控制州固定效应和时间趋势，确保满足平行趋势假设。

**创新性：**现有文献多聚焦最低工资与就业关系，较少关注最低工时保障对劳动供给特别是女性群体的影响。女性的劳动弹性更高，该政策对平衡职业与家庭时间的影响未被充分研究。

**可行性检验：**
- 变异性：处理州5个，约10个未实施州对照
- 数据可访问性：美国人口调查局(ACS)和CPS数据通过Census ACS REST API和BLS API均可免费获取，公开可用
- 未被过度研究：最低工时保障法是近年新兴政策，相关计量分析不足

**DiD 早期可行性评估：**

| 标准         | 评估 | 说明                                   |
|--------------|------|--------------------------------------|
| 处理前期数量 | 一般 | 处理州数量有限，需关注处理前趋势平行   |
| 进入处理的选择性 | 一般 | 可能有经济状况好转州先实施，需控制协变量 |
| 对照组质量   | 强   | 有多个未实施州作为对照               |
| 处理集群     | 一般 | 5个处理州，符合多州并行处理要求       |
| 并行政策     | 一般 | 部分州同时伴随最低工资调整等政策干扰   |

**主要关切：**政策实施同时伴随其他劳动市场改革，可能影响因果解释，需要充分控制州时变协变量。

## 创意 2：婚育假政策放宽对年轻女性工资动态的影响
**政策：**州级带薪育儿假政策放宽（2014-2020年间）

| 州         | 实施年份 |
|------------|----------|
| 加州       | 2014     |
| 新泽西州   | 2015     |
| 罗德岛州   | 2018     |

**结果变量：**年轻女性（25-35岁）年收入中位数（ACS API变量：PINC-ALL），及工作收入分布（BLS年度季度就业和工资数据）

**识别策略：** 使用交错DiD，处理组为实施带薪育假州，对照组为未实施州，聚焦授予政策前后年轻女性工资变化，检验带薪假对工资成长轨迹的因果影响。

**创新性：**目前研究多关注带薪育假对就业参与和离职率，少有定量分析其对工资成长路径的动态影响，且利用跨州异质性识别策略较少。

**可行性检验：**
- 变异性：处理州3个，对照州约47个
- 数据可访问性：ACS免费提供收入数据，BLS提供工资分布数据，均可免费获取
- 未被过度研究：聚焦工资动态的因果识别鲜有

**DiD 早期可行性评估：**

| 标准         | 评估 | 说明                                     |
|--------------|------|----------------------------------------|
| 处理前期数量 | 弱   | 仅3个处理州，数量较少，差异可能不明显       |
| 进入处理的选择性 | 一般 | 政策实施多因政治环境，选择性较弱            |
| 对照组质量   | 强   | 多数州未实施，可构成高质量对照组             |
| 处理集群     | 弱   | 处理州较少，限制分层聚类标准误              |
| 并行政策     | 一般 | 部分处理州同时进行最低工资调整，需控制       |

**主要关切：**处理州数量限制统计功效，政策实施动机可能与经济状况相关需谨慎处理。

## 创意 3：职业培训补贴对低技能工人就业稳定性的断点回归分析
**政策：**职业培训补贴仅对收入低于某阈值工人（例：年收入≤25,000美元）发放，2016年起全国不同州执行细节略有差异

**结果变量：**就业持续时间（月），就业间断次数（BLS JOLTS数据，可能通过CPS Job tenure变量替代）

**识别策略：**利用收入阈值作为断点，实施断点回归设计（RDD），比较临界收入上下工人就业稳定性差异，因收入接近阈值者在所获培训补贴上存在明显差异。

**创新性：**多数学者研究职业培训对就业率影响，但基于收入阈值的聚焦断点设计减少选择偏差，专注就业稳定性创新。

**可行性检验：**
- 变异性：收入断点统一，跨州可获得数据叠加提升样本量
- 数据可访问性：ACS收入变量和BLS/JOLTS就业持续性指标均可通过公共API获取
- 未被过度研究：资本市场阈值多于收入阈值下职业培训影响研究

**DiD 早期可行性评估：**（适用RDD，DiD减弱）

| 标准         | 评估 | 说明                                   |
|--------------|------|--------------------------------------|
| 处理前期数量 | N/A  | 断点设计无需处理与对照区分             |
| 进入处理的选择性 | 强   | 户籍数据基于收入断点，高内生性低          |
| 对照组质量   | 强   | 断点附近控制精细，匹配窗口内组均衡        |
| 处理集群     | N/A  | 主要基于个人收入，非跨州聚类             |
| 并行政策     | 一般 | 需排除其他收入相关政策干扰                |

**主要关切：**收入测量误差可能影响断点准确性，需进行密度和伪断点检验。

## 创意 4：托幼补贴扩展对单亲家庭女性劳动时间的影响（交错DiD）
**政策：**部分州自2014-2019年间分批扩大儿童托育补贴资格，扶持单亲家庭女性重返劳动市场

| 州         | 实施年份 |
|------------|----------|
| 弗吉尼亚州 | 2014     |
| 俄勒冈州   | 2016     |
| 明尼苏达州 | 2018     |

**结果变量：**单亲女性每周平均劳动小时数（ACS劳动时间变量，S2301表）

**识别策略：**实施交错双重差分设计，比较托幼补贴扩大前后各州单亲女性劳动时间与未扩展州变化差异。控制州和年份固定效应及社会经济控制变量。

**创新性：**托幼补贴对女性劳动参与文献较多，但劳动时间及劳动强度的因果估计缺乏跨州时差设计。

**可行性检验：**
- 变异性：处理州3个，约47个对照州
- 数据可访问性：ACS相关变量均通过Census API可获，且时间覆盖充分
- 未被过度研究：聚焦劳动强度较少，劳动力质量维度尚缺失

**DiD 早期可行性评估：**

| 标准         | 评估 | 说明                                  |
|--------------|------|-------------------------------------|
| 处理前期数量 | 弱   | 处理州较少，需关注样本量与趋势差异    |
| 进入处理的选择性 | 一般 | 政策因政治和财政支持异质，选择性弱    |
| 对照组质量   | 强   | 多州未处理，满足高质量对照组条件       |
| 处理集群     | 弱   | 3个处理州，样本聚类调整有限           |
| 并行政策     | 一般 | 部分州同时实施低收入税收抵免，存在混淆  |

**主要关切：**托幼补贴资格严格，需考虑补贴施行覆盖率，避免低政策渗透率导致估计偏误。

## 创意 5：高校毕业生贷款宽免政策对创业率的切断截断设计分析
**政策：**2017年部分州开始实行高校毕业生贷款宽免政策，针对年收入低于某阈值群体

| 州         | 实施年份 |
|------------|----------|
| 马萨诸塞州 | 2017     |
| 康涅狄格州 | 2018     |
| 科罗拉多州 | 2019     |

**结果变量：**创业率（CPS自主职业变量或ACS自主创业状态，变量名称：ESR）

**识别策略：**采用基于收入阈值的断点回归（RDD），利用宽免收入门槛比较门槛上下的高校毕业生创业行为差异，判别贷款减免对创业激励的因果效应。

**创新性：**贷款宽免对创业的因果作用少有利用阈值设计识别，且多关注就业率影响，创业路径研究不足。

**可行性检验：**
- 变异性：跨州政策实施，内部收入断点一致，样本较丰富
- 数据可访问性：ACS和CPS数据通过公共API免费提供
- 未被过度研究：创业率与教育贷款脱钩新视角

**DiD 早期可行性评估：**（RDD主线）

| 标准         | 评估 | 说明                                |
|--------------|------|-----------------------------------|
| 处理前期数量 | N/A  | 断点设计基于收入，不涉及州数目       |
| 进入处理的选择性 | 强   | 收入断点强制实现分组，内生性低        |
| 对照组质量   | 强   | 临界窗口控制良好，呈现较好均衡        |
| 处理集群     | N/A  | 主要基于个体收入，非州级聚类          |
| 并行政策     | 一般 | 需关注贷款利率变化等其他政策干扰       |

**主要关切：**贷款收入阈值政策执行差异，需验证阈值精确度及政策渗透率。
