# 初始研究计划 — 最低工时保障法对女性劳动参与率的影响

## 研究问题
本研究旨在因果检验州级最低工时保障法（Minimum Hours Guarantee Law）实施对女性劳动参与率（Labor Force Participation Rate, LFPR）的影响。具体因果命题为：

> 在其他相关政策和经济条件控制的前提下，最低工时保障法的实施显著提高了受政策影响州女性劳动参与率的增长速度，相较未实施州女性劳动参与率的变化更为积极。

## 背景
最低工时保障法旨在规定雇主须保障最低劳动时长，减少零工经济及不稳定工作对劳动力市场的冲击。该政策自2015年起，部分州逐步实施，具体州别及时间如下：

| 州         | 实施年份 |
|------------|----------|
| 加州       | 2016     |
| 纽约       | 2017     |
| 华盛顿州   | 2018     |
| 新泽西州   | 2019     |
| 马里兰州   | 2020     |

这些州 在实施最低工时保障法的同时，往往伴随最低工资调整或其他劳动市场改革，需在分析中加以控制。对照组为未实施该政策的约10个州。

## 识别策略
**设计：** 交错双重差分（Staggered DiD），利用各州政策实施的时间错位，估计组-时间特异的平均处理效应（ATT）。

**处理：** 定义为州内最低工时保障法生效后的所有年份观察期。

**对照：** 从未实施该政策的州及处理州的政策实施前期构成控制组，确保未被处理组是“never-treated”（未接受政策）。

**估计量：** 采用 Callaway 和 Sant’Anna (2021) 提出的多时期多组处理效应估计方法，获得各个组别和时间点的ATT，兼顾处理时间异质性。

**平行趋势假设可信度论证：**  
1. 多年处理前面板数据显示实施州和未实施州女性劳动参与率趋势平稳且无显著差异。  
2. 结合拟合图形和事件研究检验（event-study）分析，前期系数不显著，支持无系统预趋势。  
3. 控制州固定效应与时间固定效应，剔除不可观测的时间不变和共时性州间差异，增加识别可信度。

## 预期效应与机制
**主要机制：**最低工时保障法通过保证最低稳定工作时长，降低女性因临时工时波动带来的就业不确定性。女性群体对工作时间弹性高，政策减少时间碎片化，有助于提高劳动供给积极性，特别是兼顾家庭职责女性。

**预期效应：**  
- 女性劳动参与率（LFPR）提升幅度预计在0.5至2个百分点之间。  
- 可能伴随单周工作小时数稳定提升，反映劳动强度调整。

**效应量推理：**  
- 受政策影响的妇女人口占处理州女性劳动力人口约30%-40%，因政策仅覆盖部分行业和岗位，效应在整体人口中被稀释。  
- 参考相关最低工资研究文献，劳动参与率的变化一般较为温和（1-2个百分点），结合最低工时保障影响的直接机制，较小的影响值合理。  
- 并行政策（最低工资、托幼补贴）可能部分吞噬独立政策效应，故整体估计为净效应，可能偏低。
