## System Requirements

### Software
- R >= 4.3.0
- RStudio (recommended)
- LaTeX distribution (TeX Live / MiKTeX)

### R Packages
```r
source("code/00_packages.R")
```
Key packages: `fixest`, `did`, `did2s`, `tidycensus`, `tidyverse`, `modelsummary`

### API Keys Required
- [ ] Census API Key: https://api.census.gov/data/key_signup.html
- [ ] (Optional) FRED API Key: https://fred.stlouisfed.org/docs/api/api_key.html

## Replication Steps

### Step 1: Set up environment
```bash
# Create output directories
mkdir -p output data figures tables
```

### Step 2: Install R dependencies
```r
Rscript code/00_packages.R
```

### Step 3: Set Census API Key
```r
library(tidycensus)
census_api_key("YOUR_KEY_HERE", install = TRUE)
```

### Step 4: Fetch data
```r
Rscript code/01_fetch_data.R
```
**Expected output**: `output/panel_data.rds`
**Estimated time**: ~5-10 minutes (depends on API response time)

### Step 5: Run main analysis
```r
Rscript code/03_main_analysis.R
```
**Expected output**:
- `output/` — regression results (.RData)
- `tables/main_results.tex` — regression table
- `figures/event_study_*.pdf` — event study plots

### Step 6: Generate figures
```r
Rscript code/05_figures.R
```
**Expected output**: `figures/*.pdf`

### Step 7: Compile paper (optional)
```bash
cd apep_XXXX/vN/
pdflatex paper.tex
bibtex paper
pdflatex paper.tex
pdflatex paper.tex
```
