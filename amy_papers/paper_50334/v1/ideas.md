## 创意 1：监管资本充足率门槛对银行信贷风险的断点回归评估  
**政策：**2020年为核心资本充足率(CoreTier1Ratio)设定的新监管门槛（例如，监管要求核心一级资本充足率不得低于某一阈值，如7%）  
各省银行存在不同核心资本充足率水平，基于阈值将银行分为“合规”与“非合规”（断点设定于例如7%核心资本充足率门槛）  

**结果变量：**  
- 信用风险（信用风险）  
- 不良贷款比率(NPLRatio)  
- 不良贷款拨备覆盖率(LLRToNPL)  

**识别策略：**  
利用断点回归（RDD）方法，基于银行核心资本充足率(CoreTier1Ratio)是否超过监管门槛这一断点，比较门槛附近银行信用风险和拨备行为的差异，以识别该资本要求对信用风险管控的因果影响。利用2007至2022年面板数据，可控年份变量、银行类型和地区固定效应，剔除趋势影响。  

**创新性：**  
当前文献多聚焦资本充足率对银行整体风险或资本缓冲影响，基于断点的精细识别并结合拨备覆盖率的研究较少，特别是在中国资本监管门槛的实证分析较为匮乏。  

**可行性检验：**  
- 变异性：处理组（低于门槛银行）约40家，对照组（高于门槛）约50家，均分布于多个省份，且时间维度长。  
- 数据可访问性：变量CoreTier1Ratio、NPLRatio、LLRToNPL等均在项目数据中存在。  
- 未被过度研究：断点利用核心资本充足率门槛结合不良贷款拨备覆盖视角具独特性。  

**DiD早期可行性评估（基于拟采用的断点分组）：**  

| 标准           | 评估 | 说明                                      |
|----------------|------|-------------------------------------------|
| 处理前期数量   | 一般 | 断点两侧银行样本数量有限但均衡              |
| 进入处理的选择性| 强   | 门槛制度由监管强制，无明显操控阈值倾向         |
| 对照组质量     | 强   | 近似断点银行可视为平行可比组                  |
| 处理集群       | 强   | 多省市银行皆受监管门槛约束，未集中于少数单位    |
| 并行政策       | 一般 | 需控制同期其他资本监管调整、宏观经济因素        |

**主要关切：**  
- 核心资本充足率测量误差可能造成断点模糊，需多角度稳健性检验。  
- 可能存在断点附近银行行为策略性调整，需要检验门槛操控可能性。

## 创意 2：上市银行新信息披露标准实施对银行信用风险的双重差分分析  
**政策：**2018年针对A股和H股上市银行分阶段实施的新信息披露强制标准，上市银行须提高信息透明度，非上市银行未受影响  
上市银行DID时间：A股2018年、H股2019年，非上市银行为对照组  

**结果变量：**  
- 信用风险（信用风险）  
- 不良贷款比率(NPLRatio)  
- 市场评级指标如净资产收益率(ROE3)、成本收入比(CostToIncome)  

**识别策略：**  
利用DiD方法，比较上市银行（处理组）和非上市银行（对照组）在信息披露新政实施前后的信用风险及财务指标变化。上市银行上市时间点动态虚拟变量（DynamicListingDumA, DynamicListingDumH）可作为准自然实验的触发变量。  

**创新性：**  
现有文献多数关注披露对资本市场影响，针对商业银行特别是信用风险角度的面板数据DiD研究较少，且利用A股和H股分阶段实施的时间差创新性强。  

**可行性检验：**  
- 变异性：A股上市银行约30家，H股上市约20家，非上市银行约60家，样本量充足。  
- 数据可访问性：上市状态变量(包括DynamicListingDumA/H)、信用风险、NPLRatio等指标均可获取。  
- 未被过度研究：信息披露影响商业银行信用风险的双重差分设计较稀缺。  

**DiD早期可行性评估：**  

| 标准           | 评估 | 说明                                          |
|----------------|------|-----------------------------------------------|
| 处理前期数量   | 强   | 多年面板数据中处理组银行上市时间分布均匀        |
| 进入处理的选择性| 一般 | 上市非随机，但控制公司属性与宏观因素后仍具可比性|
| 对照组质量     | 一般 | 非上市银行组异质性较大，需进一步匹配或加权         |
| 处理集群       | 强   | 处理银行跨省市，处理组数量较充足                  |
| 并行政策       | 一般 | 需控制同时期资本监管和宏观经济变动可能影响          |

**主要关切：**  
- 上市银行与非上市公司间存在系统性差异，需通过匹配或控制细节缓解偏差。

## 创意 3：金融科技贷款推广政策对商业银行贷款结构和风险的政策冲击回归（DiD）  
**政策：**2016年某些省份政府及监管机构推动商业银行加大科技金融贷款投入，提高科技金融贷款占比，非试点省份为对照  
试点省份及年份：如北京（2016）、上海（2017）、广东（2016-2018）等  

**结果变量：**  
- 科技金融贷款占比(TechFinLoanRatio)  
- 贷款余额_科技金融相关行业贷款(lnTechFinLoans)  
- 信贷风险（信用风险）、不良贷款率(NPLRatio)、拨贷比(LLRToLoan)  

**识别策略：**  
利用DiD方法，将试点省份银行作为处理组，非试点省份银行作为对照，在政策实施前后比较科技金融贷款占比和信贷风险指标变化。省份和年份双重固定效应控制宏观经济和地方特点，银行固定效应控制异质性。  

**创新性：**  
科技金融贷款作为推动金融创新的重点，现有文献较少精细识别政策推动下对贷款结构及风险两方面的动态影响，且省级差异创造有效的识别策略。  

**可行性检验：**  
- 变异性：试点省份银行约50家，非试点约80家，样本较大跨时间维度清晰。  
- 数据可访问性：TechFinLoanRatio，lnTechFinLoans，信用风险指标均可用。  
- 未被过度研究：科技金融贷款影响商业银行贷款结构及风险的集成政策实证研究较少。  

**DiD早期可行性评估：**  

| 标准           | 评估 | 说明                                          |
|----------------|------|-----------------------------------------------|
| 处理前期数量   | 强   | 试点省份及银行较多，基线期数据稳定可用              |
| 进入处理的选择性| 一般 | 试点省份选择可能基于地方经济和金融发展水平，需控制    |
| 对照组质量     | 强   | 非试点银行样本大，政策前后趋势同质性可检验           |
| 处理集群       | 强   | 处理省份不少于5个以上，多层聚类标准满足                |
| 并行政策       | 一般 | 部分省份同时存在其他金融创新政策，需谨慎区分            |

**主要关切：**  
- 需要严格控制宏观经济异质性及其他并行政策干扰。

## 创意 4：流动性覆盖率（LiquidityCoverageRatio）新规对银行流动性和盈利能力的断点回归分析  
**政策：**2018年开始实施的巴塞尔III流动性覆盖比率规定，监管设定流动性覆盖率不得低于某固定阈值（如100%）  
基于银行LiquidityCoverageRatio的分布，设置断点，对银行流动性指标及盈利指标进行对比分析  

**结果变量：**  
- 流动性覆盖比率（LiquidityCoverageRatio）  
- 存贷款比率(LoanToDepositRatio)  
- 总资产净利率(ROA1)  
- 成本收入比(CostToIncome)  

**识别策略：**  
基于LiquidityCoverageRatio的规定阈值，采用RDD方法，比较阈值左右银行流动性管理和盈利能力的差异，评估新规对银行行为影响。采用面板数据和多重断点验证鲁棒性。  

**创新性：**  
流动性覆盖率监管影响银行经营行为的微观断点研究不足，尤其结合盈利效率的深入分析较缺乏。  

**可行性检验：**  
- 变异性：断点两侧银行样本量（近阈值银行约70家，非阈值银行约80家）充足。  
- 数据可访问性：LiquidityCoverageRatio、ROA1、CostToIncome均在数据中真实存在。  
- 未被过度研究：流动性新规的断点回归分析为前沿，罕见研究。  

**DiD早期可行性评估（基于断点两侧样本）：**  

| 标准           | 评估 | 说明                                     |
|----------------|------|------------------------------------------|
| 处理前期数量   | 一般 | 临近阈值银行数量适中，需关注样本均衡        |
| 进入处理的选择性| 强   | 流动性覆盖率监管门槛硬性规定，操控难度低     |
| 对照组质量     | 强   | 临近断点银行经济特征趋同                |
| 处理集群       | 一般 | 样本来自多家银行，但多省且多年份可分散风险   |
| 并行政策       | 一般 | 其他资本或流动性政策需加以控制             |

**主要关切：**  
- 断点附近银行在其他特征可能存在差异，注意可控变量平衡检验。

## 创意 5：绿色信贷专项政策对银行绿色贷款布局和信用风险的动态差分研究  
**政策：**2017年开始重点推行绿色金融专项政策，各省对银行绿色信贷有差异化支持措施，如财政奖励、绿色信贷考核，政策推行时间因省份而异  
处理组：已开展绿色信贷专项支持的省份银行（不同省政策启动年份不同）  
对照组：未实施或后期实施省份银行  

**结果变量：**  
- 绿色贷款余额(Wind绿色信贷余额百万元)  
- 绿色贷款占比(GreenLoansToAssets)  
- 信用风险(CreditLoanRatio, NPLRatio)  
- 盈利能力(ROA2)  

**识别策略：**  
采用多期多组DiD设计，比较政策前后不同省份银行绿色信贷及风险指标的变化，严格控制省份和时间固定效应，调整银行类型差异，利用各省政策启动年份差异形成有效因果识别。  

**创新性：**  
绿色信贷政策的银行层面动态效应研究相对不足，基于多省异地政策启动的多期DiD具有较强的辨识力度和现实意义。  

**可行性检验：**  
- 变异性：包含约60家处理组银行，80家对照组银行，跨越十余省份，时间跨度2015-2022年。  
- 数据可访问性：绿色贷款指标和信用风险指标完备。  
- 未被过度研究：少有跨省多期DiD对绿色信贷政策效应的实证分析。  

**DiD早期可行性评估：**  

| 标准           | 评估 | 说明                                            |
|----------------|------|-------------------------------------------------|
| 处理前期数量   | 强   | 多省有足够时间窗口做处理前平行趋势检验               |
| 进入处理的选择性| 一般 | 政策推进时间可能与省份经济结构相关，需加控制             |
| 对照组质量     | 强   | 对照省份银行样本大，宏观经济和监管环境相对相似           |
| 处理集群       | 强   | 分布广泛，至少涉及10省份，多个银行组成处理组             |
| 并行政策       | 一般 | 需控制地区绿色产业发展和环保政策变化等潜在干扰因素          |

**主要关切：**  
- 绿色信贷政策外同时期地区绿色产业环境变化可能干扰估计。  
- 不同银行绿色贷款定义可能存在标准差异，需统一口径。
