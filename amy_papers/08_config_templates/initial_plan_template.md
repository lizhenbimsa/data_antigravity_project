## 4. 识别策略

### 方法选择: {DiD / RDD / IV}

#### 双重差分法 (DiD)
$$Y_{bt} = \alpha + \beta D_{bt} + \gamma_b + \delta_t + X_{bt}'\theta + \epsilon_{bt}$$

- $Y_{bt}$: 银行 b 在第 t 年的结果变量
- $D_{bt}$: 处理指示变量 = 1 if 银行 b 在年份 t 已受到政策影响
- $\gamma_b$: 银行个体固定效应
- $\delta_t$: 年份固定效应
- $X_{bt}$: 时变控制变量（银行规模、资本充足率、不良贷款率等）

#### 断点回归设计 (RDD)（如适用）
$$Y_b = \alpha + \tau \cdot \mathbb{1}[X_b \geq c] + f(X_b - c) + \epsilon_b$$

- 驱动变量: {如资本充足率}
- 断点值: {如 8%（巴塞尔III最低要求）}
