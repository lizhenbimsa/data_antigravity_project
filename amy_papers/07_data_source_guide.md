# AutoPaper 复现 — 本地数据源参考指南

## 概述

AutoPaper 项目严格使用**本地存放的 DTA 标准数据集**，确保所有研究高度可复现且无需外网数据拉取依赖。所有研究需要的数据均已全部统一合并至 `data/data.dta` 文件中，严禁在研究中试图调用外部 API 或下载额外数据。

本指南说明了如何读取和使用 `data.dta`。

---

## 1. 核心数据集：data.dta

这是包含银行核心财务指标、衍生计算变量、宏观与区域控制变量的综合大宽表。
- **文件路径**: `data/data.dta`
- **涵盖层次**: 机构-年份层级 (包含 id, 机构编码, 中文简称, 计算省份, 计算城市, year)

### 主要内容概览

通过查阅同目录下的 `data_schema.txt`，您可以获得每一个具体变量的名称、标签和数据类型。该文件是利用 Python `pandas.read_stata` 或类似工具直接从 `data.dta` 中提取构建的，保证 100% 准确性。这些变量大致涵盖了：
- **银行基础财务**：资产负债表、利润表、信贷结构、资本充足率等。
- **衍生与风险指标**：各类财务比率、Z-score、非利息收入占比等。
- **前沿与新兴指标**：数据赋能、人工智能、绿色金融的文本挖掘词频、相关专利、手机 APP 活跃度等。
- **宏观与区域控制变量**：城市与省份级别的 GDP、财政投入、数字普惠金融指数、以及各类政策实施虚拟变量。
- **国家级宏观变动指数**：经济政策不确定性指数 (EPU) 等特征。

---

## 2. 如何在分析中使用这些数据

所有 Stata 脚本在执行预处理（如 `01_fetch_data.do`）时，**必须直接使用 `use` 命令** 加载唯一的数据源 `data.dta`。**不需要**再进行复杂的多文件/多表单 `merge` 操作，因为 `data.dta` 已经预先整合成了一张宽表。

### 编码格式示例
```stata
* 1. 清除内存并加载整体的 DTA 数据集
use "data/data.dta", clear

* 2. 选取研究需要的特定变量子集
keep year 机构编码 中文简称 计算省份 计算城市 净利润百万元

* 3. 过滤缺失值，例如：
drop if missing(净利润百万元)

* 此处继续其他处理...
```

> [!WARNING]
> 本项目的设定为完全局域且自洽。请牢记：**不下载、不爬取、不调用外部 API**。所有变量均可（且仅可）从 `data.dta` 中经过 `data_schema.txt` 查询后进行索取并处理。
